## 一、候选现状（12 条要点）

- **CJ01 连词是胶水词**（导引组）：连词的定义条——引 Merriam-Webster「words that join together other words or groups of words」与 BBC Bitesize 儿童版「joining words」，孩子面用胶水比喻统摄全区。
- **CJ02 FANBOYS 七兄弟**（导引组）：并列连词封闭名单 for/and/nor/but/or/yet/so + FANBOYS 口诀；孩子面文案作「并列连词只有七个」。
- **CJ03 逗号加连词，牵手两个完整句**（导引组）：两个独立分句以「逗号 + 并列连词」连接（Purdue OWL 两处原文）。
- **CJ04 从句是挂车，自己不能上路**（从属组）：从属分句依赖主句、不能独立成句（EnglishClub / Cambridge 原文），例「Although it was raining.」为残缺句。
- **CJ05 时间队**（从属组）：时间从属连词名单（after/as/as soon as/before/once/since/till/until/when/whenever/while）+ 标先后语义。
- **CJ06 原因队**（从属组）：原因连词名单（as/because/now that/since）+ as/since 语气较弱、较正式的语域注记；条内自注「because 和 so 不能同上见 GR-11」。
- **CJ07 条件与让步队**（从属组）：条件组（if/unless/provided that 等）+ 让步组（although/even though/though/whereas/while）名单；附「although 后面不能再跟 but」；条内自注与 GR-11 互挂（同一双连词家族）。
- **CJ08 not only…but also：强调搭档**（搭档组）：关联连词定义（Grammarly）+ 平行结构要求 + not only 句首前置的部分倒装（成人层注记，引 Lumen）。
- **CJ09 连接副词不是连词：力气小，靠分号**（副词组）：连接副词不是连词、逗号粘不住、须用「分号 + 连接副词 + 逗号」公式（Purdue OWL / QuillBot / SJSU）；条内自注与 GR-38 互挂（逗号粘连定版在 GR-38）。
- **CJ10 连接副词八组功能队**（副词组）：连接副词按功能分八组（转折/因果/顺序/添加等），分类综合 EnglishClub / QuillBot / ThoughtCo 三家；Cambridge 术语 linking adjuncts。
- **CJ11 连接副词会走动**（副词组）：连接副词可在分句内移动（句首/主谓间/句末）、连词不可——移动测试（ThoughtCo 引 Reid 教材）+ Cambridge「linking adjuncts can come in any position which an adverb can occupy」。
- **CJ12 身兼数职的词：看后面跟什么**（多面手组）：before/after/since/until 等词的词性判别律——后跟名词/代词为介词、后跟完整分句为从属连词、后无跟随为副词（Khan Academy + 研究合集判别标准）；条内附注 so、though 也是多面手。

## 二、图鉴命中清单

图鉴中连词/句子连接相关的成条规律**只有 3 条**，全在 GR 组：GR-11、GR-32、GR-38。另有相邻条 GR-30（关系从句）、GR-40（虚拟语气 if）、TM-31（参考语法术语演变）、介词卷宗若干页。逐项如下。

### GR-11「because 和 so 各管一段路：英语一段因果通常只留一个连接点，两个都上是汉语的习惯迁移」

- 主张原文：「英语从句连接以形合为常态：**一个主从关系由一个从属连词标明即足**。同一因果链里 because…so 并用，是汉语『因为…所以』成对关联词的意合习惯迁移到英语的冗余结构。」
- scope 原文：「问题只在同一因果链里并用；because 与 so 各自单独使用均合法。」
- 与候选的关系：CJ06 的禁忌面（because…so 不同上）即本条，CJ06 条内已自注互挂；CJ07 的 although…but 禁忌是同一「一个连接点」主张向让步链的推广——但 GR-11 的标题、主张落点与 scope 都明限**因果链**，让步链未在其登记范围内（见冲突 3）。

### GR-32「关联词成对出门：both…and、either…or 各就其位，并列成分要同形，动词听离它最近的那个主语」

- 主张原文：「① 配对纪律：关联并列是封闭配对——both…and…、either…or…、neither…nor…、**not only…but also…（also 可省、but 不可省）**，混搭不成立。② 同形原则：关联词之后紧跟的成分必须同类同形。③ **not only 前置句首时后半句主辅倒装**。④ 就近原则：either…or / neither…nor 连接数不一致的主语时，谓语与较近的主语一致……」
- 与候选的关系：**CJ08 的全部三个内容点（not only…but also 是关联连词对、平行结构要求、前置倒装）都在 GR-32 主张里逐点成文**，连 CJ08 成人层当作「进阶角」的倒装注记都是 GR-32 的主张③。CJ08 与 GR-32 是同一规律的两次写作（目录定版 + 联网新拟），不是互补关系。

### GR-38「标点是语法的一部分：英语的逗号扛不起两个完整句子，撇号也不是装饰」

- 主张原文：「① 逗号粘连：两个独立分句之间只用逗号连接，在标准英语书面语中是句子边界错误；**合法连接只有四种——句号分开、分号连接、逗号+并列连词、把一分句降级为从属分句**。……② 撇号二职……」
- 机制中另有分号连接的条件登记（「分号连接要求两分句语义密切相关」）。
- 与候选的关系：CJ03 的规则（逗号+并列连词连接两独立分句）就是主张①四种合法连接的第三种，原文成文；CJ09 的分号公式落在同一主张内（分号连接是四种之一）。但 GR-38 通篇**没有「连接副词」这个概念**——不点名 however/therefore 一类词、不说「副词力气不够」——CJ09 的词类本体与词表不在 GR-38 内（见 §五）。

### 相邻条（非对应，防误判）

- **GR-30**「关系从句先分『认人』还是『补一句』」：只管关系从句（限制性/非限制性、关系词选择、零关系词），是从句家族的一个特定成员；「从属分句不能独立成句」这一总纲不在其主张内。CJ04 与它相邻不重合。
- **GR-40**「虚拟语气只剩几块化石」：if 只出现在假设条件从句的 were 遗迹语境，是时态/语气条，与 CJ07 的条件连词分队无关。
- **GR-12**「主谓一致有三股力」：就近一致与 GR-32 主张④同源，已由 GR-32 承接关联连词场景，与 12 条候选无直接对应。
- **TM-31**（teaching 组）「语法书本身也在进化：三代参考语法」：成人层一节登记「**CGEL 把传统上作从属连词、副词的 before/after/since 等一并划入介词（可带从句补语……）**」——图鉴里唯一触及 CJ12 词群归类的文字，是术语史注记，不是给孩子的判别律（见冲突 7）。
- **介词卷宗**（small_systems/prep_thick）：after 卷宗明示「表『因为、在……之后』的 after 多已连词化……**不在本页**」；as 卷宗明示「as 的连词用法……**一概不在本页，归语法区**」——介词侧把这批词的连词面明确推给语法区，而语法区（GR 组）无任何条目承接。CJ12 正是这个跨区缺口的候选填补者。
- **E-10**（expression 组）：小学段语篇衔接只收 and/then/but 三个基础衔接手段，是口语表达的目标设定，不是连词规律条。
- **TEC-L22 / TEC-G26**（techniques 组）：写作层「衔接词是给读者的路标」（CG-01 衔接/连贯框架）与对 GR-11 机制的引用，是写作方法论，不构成连词分类或判别条。

### 全量扫查的零命中（作为「无对应」的证据）

- 「**连接副词**」/ conjunctive adverb / linking adjunct：在 model/laws 全部 YAML 中 **0 命中**；图鉴 HTML 中 FANBOYS **0 命中**。
- 「分号」在图鉴中只出现在 GR-38 主张与机制内（作为四种合法连接之一），无独立标点条。
- 从属连词的功能分类（时间/原因/条件/让步分队）在 GR、small_systems、grammar_ext（QI/CO 组）中均无成条；「从属分句不能独立」「句子残缺（fragment）」无成条表述。

## 三、重合度判定（逐条）

### 完全对应（1 条）

- **CJ08**：主张层与 GR-32 逐点重合（配对名单、同形原则、前置倒装），例证与成人层注记亦同源同旨。CJ08 的增量为零——它是 GR-32 的孩子面改写，不是新知识。保留独立候选将制造 C-14/GR-15 式的同容双条。

### 部分重合（4 条）

- **CJ03**：核心规则（逗号+并列连词连接独立分句）在 GR-38 主张①中原文成文，是其四种合法连接之一；但 GR-38 的条目主题是句界错误全景 + 撇号，CJ03 是把这一条合法连接抽出做正向教学（先立正例、再防粘连），且其词表依赖 CJ02 的七词名单。规则有据、无独立条——与 NEW-T 先例中「三读全貌被 S-18 以支撑引用」的情形同构。
- **CJ06**：禁忌面（because…so 不同上）与 GR-11 完全重合且候选已自注互挂；但本条主体——原因连词名单（as/because/now that/since）与 as/since 的语域分工（较弱、较正式）——图鉴无对应表述，GR-11 不做原因连词清点。
- **CJ07**：although…but 禁忌是 GR-11 一般主张（一个主从关系只标一个连接点）的合理推广，但 GR-11 的 scope 明限因果链，推广未登记；本条主体——条件组与让步组名单——图鉴无对应。
- **CJ09**：标点面（分号连接两独立分句）落在 GR-38 主张①内；但本条的立条理由是「连接副词」这一词类范畴（不是连词、逗号粘不住的原因在词性），该范畴连同 however/therefore 词表与分号公式，图鉴全无。

### 无对应·真空白（7 条）

- **CJ01**：图鉴是机制/规律型图鉴，没有任何词类的定义条；「连词是连接词」这一定义在图鉴内无落点。它在连词区的功能是区级导引（类 LAWREG 的框架位 V-15/V-30），不属于规律对账的同一物种。
- **CJ02**：并列连词的封闭名单（七词）与 FANBOYS 口诀在图鉴中 0 命中；GR-38、GR-32 都只泛用「并列连词」一词，从不清点成员。这是小学阶段最常教的一条连词事实，图鉴缺条。
- **CJ04**：「从属分句依赖主句、不能独立成句」是句子结构的基础规律，图鉴只有它的下游应用（GR-30 关系从句、GR-38「降级为从属分句」的合法连接），总纲本身无条。
- **CJ05**：时间从属连词的分队名单与「标先后」语义，图鉴无对应（介词卷宗有 after/before 的介词面卷宗，但连词面被明确排除在外，见 §二）。
- **CJ10、CJ11**：连接副词的功能分类与移动性判别，整组空白（详见 §五）。
- **CJ12**：词性判别律（看后面跟什么）在图鉴无成条；TM-31 的 CGEL 注记是成人术语史，且口径与 CJ12 的传统三分不同（见冲突 7）；介词卷宗的排除声明反证此缺口真实存在（推给语法区、语法区没接）。

## 四、编号与归属建议

### 总原则：续 GR 号，不另立 CJ 组

图鉴既有的连词/句子连接条（GR-11、GR-32、GR-38 及相邻 GR-30）全在 GR 组（语法：句法与句子结构）；新条续 GR 号（GR 组现至 GR-45，续号自 GR-46 起）能让连词家族在目录里团聚。另立 CJ 组会把 GR-11/32/38 与新条拆成两个家——正是本次治理要消除的双户口病。以下各条的编号即按此原则给出；若 Stewart 另有组别裁定，编号顺延即可，处置（并入/立条/撤销）不变。

### 逐条处置

1. **CJ01 → 撤销候选，转区导引**。不定编号、不入图鉴：定义条不是规律条，强行立条会开「词类定义入册」先例。它在连词区的导引位置保留，状态标记由「新拟·待对账」改「区导引」即可销账。
2. **CJ02 → 立条 GR-46**。内容 = 七词封闭名单 + 「两边等重」的连接对象说明；FANBOYS 口诀降为孩子面助记（成人层注明口诀来源为学校语法传统）。文案需先校准「只有七个」的口径（见冲突 4）。
3. **CJ03 → 并入 GR-38（呈现位）**。不新开编号：规则本体在 GR-38，连词区保留现行孩子面页作为 GR-38 的呈现位（与 NEW-C 并入 S-21 的先例同构），页内词表引用 GR-46 的七词名单。
4. **CJ04 → 立条 GR-47**。内容 = 从属分句的依赖性 + 残缺句判别；与 GR-30（关系从句是其一个成员）、GR-38（降级从属是合法连接之一）双向互链。
5. **CJ05 + CJ06 + CJ07 的分队部分 → 合并立条 GR-48「从属连词按意思分队」**。三条候选同构（名单 + 一句语义），分开立条会产生三条瘦条；合并为一条四队总表（时间/原因/条件/让步）更合图鉴的成条体量先例（参 GR-29 一条装下八个词尾、GR-32 一条装下配对+同形+就近）。各队原候选的孩子面页保留为呈现分节。CJ06 的语域注记（as/since 较弱较正式）随条保留。
6. **CJ06 的禁忌面 → 互链 GR-11，不重复立条**（候选已自注，照此定版）。
7. **CJ07 的 although…but 禁忌 → 建议在 GR-11 边界增补登记**（「同一原则适用于让步链：although…but 同样只留一个连接点」），CJ07/GR-48 页内只作互链提示，不另立禁忌条。此项涉及改动 GR-11 登记文本，列入待裁定（见 §六.3）。
8. **CJ08 → 并入 GR-32（撤销候选，呈现位）**。内容权威源定为 GR-32；连词区现行页保留为 GR-32 的孩子面呈现（与 CJ03 呈现位同例）。CJ08 成人层那条 Lumen 倒装例句可回填 GR-32 成人层作例句补充（GR-32 主张③目前无此例句），属内容增益而非冲突。
9. **CJ09 → 并入 GR-38（呈现位）+ 与 GR-49 互链**。分工定为：标点规则（分号公式、逗号粘连）归 GR-38 详讲；词类本体（什么是连接副词、有哪些、怎么动）归 GR-49。CJ09 现行页保留为 GR-38 在连接副词场景下的呈现位——它自注的「与 GR-38 互挂、本条专管连接副词场景」正是这个分工，照此定版即可。

## 五、整体结论：连接副词在图鉴中是整组空白

任务书预判的情况成立，且程度比预判更彻底：「连接副词」作为一个范畴，在 428 条图鉴中**零存在**——没有定义条（它是什么、与连词的区别）、没有成员条（功能分队、常用词表）、没有判别条（移动测试），连术语本身在全部模型 YAML 中都 0 命中。图鉴与它最近的接触点只有 GR-38 主张里的「分号连接」四个字：分号在图鉴里是作为逗号粘连的解法之一出现的，使用分号的那类词从未被点名。

这意味着 CJ09/10/11 这一组候选里，只有 CJ09 的标点外壳能挂靠 GR-38，词类本体（CJ10+11）是图鉴体系外的新大陆。处置上因此分两层：标点规则不另起炉灶（并入 GR-38，防双处表述），词类本体集中立一条 GR-49 承接，避免三条候选各立一条互相重复的连接副词条。

同理可作整体观察的还有两处：

- **从属连词的功能分队（时间/原因/条件/让步）在图鉴中亦无成条**——图鉴对从属连词的处理是「点状」的：GR-11 只打双连词禁忌一点、GR-30 只管关系从句一族、GR-40 只借 if 讲虚拟语气。小学阶段按功能队教从属连词是主流教法（候选的分类综合自 EnglishClub/Cambridge/Khan 三家），图鉴缺的是一张总表，故 GR-48 以合并条承接。
- **本批 12 条的整体成色**：与 NEW-P 等候选不同，CJ 批的「新拟」多数不是图鉴已有规律的改写，而是图鉴在「句子连接」这一章的真实留白（7 条无对应中，CJ01 是物种不同，余 6 条都是实缺）。这与连词区是全 App 最晚建成的区、图鉴 v6 的 GR 组以形态与句法机制为主、句子连接只立了 3 条纠错型规律（GR-11/32/38 均为「防错」条，无一条「建构」条）的历史有关：12 条候选恰好补的是建构面（名单、分队、判别、公式）。

1. **CJ08 与 GR-32 同容双条**：不是口径冲突，是同一规律的两次写作。若不并入，将重演 C-14/GR-15 式双条（且那对还是 Stewart 明示保留的，这对没有保留理由）。

3. **CJ07 对 GR-11 的 scope 外溢**：GR-11 主张是一般式（「一个主从关系由一个从属连词标明即足」），但标题与 scope 明限因果链；although…but 禁忌是向让步链的推广，学理上成立（Cambridge 的一般式表述可佐证），但在图鉴登记口径上属未登记推广——须经裁定后在 GR-11 边界增补一行，CJ 侧才算名正言顺。
4. **CJ02 文案强于其来源**：孩子面作「并列连词只有七个」，其自引来源 Grammarly 原文是「The most common coordinating conjunctions are…」（最常用）。传统学校语法中七词确为封闭名单，「只有」在该传统内可辩护，但与自引来源口径不一致；立条 GR-46 时应校准为与来源对齐的表述（如名单封闭性注明「学校语法口径」并在成人层交代）。
5. **CJ05 与 CJ06 候选内部兼队**：since、as 同时出现在时间队（CJ05 名单含 since；as 亦在时间名单）与原因队（CJ06 名单含 as、since）——按功能分队必然有兼队成员，这不是错误，但立条 GR-48 的总表须标注兼队并与 CJ12/GR-50 的多面手判别互链，否则孩子会问「since 到底是哪队的」而无口径。
6. **CJ10 八组分类无定版一源**：功能组数与组界是 EnglishClub / QuillBot / ThoughtCo 三家综合，各家分法不一（组数 6–8 不等）。立条 GR-49 前须选定一版为定版（或明示综合口径），否则分队表本身成为下一个漂移源。
7. **CJ12 与 TM-31 已登记的 CGEL 口径张力**：图鉴在 TM-31 成人层已登记 CGEL 立场（before/after/since 等一并划入介词），CJ12 的传统三分（介词/连词/副词）与之不同。两者并非谁对谁错（介词卷宗 as 页已有「按国内教材的介词口径收录」的先例），但 GR-50 立条时成人层必须注明两派口径与本条取舍，免得与 TM-31 在图鉴内表面打架。
