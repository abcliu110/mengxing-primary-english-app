## 三、横幅四数口径与数据来源（全部实算，源 = mxReviewV1 + RV.buildPool）

账本记录形态（实测）：`mxReviewV1 = {items:{key:{b, due}}, wrong:{key:{n, ts}}}`，无其他时间戳。

| 格 | 口径 | 可算性 |
|---|---|---|
| 今日学习 | 池题中「最后练习时刻落在今天」的题数。最后练习时刻由记录反推：答题时写入 `due = 答题时刻 + INT[b−1] 天`（INT=[0,1,3,7,16]，与复习引擎同表），故 `due − INT[b−1]·DAY` 即答题时刻 | ✅ 实算 |
| 完成度 / 已学 | 账本已进题数（touched）/ 池总量 1,796（运行时 buildPool 实数） | ✅ 实算 |
| 待复习 | 账本中 `due ≤ 今日 23:59` 的池题数，与复习区 buildQueue 的 due 口径一致 | ✅ 实算 |
| 右格前数 | **「新学」不可算**：账本没有「首次练习」时间戳，首学与复练在记录上不可区分。按任务书预案改显 **今日错题** = `wrong` 中 `ts` 落在今天的条数（同源实算），UI 文案即写「今日错题」，不冒充新学 | ⚠️ 替代（已如实标注） |

零数据（新用户）：四数全 0、进度条 0%、提示行显「还没有练习记录，从任意一区开始吧。」，不报错（冒烟 Phase C 验证，且与基线比对无新增脚本错误）。统计在页面初载与每次点回首页（data-v/data-go=home）时重算。

注：横幅口径为复习池单源（与任务书「与待复习同源」一致）；动词 SRS（mx_vb_srs_v1）记录无逐题时间戳，不并入横幅，只在动词卡单列。
