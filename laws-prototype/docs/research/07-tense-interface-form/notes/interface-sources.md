# Interface-focused sources — read 2026-11-02 (follow-up mission)
## VERIFIED LIVE in research window
- Lingolia Timeline https://english.lingolia.com/en/grammar/tenses/timeline — 3 cols (Past/Present/Future) x 4 rows (Simple/Progressive/Perfect/Perfect Progressive) SVG matrix. Left rail = full tense topic list (Overview, Timeline, then each tense, Irregular Verbs, Tense Comparison). CLICKED Progressive row (live): matrix filtered to just that row, 3 cells across time, SAME verb (bake a cake) in all 3, glyph = green wavy line crossing a vertical reference line; below: 3 example sentences + viewpoint definition ("you view an action as ongoing, incomplete or temporary"). Simple row glyph = green X marks (points). Reset icon appears. So: aspect=row (one glyph grammar), time=column, cell=example. Clicking a row/column is the lesson.
- Lingolia present-perfect unit page (prior turn, verified live) https://english.lingolia.com/en/grammar/tenses/present-perfect-simple — order on screen: definition line, dialogue (Ada/James, every target use bolded in situ), uses list, signal words, conjugation table AFTER uses, participle spelling, been/gone contrast box, contractions; exercises are a separate linked page per topic (also graded exercise sets). Meaning first, form mid-page.
- Perfect English Grammar USE page https://www.perfect-english-grammar.com/present-perfect-use.html — VERIFIED LIVE this turn: top nav separates EXPLANATIONS | EXERCISES as two silos. Page itself: hero title, then link OUT to separate MAKE page ("Click here to learn how to MAKE the present perfect") — use and form are different URLs. Body = numbered uses 1-5, each bold verb examples, a struck-through NOT example (*I've seen him yesterday), been/gone section; practice only as outbound links at the very bottom ("Try an exercise... here"). Read-only scroll; nothing manipulable on the page.
- IIENSTITU Tense Explorer https://www.iienstitu.com/en/tools/en-tense-explorer — VERIFIED LIVE (tool itself rendered as skeleton/loading in window; feature set from page text): "16 tenses in one dashboard": grid of cards grouped Present/Past/Future, each card = name + formula string (S+have/has+V3); per-tense panel = +/-/? formulas, time markers, use cases, SVG mini-timeline; LIVE SENTENCE BUILDER: pick subject/verb/object/adverb -> builder assembles positive+negative+question instantly; COMPARE tab puts confusing pairs side-by-side (PresPerf vs Past Simple, will vs going to, Past Cont vs Past Simple); Reference tab = V1-V2-V3 list. Form is composed by the learner manipulating slots — closest public analogue to 'form composed last'.
- British Council LearnEnglish present perfect page (index) https://learnenglish.britishcouncil.org/comment/192408 (canonical grammar page; a guessed deep URL 404'd live — do not use it): interface order = hook examples -> "Try this exercise to test your grammar" (TEST BEFORE explanation) -> Grammar explanation (unfinished time/states; finished time = past simple; result-in-present; just/yet/already) -> "Do this exercise to test your grammar again" Grammar test 2. Test-explain-retest sandwich on ONE page; contrast pair built into the explanation zones. A2/B1 versions split simple vs continuous into a two-column contrast table (result vs activity, how many vs how long).
## INDEX (descriptions/reviews/research paper, not in-app live — signed out)
- Duolingo Path (2022 redesign): home = winding vertical path, coloured unit banner header (section/unit title + guidebook icon), nodes = circles with icons, progress RING around current node replaces crowns; each unit starts with a GUIDEBOOK (bite-size grammar tips+phrases, tappable, re-openable after completion); Stories and review lessons are nodes IN the path, not a separate tab; unit jump/test-out at unit header; Legendary = whole-unit harder replay. Duolingo research report DRR-24-04 (duolingo-papers.s3.amazonaws.com): path vs tree — stories became obligatory in-path, dedicated review lessons added in-path, 3 difficulty tiers obligatory (low=recognition, high=recall/production); path took longer, better proficiency outcomes than tree. Nodes are labelled by TOPIC/function ("Talk about music preferences"), NOT by tense — tense-aspect system is invisible on the map; no overview screen of the verb system; course overview exists only as a hidden section list (tap banner) with CEFR/score ranges.
- Busuu: 3-tab interface Learn | Community | Review. Learn = chapters grouped by CEFR level shelf, linear feed; a dedicated grammar lesson every ~3-4 lessons (2-3 sentence explanation + examples + drills on one screen). Review tab = separate SRS space: vocabulary/grammar colour-coded by mastery strength, Smart Review resurfacing, Mistake Repair list. Grammar is findable again via Review, unlike Duolingo.
- Babbel: course list by level; lesson screen sequence = dialogue first (see+hear) -> vocab/grammar callout boxes extracted FROM that dialogue -> matching/translation/typing + speech recognition, immediate correction; Review Manager = separate spaced-repetition deck of everything met. Grammar callouts are overlays on content, not a separate lecture page.
- BBC Learning English (prior turn, index/course-info PDF + mirrored pages): course home = numbered list of 30 TOPIC units (titles are topics, not grammar); unit = 5 session tabs (6 Minute Grammar audio+transcript+quiz, 6 Minute Vocabulary, News Review/drama episode of The Race, writing/reading, quiz); bottom of session = "Session Grammar" reference box + "View full grammar reference"; Lower Intermediate U20 and Intermediate courses re-teach tenses as a combined review inside a topic shell. Story player = serial drama: same characters, tense taught inside episode plot.
- Murphy (print interface, prior turn): the SPREAD is the interface: left page = explanation zones A/B/C/D each opened by a pictured example situation + timeline/clock drawings, margin cross-reference arrows (Present perfect -> Units 7-8, 11-14) make a printed hyperlink network; right page = exercises only, graded within the page (form completion -> picture/situation sentence-writing -> correct-the-sentence -> write-about-yourself last exercise). Contents list + diagnostic Study Guide ("if you don't know which units you need, use the study guide") = routing interface on top of a non-sequential book ("units are not in order of difficulty").
- Azar (prior turn + chart search): TWO map interfaces: (1) Contents-as-map: Ch1 Overview + 1-5 Summary Chart of Verb Tenses comes FIRST, before any single tense is taught — the whole 12-cell system is shown as a chart with one constant example verb, timelines under each cell; a standalone Chartbook strips exercises away entirely (charts-only reference interface). (2) Unit interface: Warm-Up exercise BEFORE the chart (learner tries examples first), then chart (form+meaning+timeline drawing in one table), then exercises incl. editing/error-correction and pair interview; Azar Interactive adds pop-up charts + animated presentations. Chart rows/columns in Azar-derived charts: time columns x aspect rows, each cell = example + time-span gloss ("habitual action - past to present to future").
- Timeline glyph grammar (cross-source): X/cross = single completed event; wavy/long line = ongoing; arrow linking two X's = perfect (earlier event linked to reference point); ? = unknown start/end (TEFL timeline-teaching tradition, videohighlight summary); Woodward-style timeline chart = one long horizontal axis, all 12+ tenses placed as shapes ON it, rare tenses asterisked.
- Structured-input drill interface (VanPatten PI, prior turn): referential activity screen = hear sentence, choose NOW or PAST picture — temporal adverb REMOVED so the verb ending is the only cue; interface forces attention to form by deleting the redundant cue. Affective activity = agree/express opinion about content (weaker alone).
