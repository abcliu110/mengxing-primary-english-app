# 介词研究总集（prepositions-compendium）

本目录是本仓**全部介词研究资料的统一入口**：把分散在四处研究目录、一份数据卷宗与一份产品规格中的介词材料合并成一部总集（`compendium.md`）。原件全部保留不动；总集只做编辑合并，不产生新结论。

## 与原件的关系

- **原件为准**：总集是入口与合并读本。任何裁决、引证、数据与原文表述以原件为准；总集与原件不一致时以原件为准，原件不因总集而修改。
- **编辑合并口径**：同一内容在多份源材料中重复的，总集只写一次并多标出处；禁止新造例句、义项、理据或结论；极少量编辑性说明以「按：」标明，与引证内容可区分。
- **分歧不调和**：源间冲突与未决项在总集第一部 1.6 集中登记（over 双中心、on 断链、with/of 负裁定、by 未决、plus 空白等），并在第二部对应词节原文呈现，不擅自裁决。
