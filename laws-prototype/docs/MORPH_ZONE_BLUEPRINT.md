## 二、扩充（第二步成果：`model/morpheme_expansion.json`）

- 方法：脚本按五路生成候选（前缀+自由词基 / 后缀+自由词基 / 黏着根子串 / 复合双词基 / 屈折形条目），**逐条人工裁定**；接受须有 V/GR/S 条出处，拆分须为该词真实构词；历史构词与教学口径冲突时按目录条口径并在 note 注明；驳回与拿不准的进 pending 并写明理由。
- 结果：**新增拆分 388 条**（透明度：全透明 184 / 半透明 183 / 不透明 21），**pending 登记 79 条**。

### 3.3 明细页内容结构（每类一式）

- **前缀页**：义项分工（取 V-33/V-35/V-39 原文儿童版，如 in- 两职分列、un- 的「不/做反动作」分列）→ 家族全词表（谓词现算：合并态 morphemes 中该前缀的全部词，A–Z，每词带透明度点与词库中文义）→ 拼写/同化注（V-34/V-37：变体形与双写留痕就地标在词上）→ 易混对手（un- vs in- 页、im- 组内辨）→ 练习（口径见 3.4）。
- **后缀页**：变身机图式（V-36 原文：装上它，词变什么类 + 营业状态灯：通电/半产/封存）→ 全词表 A–Z → 重音班注（S-27：-ic/-ion/-ity/-ial 拽重音，其余中立）→ 易混对手（-able vs -ible 专页，判据与例外带取 V-37 原文；-er 施事 vs -er 比较级分流注）→ 练习。
- **词根页**：词根义与来历（V-21/V-26 原文，\*spek- 页用 Watkins 链）→ 家族全词表 A–Z（每词一句话拆解：前缀义+根义+今义，取自 morphemes 的 gloss 与 note）→ 图式变换注（同根词的义项如何从根义长出，按条目 note）→ 假亲缘警告（本家族的 pending 假命中，如 fer 页挂 ferry）→ 练习。
- **屈折页**（一位一式）：功能位图式（GR-29 原文：一词尾一职）→ 形条目全表 → 拼写让路注（V-37：双写/去 e/y→i/f→v 四格）→ 不规则名单（只列示不拆）→ 与语法区 GR-04（三单幸存者）、GR-28（复数家族）、GR-13（所有格）互链。

### 3.4 练习口径（全区统一，取 V-30/V-39）

1. **零件+语境双通道**：先只给零件让学生猜（对账 V-30 的六成线），再给句子语境猜（八成线），两段分开计分——练习结构本身就在教 V-30 这条规律。
2. **假拆辨伪题**：题源 = 扩充 pending 清单（79 条）与 V-38 三型（butter、corner、listen、understand…），题型为「这个拆法对不对、错在哪一型」。
3. **小集合推进**：按 V-39 排序——先立概念与防假拆，再按义项分课；前缀按 V-33 频次序（un- → re- → in- → dis- → …），不按字母序。
4. 答错回链：每题 hint 指回对应明细页的图式段（与全 App「答错只提示回机制」一致）。

### 3.5 与既有内容的关系（不重复挂接）

- **与拼读区**：拼读区管 grapheme→phoneme（字母怎么读），本区管 morpheme→meaning（零件是什么意思），维度不同。唯一交叠是拼写让路（双写、去 e、y→i 在两区都会出现）：**只在一处立条**——规则正文归本区（源 V-37），拼读区词墙在相关词上加一行互链注，不复制规则文本。
- **与词汇解码区 V 条单元页**：V 条页是「规律机」六步环（讲机制），本区是「零件索引 + 家族词表」（查与练）。同一条规律只在一个地方讲透：本区明细页的讲解段**引用** V 条原文（headline_kid + mechanism），不改写、不另立说法；V 条页的例词反向回链本区家族页。
- **词的唯一出处**：本区一切词表由谓词对合并态 morphemes 现算生成（菜单完整性校验沿用 WORDBANK 规则 6：条目内词全部来自词库、逐词可查 bank_id）；本区不新建任何词条，缺词走补词流程（如 fore-/anti- 等空位前缀的成员词、comfort/fame/nerve 等未入词库词基，均已在扩充数据中登记待补）。
