## 1. 功能定位与范围

### 1.1 定位

自然拼读是规律版**先行落地**的功能块，理由是三条现成条件同时成立：

1. **内容最新最完整**：S 组 43 条 + SR 组 9 条是清单中最近一轮按一手源重挖的簇——GPC 内容层（S-28 – S-42）逐条带口径、带纠正登记，拼写定律区（SR-01 – SR-09）只收可当场判对错的规则，教学序列（TM-33 – TM-35）与中国孩子难点地图（S-43）同批到位；
2. **词库侧天然适配**：词库的 `gpc_patterns` 与 `sight_type` 两个字段就是为本块准备的挂接面，全库回填完成后，本块的全部词集可由谓词机械推导（见 §3.2），不需要另立词表；
3. **闭环最易验真**：拼读的对错可当场判定（读得出、拼得对），误解探针与检查点的设计成本全 App 最低，适合作为其余各区入模的样板波次（对应 DESIGN §4.2 的 W1 波次）。

### 1.2 单元构成（52 个单元）

52 个单元 = S 43 条 + SR 9 条，按教学职能分为六股（股不是菜单层级，只是设计组织；菜单呈现按 §5 与学习路径 §2）：

| 股 | 条目 | 职能 |
|---|---|---|
| 总纲股 | S-01、S-02、S-03、S-04、S-06、S-07、S-28、S-29 | 立「为什么学、学什么」：系统拼读的证据、认词机制（正字法映射、自我教学）、统计倾向观与可预测性账本、44 音坐标 |
| 声音股 | S-05、S-08 – S-14、S-20 | 耳朵侧：语音意识（韵脚→音素）、schwa 与弱读、节奏与句重音、连读、中国孩子音系缺口底座、复合词重音 |
| 辅音股 | S-18、S-30、S-31、S-32、S-33 | GPC 辅音区：可靠区 14 字母、软硬 c/g、二合字母、加厚拼法与哑字母组合清单、-es 垫音节 |
| 元音股 | S-34、S-35 – S-39、S-40、S-41、S-42 | GPC 元音区：短元音默认、五个长音拼法菜单、r 控、双元音组、变脸榜收官 |
| 拼写定律股 | SR-01 – SR-09 | 可判定对错的拼写规则：Magic e、Floss、ck/tch/dge、Cat/Kite、位置规则、尾音节合同价、i-before-e 真相、聚合口诀辟谣、音节切分 |
| 历史与拼写系统股 | S-15、S-16、S-17、S-19、S-21、S-22、S-23、S-24、S-25、S-26、S-27 | 解释层与拼写侧：元音大推移、格林定律、i-变音、哑字母史、拼写三圈（音/形/义）、六音节框架、分堆活动、拼写循环、高频词直认、地层拼写法、后缀重音班 |

六股合计 S 组 42 条；余下 1 条形态特殊，单列：

- **S-43 难点地图（S 组第 43 条，计入 52 个单元）**：九项难点（th、v/w、i 长短、æ 开口、schwa 弱读、词尾浊音与尾辅音、-ng/-n、辅音丛插元音、拼写面）逐项带「错法→成因→处方」，是本块练习与探针的优先级排序依据（按可懂度排序，不按 GPC 表平均用力）。它入模成条，但教学呈现不单独成课：处方落点分散进相关单元（落点表见 §6.4），条目本体在成人层/教师层呈现为全图。

另有**序列三条（TM-33 / TM-34 / TM-35）**不属本块单元：它们是教学层条目，为本块的学习路径（§2）与检查点（§2.4）、读物纪律（§3.3）提供依据，不进孩子的拼读菜单。

### 1.3 与拼读区菜单的关系

- 拼读区菜单 = 本块 52 个单元按 §2 学习路径的 `order` / `prereq` 渲染（DESIGN §5.2），外加由词库谓词推导的**词集屏**：各拼法菜单屏、不规则词表（见 §3.2、§5.3）。单元是「课」，词集屏是「词表」，两者同属拼读区、互相挂接（单元例词点击进词集屏，词集屏的词回链所属单元）。
- 本块在数据总账中对应数据集：规律模型之 phonics 组（模型文件 `model/laws/phonics.yaml`，落盘后以其组建模文档 `phonics_MODEL.md` 为专属文档）+ 词库 `gpc_patterns` / `sight_type` 回填部分。

### 1.4 不做什么（范围红线）

- **不替代词库**：本块不维护任何自有词表；一切词形、音标、释义从词库渲染（WORDBANK 规则 3）。模式的成员词、例外词、不规则词一律是词库词条的标记结果，不是本块文档里的名单副本——本文出现的词例只是说明性引用，施工以词库推导集为准。
- **不分学段**：不按在校阶段切分内容、不设阶段入口；难度只由 §2 的顺序与前置承载（REQUIREMENTS §2 裁定）。
- **不做产出裁定**：发音产出要求（弱读教到什么程度）属未决裁定 A，现行默认 A1（听辨全教、产出只练核心）经 `config_gates` 顶行（DESIGN §3.1）；本块涉及产出的设计（S-09、S-43 排序）不预设裁定结论，裁定落档后只调呈现与练习要求，不改数据。
- **不搬外国学制**：Letters and Sounds 的阶段内容与次序可借，其年龄对应、周数与英格兰筛查词表、分数线不搬（TM-33 边界②、TM-34 边界④）；Phonics Screening Check 只借评估思想（§2.4）。
- **不自产发音事实**：口型、发音动作提示只用清单已核内容（S-43 处方、S-14）；音频来源未定（§7-Q1），音频缺位时不以未经核实的口型描述代偿。

## 2. 学习路径设计

### 2.1 路径依据与借用原则

路径骨架取 TM-33（Letters and Sounds 六阶段）的**推进逻辑**，不取其学制参数：

1. **产出优先开局**：先教一小撮高可靠对应，学完第一组即可拼出真词（Phase 2 的 satpin 逻辑，与 S-30 可靠区、S-29 辅音一致性 96% 的账本互证）；
2. **先一拼一音、后一音多拼**：代表拼法先行落户（Phase 3），替代拼法与替代读法后置成系统（Phase 5）——与 S-35 – S-39 菜单「主力先行、小路后学」的内部结构同构；
3. **中间设巩固段**：新对应暂停、专练辅音丛与多音节拼合（Phase 4），正对 S-43 难点⑧（辅音丛插元音）与 TM-34 筛查词表约 24/40 含辅音丛的设题结构；
4. **末段转攻拼写**：解码立稳后，拼写定律（SR 组）与拼写策略成主线（Phase 6）。

同时叠加两条本块特有的排序约束：

- **S-43 优先级**：同一阶段内，涉及难点九项的单元与练习排前、练量加重（可懂度纲：元音三项与 th 权重最高，见 S-43 支撑栏）；难点处方的「听辨先行」要求（难点③）落实为：相关单元的练习序固定为先听辨、后产出。
- **TM-35 的忠实执行原则**：五家队列互不兼容，本路径只取 L&S 一家的次序作骨架，其余四家（RWI 的 Fred 机关、Jolly 的动作歌曲、Spalding 的 70 卡全音同教、Sounds-Write 的音→拼方向、UFLI 的课次表）只作机关层借鉴登记，不拼凑队列（TM-35 边界①）。

### 2.2 阶段与顺序表

全路径 8 个阶段。`order` 为区内默认序（落到条目 `order` 字段），`prereq` 只记结构性前置（无前置者可并行进入）；同一阶段内按 `order` 推进，跨阶段须经 §2.4 检查点或等效练习达标才解锁下一阶段的首单元。

| 阶段 | 名称 | 单元（按 order） | 前置与解锁关系 | 对应 L&S |
|---|---|---|---|---|
| P0 | 耳朵先行 | S-05 → S-10 → S-11 | 无前置（全块入口）；解锁 P1 | Phase 1 |
| P1 | 可靠区开局 | S-30（首批：s a t p i n m d 等高产出组）→ S-34 → S-01（成人层主读，孩子面作激励屏） | 前置 P0 的韵脚/首音意识；学完首批对应即拼真词 | Phase 2 |
| P2 | 辅音全图 | S-30（余部）→ S-31 → S-32 → SR-04 → SR-02 → SR-03 → S-18 → S-33 | 前置 P1 短元音与拼合；ck/tch/dge 须在短元音立稳后（SR-03 判据） | Phase 2 后段 – Phase 3 |
| P3 | 巩固与音节盒子 | S-22 → SR-09（闭/开两型先行）→ S-25（高频直认词首批） | 前置 P2 全部单拼对应；本阶段不教新对应，专练辅音丛、多音节拼合与直认词 | Phase 4 |
| P4 | 五个长音菜单 | SR-01 → S-35 → S-36 → S-37 → S-38 → S-39 → SR-05 | 前置 P3 的开/闭音节对立（Magic e 是其拼写面）；菜单按音位逐个解锁，前一菜单达标开下一菜单 | Phase 5（VCe 与菜单部分） |
| P5 | r 控与双元音 | S-40 → S-41 → S-20 | 前置 P4 元音菜单骨架；r 控须在 ar/or/er 基础拼合后 | Phase 3 尾声 + Phase 5 |
| P6 | 变脸榜收官 | S-42 → S-06（收官重读）→ SR-07 → SR-08 | 前置 P4/P5 全部菜单（变脸是菜单的全谱面，无菜单基础不进）；S-29 账本在此阶段向孩子面开放简化版 | Phase 5（替代读法部分） |
| P7 | 长词与拼写系统 | SR-06 → SR-09（VCV 切分全量）→ S-23 → S-24 → S-27 → S-26 → S-21 | 前置 P6；历史解释层（S-15、S-16、S-17、S-19）不设独立序位，随相关单元的成人层与「为什么」角挂接呈现（knight 挂 S-33/S-19、find 族挂 S-37/S-15） | Phase 6 |

未列入主线序位的条目（S-08 schwa、S-09 弱读、S-12 连读、S-13 可懂度、S-14 难点底座、S-02/S-03/S-04/S-07 认词机制）如下落位：S-08/S-09/S-12 随 P5 之后的句中语音练习以「语音角」形态并行开放（前置 = P1 拼合立稳）；S-02/S-03/S-04/S-07 与 S-13/S-14 为成人层/教师层主读条目，孩子面只以一屏激励或提示形态出现，其 `order` 置于所属阶段之首。S-43 同样不占序位：其九项处方随相关单元的机制与练习落实（落点表见 §6.4）。

### 2.3 顺序的校验口径

- 每个单元的 `prereq` 必须能在上表中找到依据；表中没有的关系不许在条目里私设（改路径先改本文 §2.2 并过评审，见 SOP §6）。
- 阶段内「先听辨后产出」仅约束涉 S-43 难点的练习序，不构成新的前置关系。

### 2.4 PSC 式检查点（纯解码探针）

借 TM-34 的评估思想：用**伪词切除词汇记忆通道**，只量「代码知识 + 拼合技能」一维。设三个内部检查点：

| 检查点 | 位置 | 构成 | 达标线（内部口径） |
|---|---|---|---|
| CP1 | P3 末 | 20 题：真词 10 + 伪词 10，限已教对应（单拼 + 二合 + 辅音丛） | 16/20 |
| CP2 | P5 末 | 40 题：真词 20 + 伪词 20，含长音菜单、r 控、双元音 | 32/40 |
| CP3 | P6 末 | 40 题：真词 20 + 伪词 20，含变脸榜组合的**词族内**选读与菜单全谱 | 32/40 |

口径声明（必须随检查点一并登记，不许省略）：

- 题量与真伪各半的结构借自 Phonics Screening Check（40 词、20 真 + 20 伪、达标线 32，TM-34 定版）；CP2/CP3 的 32/40 是**按同一比例设的本产品内部线**，不是英格兰分数线的平移，词表自建（只用已教对应拼合，伪词生成约束见 §7-Q5 与 PHONICS_SOP 步 7），分数线的本土校准属未决问题（§7-Q3）。
- 检查点只测解码一维：**不达标的处置是回补对应单元，不给孩子贴标签**（TM-34 分歧栏两造共识：结果须结合教学判断使用）；达标也不等于阅读达标（解码 × 语言理解，TM-34 边界③），家长角呈现检查点结果时必须带此说明。
- 变脸组合（ough 等）不进伪词题：无规则可拼的组合用伪词测的是运气不是技能；CP3 对变脸组只测「词族内选读」（给出词族、选对读音），与 §4.4 变脸榜类闭环一致。

## 3. 核心数据对象

本块的数据对象四件：**模式注册表**（GPC 模式清单）、**词集推导**（词库谓词）、**可解码文本约束**、**错形展示资产**。四件都不是新数据源：模式注册表是 S/SR 条目内容的索引化，词集是词库的视图，文本约束是元数据规范，错形资产在探针库登记。

### 3.1 GPC 模式注册表（模式清单的组织）

模式 = 一条「字素 → 音位」的对应，是菜单与词集的最小单位。注册表字段（落盘形态随 DESIGN §8-Q1 的格式裁定，现按 YAML 组织于本组建模文档与 `phonics.yaml` 的模式段）：

| 字段 | 说明 |
|---|---|
| `pattern_id` | 稳定编号，形如 `GP-<字素>`（如 `GP-ai`、`GP-ough`、`GP-ck`)；与词库 `gpc_patterns` 的取值严格一致，永不复用 |
| `grapheme` | 字素（单字母、二合、三合、分裂二合如 `a-e` 记为一个模式） |
| `phoneme` | 音位（**RP 口径标音**，与清单 S-28 – S-42 立条口径一致；GA 差异只进 `note`，不另立模式） |
| `position` | 位置条件：词首 / 词中 / 词尾 / 音节条件（如「紧跟重读短元音后」），无条件的记 `any` |
| `syllable_context` | 依赖的音节型（闭 / 开 / VCe / r 控 / -le），无依赖记空 |
| `reliability` | 可靠度类：`rule`（条件成立即成立）/ `tendency`（倾向，带例外队）/ `roster`（无规则、整组记，如 ough 各读、o 孤组）——与 claim 分型对齐，`tendency` 必须挂例外清单 |
| `exceptions` | 例外词 id 清单（只引词库 id；例外本身也是词库词条，带本模式的「不适用」判定，见 §3.2) |
| `source_laws` | 定义本模式的条目 id（S-3x / SR-0x)，一个模式可由多条共定（如 ck 由 S-33 与 SR-03) |
| `menu` | 所属菜单屏（音位菜单 / 辅音区 / 变脸榜 / 不规则表），决定呈现位置 |

组织原则：

- **音位坐标先行**：模式全集的行数由 S-28 的音位表决定（RP 44 = 教学坐标，非自然常数；分歧只进成人层）。辅音区以 S-30 – S-33 为全集：可靠单字母 14 个（+j 近专职，共 15 个教学项，**不得写作 16**)、软硬 c/g、二合字母（ch 三音、th 清浊两班按分工拆成模式）、加厚三件套与哑字母组合；
- **元音区以菜单为骨架**：S-34 短元音 5 个默认模式；S-35 – S-39 五个长音各成一组模式（主力/次要由条目内分级标注，不另设字段）；S-40 r 控（含 w 后改道组）、S-41 双元音组的位置分工（oi 词中 / oy 词尾等）写进 `position`，不立新模式；
- **变脸榜是模式的全谱视图**：S-42 的六组（ough、ea、ou、a、y、oo）不是新模式，而是把同一字素的全部读音模式并排成榜，排序口径固定为**读法数 × 不可预测度加权**（S-42 定版：ough 常用 8 读 / 全谱 10 读居首，ea 本体 4 读 / 含 ear 家族 7 读第二，ou 重读 6 读 + 非重读 1 读第三，a 全谱 8 读但线索多列第四，y 4 读第五，oo 3 读第六）——计数必须带口径（常用/全谱、是否计弱读），呈现与文案禁用裸数字；
- **定律类模式**（SR 组）与读音模式分开登记：Floss、ck/tch/dge、Cat/Kite、位置规则、尾音节合同价是**拼写方向**的格局（音 → 拼），在注册表中以 `direction: encode` 标注，与解码方向（拼 → 音）的模式同表不同向，词集推导时按方向取词（见 §3.2）。

### 3.2 词集推导（菜单全量呈现的实现）

词集不存名单、只存谓词（DESIGN §5.1、WORDBANK 规则 6）。本块的推导规则：

1. **回填先行**（DESIGN §2.2 的 W1 职责）：对词库全部词条逐词判定——`gpc_patterns` = 该词拼写实际命中的全部模式 id（一个词可命中多个模式，进每个对应菜单）；命不中任何已立模式的词显式判空数组（=已判定），不许留未判定状态；`sight_type` 同步全量判定（`decodable` / `irregular`，判定依据 = 是否可由已立模式 + 位置条件完整拼出）。
2. **模式词表** = `{词条 | pattern_id ∈ 词条.gpc_patterns}`，由生成器现推；菜单屏呈现的即此全集（§5.3），单元 `examples` 只从全集中按分级取样，不反向定义全集。
3. **不规则词表** = `{词条 | sight_type == irregular}`；其中「部分不规则」（只错一处，如 said 的 ai）按 S-29 账本的「错一处」层单独成组呈现，词条以 `sight_type` + 不规则部位注记区分（注记字段口径在组建模文档定版）。
4. **例外词的双向登记**：模式的 `exceptions` 与词条的模式判定必须一致——例外词不挂该模式（挂的是它的实际读音模式），但在模式屏的「例外队」位置呈现，数据上由模式 `exceptions` 引其 id。校验时两边对账（SOP 步 3）。
5. **拼写方向词集**：定律类单元的词集 = 满足该定律位置条件的全部词条（如 Floss 词集 = 单音节 ∧ 短元音 ∧ 词尾 f/l/s/z 紧贴），条件写进条目的谓词注记，由生成器按词形与音标机械筛 + 人工裁定边界词，裁定结果回填为词条的模式挂接，不另存名单。

### 3.3 可解码文本的词约束

主线读物与句级练习文本（下称受控文本）的选词纪律（据 TM-34):

- **约束定义**：文本中每个词须满足其一：(a）其全部模式 ⊆ 该文本所属阶段已教模式集（按 §2.2 阶段累计）；(b）在该阶段的直认词名单内（S-25 高频词，按阶段分批，其 `sight_type` 多为 irregular 或含未教模式）；(c）专名与句式占位符——按 DESIGN §8-Q5 倾向口径登记豁免，不进词库、不计入比率分母。
- **比率登记（「>90%」口径的登记方式）**：每份受控文本落盘时必须带元数据 `{stage, taught_set_version, decodable_ratio, tricky_words_used}`，比率 = 满足 (a) 的词次 / 全部实词词次，机械计算、不许手填。口径声明随元数据固定登记：**研究界对可解码率无共识门槛**（Blevins 的操作口径为过半即可，TM-34 边界②;Cheatham & Allor 2012 综述指其独立效应证据不一致）——「>90%」是严格一端出版商的自标口径，本产品**自选**主线读物 P1 – P3 阶段的写作门槛为 ≥90%(P4 起 ≥80%，因菜单替代拼法进入后 (a）口径自然放宽），该数字只作本产品内部写作闸门，**不许在任何呈现或文案中宣称其为研究结论或行业标准**。
- 受控文本与序列必须**同表**：换序列即比率作废重算（TM-34 边界②：百分比脱离具体 GPC 序列表没有意义）。

### 3.4 错形展示资产

探针与练习中故意呈现的错拼（blu、hav、littl、furnitures 型）是设计资产，已在探针库以 `error_form_display` 登记（`model/laws/probes.yaml` 文件头注与条目字段）。本块规则：

- 错形**不进词库、不算例词、覆盖校验豁免**（DESIGN §3.6、§6-V3 注），但必须逐个登记来源（哪条探针/哪道练习、错因是什么），未登记的错形按库外词处理、校验阻断；
- 本块自产练习若需新错形，先在探针库或练习规格中登记再使用，登记格式与探针库一致；
- 错形只许出现在「辨错/选对」语境并即时给出正形，不许在例词榜、菜单屏等正形呈现位置出现。

## 4. 六步闭环在本块的实例化

六步骨架以 REQUIREMENTS §4.3 为准（医院 → 机制 → 总结 → 例证 → 练习 → 复习归档），本块按单元类型分三类实例化。五种交互件在三类中的落点先总表，后分述：

| 交互件 | 定义 | 主要落点 |
|---|---|---|
| 听辨 | 最小对立听选（ship/sheep 型）、听音指字素 | 机制步导入、练习步第一题型；涉 S-43 难点单元强制前置 |
| 拼读 blending | 字素逐个出声拼合（慢速连读、由尾及首反向连滑用于辅音丛） | 机制步演示、练习步主 题型 |
| 分割 segmenting | 听词数音、逐音指认（手指计数法登记在案，机关来源 TM-35 Fred Fingers） | 拼写方向单元（定律类）的机制与练习 |
| 伪词关 | 读自建伪词（只含已教模式，§3.5 生成约束） | 检查点（§2.4）与菜单类练习的迁移题 |
| 拼写回写 | 听词写形：切分 → 按模式/定律选拼 → 对照正形 | 定律类练习主 题型、每单元收尾题 |

### 4.1 菜单类单元（S-34 – S-41 各菜单、S-30 – S-33 辅音各条）

1. **病句医院**：误读病例开场——把菜单的典型读错摆出来（如 ea 一律读 /iː/ 把 bread 读错；ough 见词乱猜），病例取自条目 `error_cases`（来源类型必填，多为登记错型与 S-43 难点项）；
2. **动画讲机制**：菜单成形过程——一个音位、多条拼法路逐条点亮（主力大路先行、小路后到），位置分工以词在屏上的落位演示（ai 站词中、ay 站词尾）；辅音类则演分工与变软/加厚的触发条件；
3. **一屏一总结**：菜单卡（音位 + 全部拼法 + 每拼法一个锚点词）+ 亲戚网（同音位邻居菜单、变脸榜回链）；
4. **分级例证**：按拼法分道、道内由高频到低频分级（≥2 级、每级 ≥2 例，REQUIREMENTS §4.4），例词只引词库 id，展示从词库渲染；全量词集在菜单屏（§5.3），例证只是教学取样；
5. **检索练习**：听辨（选对读音）→ blending（读真词）→ 伪词关（用本菜单拼法读没见过的词，测迁移）→ 收尾一题拼写回写（听词选拼法写出）；答错只给回机制提示，指向菜单的具体一道（哪条拼法路）或位置条件；
6. **间隔复习 + 病因归档**：错题按错因归档（错因分类与 S-43 难点项对齐：如「ea 主场误植」「词尾加厚未用」），复习时同因成组回放。

回补点：本类已有探针的单元（S-36）练习答错达量规「中招」时，插入对应探针（PRB-S36-1 – 5）做诊断，再按探针 `remedy` 指回机制屏的指定小节（菜单边界注 + S-42 对照）复测；无探针单元按同型回补（指回机制小节）并在入模时补写探针（SOP 步 6）。

### 4.2 定律类单元（SR-01 – SR-09）

1. **病句医院**：拼写错例开场（*paniced 的 k 漏插、*hav 的护栏 e 丢失、*bak 的 ck 缺位），病例须为登记错型（中国学生高频错型优先，S-43 难点⑨）；
2. **动画讲机制**：规则的**条件**逐个点亮（如 Floss 四条件逐项打勾、SR-03 的「紧跟重读短元音后」判据演示），规则本体后置——先看条件、再给结论，防止口诀字面化；
3. **一屏一总结**：定律卡（规则一句话 + 条件清单 + 例外队名单），例外队与规则同屏同字号，不许小字藏匿；
4. **分级例证**：守规队与例外队对照分级呈现（每级两队各 ≥1 例），例词引词库 id；SR-01 的五职按职分级（每职一例组），并注明「五职是教学节选、原表九项」在成人层（孩子面只呈现节选声明的一句话版）；
5. **检索练习**：判断题（给词判守规/例外并点出命中的条件）→ 拼写回写（听词写形，定律类主 题型）→ segmenting（数音定拼）；答错提示指回**未命中的那个条件**，不给正字；
6. **间隔复习 + 病因归档**：错因按「哪条定律的哪个条件」归档（如「SR-03 判据误用：把单音节当判据」）。

回补点：SR-01 已有探针（PRB-SR01-1 – 5，如「e 只会变长」的过度泛化探针），回补路径 = 机制屏的对应职小节 + 例外队复看；SR-07 的回补须区分三层（裸口诀/限定版/射程误用），提示文案不得把 weird 讲成限定版的例外（SR-07 边界③）。

### 4.3 变脸榜类单元（S-42，及 S-06 的名单部分）

1. **病句医院**：过度规则化病例（把 though 按 ou+gh 的「常读」硬拼、把 ea 一律读 /iː/）；
2. **动画讲机制**：不讲规则、讲**归队**——同一字素的词按读音逐个入队（-ought 队整队 /ɔːt/、/ʌf/ 队 rough/tough/enough），演「变脸发生在队与队之间、队内整齐」的内部秩序；
3. **一屏一总结**：榜单卡（名次 + 每组读法数，**带口径注**：常用/全谱与计数范围，见 §3.1）+ 每队锚点词；
4. **分级例证**：按队分级，队内全量词（变脸组的词集即队名单，由词库推导、与 S-42 条目词例对账）；
5. **检索练习**：分堆（word sort，S-23：给词卡按读音归队）→ 队内读词 → 新词归队判断（给一个未学词，选它最可能进哪队并说依据）；**不设伪词关**（无规则可迁，见 §2.4 口径）；答错提示指回该词所属队的锚点词；
6. **间隔复习 + 病因归档**：错因按「哪一组字素、错入哪队」归档。

回补点：已有探针（PRB-S42-1 – 5，含「反向误读：-ought 也不敢归队」的迁移探针），回补 = 机制屏对应队 + 用未学过的同队词（fought/sought 型）复测迁移。

### 4.4 三类共用规则

- 每单元练习的最后一题固定为**回写或归队型**（产出侧），不许全单元只有选择题；
- 答错提示一律指向 `mechanism` 的具体小节（DESIGN §3.1 `quiz` 字段），三类皆然；提示出现两次仍错，触发探针诊断（有探针的单元）或标记病因待复习（无探针的单元）；
- 涉 S-43 难点的单元，机制步前加一屏**听辨导入**（最小对立对先行），此屏不计入六步步数。

## 5. 呈现与交互要点

### 5.1 音形呈现规范

- **音位标音以 RP 为准**：音位名、菜单读音、模式 `phoneme` 一律用清单立条的英式口径（S-28 的 44 坐标、S-35 – S-42 的英式菜单）；美式差异（GA 元音切法、r 控的 /r/ 显形、yod 脱落等）只进成人层与边界注，**同一屏内不许英美混编**（S-28 边界、S-40 边界④）。
- **词条音标从词库渲染**：单个词的音标不由内容侧手写（WORDBANK 规则 3）；词库音标的英美口径未统一是词库评审的已登记缺口（WORDBANK_MODEL §6)，与本块 RP 立条之间的张力登记为未决问题（§7-Q2)，裁定前菜单屏的音位标音用模式 `phoneme`、词例音标用词库值，两者冲突的词在组建模文档登记清单、不许静默取舍。
- **字素呈现**：字素用下划线/色块标出在词中的位置（sound buttons 式打点与下划线标记法可借鉴——归属须注正：该标记法是 Letters and Sounds 系课堂通用法，**不是** RWI 的装置，TM-35 边界③）；二合/三合字母必须整体成块呈现，不许逐字母拆色。
- **发音提示的边界**：口型与发音动作提示**只许**用 S-43 处方与 S-14 已核内容（如 th 的舌尖探出齿缝、v 的上齿咬下唇、æ 的开口度阶梯、/ɪ/-/iː/ 的时长手势、词尾浊音的元音时长线索），每条提示在条目成人层可回指来源；清单之外的口型描述、发音口诀一律不用。真人口型图/声墙式音位图（TM-35 支撑栏的 Sound Wall / vowel valley）可作 §5.3 总览屏的设计蓝本，图源与授权未定前只用示意规格占位（§7-Q1)。

### 5.2 听辨与产出的呈现档位

- 听辨材料（最小对立对、词表）只用已教模式内的词 + 本阶段直认词，选词规则与 §3.3 同表；
- 产出要求按裁定 A 的现行默认 A1 呈现（`config_gates`):S-09 弱读等现象听辨全呈、产出标「认识即可」；档位切换只改练习的达标判定，不改屏面内容构成。

### 5.3 菜单屏信息架构

一个音位一张菜单屏（五个长音 + 短元音组 + r 控 + 双元音组），辅音区按 S-30 – S-33 分屏，变脸榜独立成屏。单屏结构自上而下：

1. **音位头**：音位标音（RP）+ 一个锚点词（图 + 词，词引词库 id）+ 本屏在路径中的位置（阶段与前后菜单）；
2. **拼法道**：每条拼法一道，主力道在前（大字、宽道）、次要道在后（窄道），道头 = 字素块 + 位置注（词中/词尾/紧跟短元音后等），道内 = 该模式**全量词集**（§3.2 推导集）按频分段滚动，锚点词置顶；
3. **变脸角**：本屏字素若在变脸榜有全谱面（如 ea、ou、oo)，屏角固定挂变脸榜回链与本字素的读法数（带口径注），防孩子把菜单主场当唯一读法（PRB-S36-1 的误读正源于此）；
4. **例外队**：本屏各模式的例外词成队呈现（队名即例外类型：词源型/条件不成立型不混列，SR-02 边界口径）；
5. **成人层开关**：同屏展开出处、边界、分歧（DESIGN §3.7)，含本菜单的口径声明（计数口径、英美差异）。

总览屏（拼读区首页）= 音位地图：辅音按发音部位×方法排布、元音按舌位排布的声墙式布局（蓝本见 TM-35 支撑栏），已解锁音位点亮、未解锁置灰，点任一音位进其菜单屏；总览屏只做导航，不承载教学内容。

## 6. 验收标准（本块上线门槛）

本块的上线 = 52 单元全部达「已入模」且下列门槛全过（与 REQUIREMENTS §7、DESIGN §6 对齐，本节只列本块的具体化口径）：

### 6.1 数据零差类

- **模式词表零差**：每个模式的呈现词集与 §3.2 谓词推导集逐词比对，差集为空（DESIGN §6-V4 在本块的实例）；
- **例词覆盖零缺口**：52 单元的例词、例句、练习题、探针题、受控文本用词逐词比对词库，库外词清单为空（V3；错形展示登记项除外）；
- **挂接闭包**：条目引词 id 全部可解析、词条 `law_refs` 与条目引用双向一致、模式 id 全部在注册表内（V5）；
- **回填全量**：全库 1,959 条的 `gpc_patterns` 与 `sight_type` 判定无未判定项（空数组 = 已判零命中，不是未处理）。

### 6.2 条目规格类

- 52 条全过 schema 与分型硬门槛（V1/V2)：S-06、S-29、S-42 等 tendency 型断言例外齐备且措辞无绝对化（V6)，SR-08 的辟谣对象（聚合口诀）只许出现在纠正语境；
- 每单元六步素材齐备（V7)：病例 ≥1 且 `source_type` 为登记错型、例证 ≥2 级、测验含回机制提示、成人层出处可核、探针 ≥1（本块现成探针仅覆盖 S-36、SR-01、S-42 三单元，其余 49 单元的探针在入模步 5/6 补齐，缺一不上线）；
- 数字口径复核：PSC 40/32、ough 8/10、ea 4/7、ou 6+1、Clymer 45%/63%、Hanna 49.9% 账本、可靠辅音 14(+1）等定版数字在全部屏面与文案中逐处与条目定版一致（核对表见 SOP §5)。

### 6.3 路径与检查点类

- `order`/`prereq` 与 §2.2 顺序表逐条一致；CP1 – CP3 的题库建成且每题可回指已教模式集，达标线与口径声明随题库登记；
- 受控文本全部带 §3.3 元数据且比率达本阶段写作门槛，比率可由工具复算。

### 6.4 难点对策类

- S-43 九项难点逐项有落点：每项至少在一个单元的机制或练习中落实其处方（落点对照表随组建模文档交付，九项无一落空）；涉难点单元的「听辨先行」屏齐备；
- 接地气清单（REQUIREMENTS §3.3）逐项勾验：例词例句场景、病例真实性、学术词只进成人层、每单元落到「孩子今天能说/能做的一件事」。
