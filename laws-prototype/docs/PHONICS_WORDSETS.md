## 2. 判定方法（双条件 + 音节对齐）

1. **拼写侧**：把词形按最长优先切成字母块（ough/eigh/igh/air/are/ear/eer/ere/oor/ar/er/ir/or/ur/all/alk/tch/dge、双字母组合、单字母），词尾 VCe 分体组合（a-e 等）合并为一块。
2. **读音侧**：把词库 phonetic 切成音素（含 tʃ/dʒ 整体、二合元音整体），提取元音单位并传播重读标记。
3. **对齐**：字母块中的元音块与音素元音单位做保序 DP 对齐——允许：词首辅音性 y/w 块跳过、词尾静音 e 跳过、音节性辅音前的 e 跳过（garden 型）、可分读组合一块对两单位（oe/ie/ia 等）、三合元音与相邻 schwa 合并、j+元音合为 /juː/ 单位。对齐失败且含变脸组合的词进待裁定，不硬塞。
4. **命中**：某元音块对齐到的音素 ∈ 该模式的读音集（r 控模式另核对后随 r），且模式的位置/条件成立（如 c 软音须后随 e/i/y、floss 须紧跟重读短元音、wh→/h/ 仅限 who 一家、-stion 不进 -tion 等条件均按清单定版编码）。辅音模式按字母块+音素 token 双条件（成音节/静音团队按定版名单与音素缺失核对）。
5. **多读拆分**：变脸组合按读音拆子模式（ea→/iː/ 与 ea→/e/ 分开；ough 按 S-42 定版拆 8 面 + hiccough；ou 拆 7 面；oo 拆 3 面等）。同一词的不同字母块可命中多个模式；同一块只进读音相符的子模式——如 great 的 ea 读 /eɪ/，只进 ea→/eɪ/，不进 ea→/iː/。
