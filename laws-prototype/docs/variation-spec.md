# 变式表规格（例句补齐的可执行口径）

生效：2026-11-04，学习改善·阶段 2 首波定版。来源：Stewart 例句规矩（2026-11-03：每讲一个概念至少 10 个例句展开、例句承载解释、例词不顶替例句）+ 深挖分析 §3.2（变式理论）+ CO 补例试点口径。本规格约束此后全部规律例句补齐波次（GR/TA 首波用 `tools/fill_grta_examples.py` 落地）。

## 1. 每律先定变式表，后生例句

补任何一条律之前，先在波次报告附录里写下该律的变式表，三件套：

- **可变维度**：这条律的概念允许在哪些维度上变化——主语人称/单复数、时态、句式（肯定/否定/疑问）、语域、被演示的形式点（元规律）等，逐项列明；
- **不变内核**：无论怎么变都不许变的东西——该律的目标结构本身（如 GR-02 的「标记只落一次」）；
- **边界**：反例与似是而非——形式相近但不属于本律、或属于本律但容易被误判的句子，单独成组呈现。

例句照表生成：每个可变维度至少被一组例句实际演示到，不许只在组名里声称。

## 2. 数量与分组

- 每律例句 **≥10 条**（病例 wrong→right 不计入例数）。
- 小律（实有维度铺不满 10 条，如证据评议型、历史来源型）按实有维度铺满，并在波次报告中逐律注明「铺满数 + 理由」，不许硬凑同构句充数。
- 全部例句**分组呈现**（分组率 100%），**组名说破在变什么**（如「换主语：I 换成 he」），不许用「例句一/例句二」式空名。
- 每律至少 **1 个边界组**（组名或注中明示边界/易混/对照性质）。

## 3. 来源三通道（零自由编造，逐句登记 `src`）

| 通道 | 记号 | 口径 |
|---|---|---|
| 原例保留 | `orig` | 条目原登记例逐字保留，只许加 `grp` 分组与 `src` 标记，`s`/`note`/`words` 一字不改 |
| 自有材料复用 | `own` | 该律自有材料（病例 right 句、练习题干/答案句、yaml 例句、本律机制登记句）中已有、但未进例句列的完整句；脚本断言该句逐字存在于该律自有材料中，出处登记进 `src.ref` |
| 机械组句 | `gen` | 句框取自该律登记例句或 App 登记材料（`src.from` 逐项注明），槽位词只许出自词库（wordbank）与动词五形式表（verb_forms_completion）；动词形态由句框的人称/时态要求决定，脚本逐句校验形态与五形式表一致（三单/-ing 表内未立条者按拼写规则派生，与 CO/gen_interact 先例同口径） |

词典例句通道（ECDICT 例句字段）在本工作区实测为空，产出为 0，沿 CO 试点登记结论，不再重复试探。

## 4. 注（note）口径：只许孩子白话

- 每例必有注，只讲「这句在演示什么、注意看哪里」，用孩子能懂的话。
- **生产腔零容忍**：注与病例 diag 中不许出现登记 / 纲领 / coreView / 源： / 裁定 / 口径 / 待补 / 命中 / 归一 / 标志性原例 / 学术出处等生产侧词汇（完整扫描表见各波校验脚本）。出处信息只进 `src` 数据字段，不出镜。
- 学术来源、历史掌故如需提及，写进成人层字段（yaml adult / lawdata aud），不进注。

## 5. 雷同判定（同构合并）

- 把句子中的**人名、地名替换为占位符**后，骨架完全相同的句子计为 **1 例**（如 "Tom plays football." 与 "Sam plays football." 只计 1 例）。
- 每律达标计数以**合并同构后的有效例数**为准；脚本按此口径复算并在报告中登记有效数与表面数。
- 换主语人称（I/he/they）、换时态、换肯定/否定/疑问**不算同构**——这些是变式表上的真维度，骨架判定只吸收人名/地名替换。

## 6. 锚词（words / word_ids）

- LAW 通路例句的 `words` chips：锚词全部命中词库，音标/释义逐字取词库登记值，脚本生成不许手写。
- yaml 通路例句的 `word_ids`：取 words_master 中该句内容词的 id（按句序、去重）；词库/总表无此词 id 的（如专名 beijing，按专名口径不入词库）不硬凑，缺 id 为可接受终态，沿 TA-05 既有登记。

## 7. 落位与校验（每波必过）

1. 事实源先行：LAW 通路改 `model/laws_master.json` 的 lawdata 分仓 → `tools/gen_laws.py --write` 同值落主文件 LAWDATA 镜像；yaml 通路改 `model/laws/*.yaml` 上游源与总表 yaml 分仓同值（`check_upstream` 链 a 把关）；非 LAW 通路的显示镜像（如 TN 内嵌 DATA）由波次 fill 脚本同值写入并在报告中登记落点与渲染差异（如 TN 渲染不呈现分组标题时，分组只落数据层，登记待渲染波）。
2. 原例保留对差：改前原例集合 ⊆ 改后例句集合（逐字）。
3. 逐律计数：例数（有效数）≥10 或铺满注明、分组率 100%、边界组 ≥1。
4. 英文质量抽检：随机 30 句脚本校验（词表/形态）+ 人工通读无病句。
5. 注行话扫描 = 0（§4 扫描表）。
6. `tools/check_all.py` 12/12 全绿；题池 sha256 不变（补例不动 quiz/prb/cases，池构成不应变化；若变，停工报告，不许静默接受）。
