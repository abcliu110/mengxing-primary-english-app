# 萌星英语 · 规律版——产品需求文档（定稿 v1）

定稿日期：2026-11-01。本文件整合《App 原型定义 v1》与 2026-11-01 当日全部用户裁定；两者冲突处以裁定为准，文中标注「裁定覆盖」。本文件只写需求口径（产品要什么），不写技术实现。配套文件：词库规则 `../model/WORDBANK.md`、数据总账 `../model/README.md`。

## 1. 产品定位与一句话价值

给学英语的孩子的一台英语「规律机」：**不背清单，学解码**——每个知识点都讲清机制、给得出边界、治得了一个真实的病。

- 本产品是**完全独立**的新产品，与既有 App 不合并、不做原地升级；既有 App 是另一条产品线。（来源：用户裁定 2026-11-01）
- 产品的核心资产不是题库数量，而是经专家出处核验的规律知识与其教学闭环。

## 2. 用户与使用场景

- **主用户**：学英语的孩子，自学为主、家长陪学为辅。**不分学段**：内容不按在校阶段切分，难度由各区内的学习顺序与前置关系承载，孩子按顺序推进即可；不设阶段入口、不按教材年级切分内容。（来源：用户裁定 2026-11-01；裁定覆盖定义底稿原「延伸段」表述）
- **次用户**：家长与教师——看机制原文、出处、证据等级与分歧登记。呈现分两层：孩子层大字讲机制，成人层小字给出处与边界。
- **场景**：家庭碎片时间为主，单次 10–15 分钟完成一个学习闭环；课堂辅助为次。

## 3. 内容来源与质量标准

### 3.1 出处四通道（内容准入）

任何进入本产品的知识，必须能溯源到以下四类来源之一，并留可核查的出处（专家姓名 + 著作/篇目 + 可达链接或页码）：

1. **经典书籍**——领域内公认的专著与经典教材；
2. **经典理论**——语言学、认知科学、学习科学的经典理论原典；
3. **经典网文**——作者实名、被长期引用的专家长文（经典性须有证据：署名专家 + 长期被引；营销号、SEO 内容不算）；
4. **英语教学专家**——公认教学专家与一线名师的公开论述。

民俗口诀、培训机构自创口诀不得作为出处。没有出处的内容不入产品。

### 3.2 内容三步工序

每条知识按固定工序生产，不得跳步：

1. **深挖**：回到一手源核对原文，不采二手转述；
2. **总结理解**：提炼到机制层面的理解（为什么、怎么运作、边界在哪），条目之间互相关联，不做孤立摘抄；
3. **深入浅出展示**：在 App 内以机制 + 边界完整保留的前提下，用孩子能懂的方式呈现。

### 3.3 接地气四条（展示层验收口径）

1. 例词例句取材于中国孩子真实的学习与生活场景、现行教材语境；
2. 病句医院的病例取自中国学习者真实错误类型，不许编造病例；
3. 从具体场景出发讲机制，学术术语只出现在成人层小字，不压孩子层；
4. 每条规律必须落到孩子今天就能说出口、用得上的一句话或一个动作。

### 3.4 分歧与待核纪律

- 专家之间有分歧的，登记为「学界分歧」如实呈现，不许私下裁决、只取一说充数；
- 无法核实的内容隔离为「待核」，宁可留空标注，不许猜测填充；
- 禁止编造引文、出处与统计数字；民间说法与已被证伪的讲法只许出现在「纠正」语境中，并标明其性质。

## 4. 功能需求

### 4.1 信息架构：六大区 + 复习区 + 家长角

| 区 | 内容来源（清单组别） | 条目数 | 招牌件 |
|---|---|---|---|
| 拼读区 | S + SR | 52 | 长元音拼法菜单、变脸榜、拼写定律区（Magic e 九职等）、拼读序列主线、中国孩子难点地图 |
| 词汇解码区 | V | 45 | 词根家族树、变身机（词缀）、打包错位对照台、假词源侦探、同源对配对 |
| 语法区 | GR / TA / CO / QI | 95 | 总纲置顶、反意疑问三步法、get 五构造 |
| 小系统区 | P / PB / C / PR | 63 | 介词花园（多义网络）、冠词三出口、汉语刀口对照 |
| 表达写作区 | E / W / NE | 59 | 整块取句、范文先行、语义韵选词 |
| 复习区 | 由各单元病因错题与间隔队列供血 | — | 间隔队列、病因错题本、提取自测 |
| 家长角 | 全部条目的成人层 | 全量 | 机制原文、出处、证据等级、分歧与待核如实呈现 |

另有 114 条支撑知识（教学法、学习科学、少儿研究、语料库等）不直接上孩子的菜单，作为讲解口径、成人层与产品设计的依据，其中教学法条目的教师侧技巧随技巧库管理。

### 4.2 入口（两面）

- **痛点入口**：记不住 / 听不懂 / 说不出 / 写不长 / 读不快 / 错不完——从孩子的实际困难进入对应单元；
- **分区入口**：按主题区进入，区内按学习顺序与前置关系排列。
- 不设其他切分维度的入口（见 §2 不分学段）。

### 4.3 核心学习闭环（每个知识单元固定六步，顺序即教学法）

1. **病句医院入口**：先呈现中国孩子真实犯的错，制造「为什么错」的缺口；
2. **动画讲机制**：白板动画只画机制本身（识解、打包、原型扩展等），不画装饰；
3. **一屏一总结**：儿童版标题句 + 示意图式 + 亲戚网 / 拼法菜单 / 搭配银行（按单元性质取一）；
4. **分级例证**：每级至少 2 例，取材遵守接地气四条（§3.3），例词遵守词库依赖规则（§5.2）；
5. **检索练习**：答错不直接给答案，只提示回到机制重看；答对给出确认；
6. **间隔复习 + 病因归档**：错题按病因（错的机制原因）归档、不按题号归档，复习队列由病因驱动。

### 4.4 内容单元构成（一条规律的上屏规格）

一条规律须齐备以下要素才可上屏，缺一留在候选区：类型化断言（类型 + 证据 + 已知例外）/ 儿童版标题句 / 机制说明 / 至少 1 个动画场景规格（含事实表）/ 分级例证（≥2 级）/ 病句医院病例（≥1，真实错型）/ 亲戚网 / 测验题（答错回机制提示）/ 误解探针（≥1，预判孩子会怎么理解反，附判读量规）。

### 4.5 复习区需求

- 错题本按病因分组呈现，每条错题可回溯到对应单元的机制屏；
- 间隔复习队列按遗忘节奏生成提取自测，题目从已学单元的题库与探针中取；
- 复习不引入新知识，只做提取与纠偏。

### 4.6 家长角需求

- 与孩子层同源：每个单元的成人层包含机制原文、出处（可点开核对）、证据等级、边界与已知例外、学界分歧与待核登记；
- 家长角呈现成人层全量内容，孩子层默认不显示成人层（同屏开关切换；具体形态见 §8 未决事项 3）。

## 5. 数据需求

### 5.1 词库为根

词库是全部数据的第〇层（根）：先有词库，其他一切依赖词库。词库已落盘（`../model/wordbank.json`，建库 1,567 条；覆盖审计认定的真缺词与边缘例词共 400 词按普通词逐词核查补入中）。（来源：用户裁定 2026-11-01）

### 5.2 词库六条依赖规则（硬规则）

1. **例词必有出处**：任何规律条目、练习题、探针题、场景台词里出现的英语词，必须能在词库中找到（按词形、别名，或经变形归一到原形）；找不到即不合格，要么先补词入，要么换例词；
2. **新词先入再用**：内容需要词库外的新词时，先给词库补条目（音标、词性、释义经核查），再在内容里引用；不许内容先行、词库欠账；
3. **一词一源**：同一个词的音标、释义、拼法信息只在词库存一份，内容侧的例词展示从词库渲染，不手写第二份；
4. **挂接单向**：规律层通过挂接字段（命中的拼读模式、词根词缀拆分、所属规律编号）回连词库；词库不反向依赖任何规律条目的存在与否；
5. **覆盖校验**：入模校验须含「例词覆盖检查」——扫描全部内容用词比对词库，库外词清单非空不过关；
6. **菜单全量呈现**：见 §5.4。

### 5.3 全部入模

专家清单的 428 条知识**全量**转化为类型化模型条目，不搞试点缩水、不预留「文档态」散装数据；误解探针库、技巧库同样入模。施工可以分批（词库补全 → 逐组入模并回填词库挂接 → 例证、练习、探针、场景全部改引词库编号），但范围不缩减。（来源：用户裁定 2026-11-01；裁定覆盖定义底稿原 MVP/二期分期表述）

### 5.4 菜单全量呈现

每个菜单（区）呈现的词，必须是词库中符合该菜单口径的**全部**词，不许只挑样例词。词集不手工挑选，由词库字段谓词推导：拼读区按拼读模式与可解码性、词汇解码区按词素拆分与多义标记、语法与小系统区按词性与功能词标记、表达区按主题与短语标记。各菜单的具体谓词口径写入该区建模文档、评审定版。校验含「菜单完整性检查」：菜单词集与谓词推导集逐词比对，遗漏非空不过关。（来源：用户裁定 2026-11-01）

### 5.5 数据文档制度

每份数据集必须有专门的文档记录：登记本体文件、专属说明文档、规模、状态（草案 → 评审中 → 定版）与变更日志，汇总于数据总账（`../model/README.md`）。数据随时可改：变更先改本体，再回总账与专属文档各记一笔（日期 + 改了什么 + 依据）；每份数据定版前须出说明文档交评审，评审结论与采纳情况记回总账。（来源：用户裁定 2026-11-01）

## 6. 非功能需求

- **单文件、离线、双击可用**：产品为单个 HTML 文件，双击打开即用，不依赖网络、无账号、无服务器；学习进度存本地。（沿定义既定形态）
- **呈现形态**：动画沿用项目既定的白板动画形态（位图人物 + 元素道具），不引入外来动画技术。（沿定义既定形态）
- **数据可维护性优先**（本产品的第一设计要求）：单一事实源——同一事实（词条信息、规律断言、台词文案）只存一处；动画、卡片、测验、复习等全部视图由模型渲染，文案零副本；改一处，全部引用视图同步生效；变更的影响范围可由工具列出并校验。

## 7. 验收标准（每条内容上线门槛）

一条内容（规律单元）上线前必须全部通过：

1. **出处可核**：出处指向一手源、可点开核对；分歧已登记、待核已隔离（§3.1、§3.4）；
2. **单元规格齐备**：§4.4 全部要素齐全，动画场景的自动检查 0 失败、事实表完备；
3. **误解探针过关**：探针已备且量规可用（§4.4）；
4. **词库校验为零**：例词覆盖检查库外词为零（§5.2 规则 5）；所在菜单完整性检查遗漏为零（§5.4）；
5. **接地气清单**：§3.3 四条逐项勾验通过。

## 8. 未决事项（仅以下三件未拍板，现以默认档顶行，不阻塞其余工作）

1. **裁定 A · 发音产出要求（弱读教到什么程度）**，三档：
   - **A1（现行默认，推荐口径）**：弱读等发音现象听辨全教，产出只练核心项，弱读产出标记为「认识即可」；
   - A2：核心优先——弱读连听辨也降为次要，只保核心发音项；
   - A3：应试口径——弱读产出也要练、要考。
   切换只改变呈现与练习要求，不改数据本体；相关条目内的专家分歧原文保留。
2. **裁定 B · 产出导向法（POA）入模程度**，三档：
   - **B1（现行默认，推荐口径）**：只收其排序思想（先试产出、暴露缺口、再给输入）作为关卡排序原则，完整教学流程不进本产品；
   - B2：简化版试点——在进阶顺序后段设简化流程试点，入模但标注「试点、证据待验」；
   - B3：不入模——只留在成人层/教师层。
3. **家长角形态**：与孩子层同文件、同屏开关切换（现行默认）——或做成独立的家长页面。二选一未拍板，默认顶行期间按同屏切换实现。
