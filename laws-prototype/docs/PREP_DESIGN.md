# 介词模块重做规格（PREP_DESIGN）

定版：2026-11-01，用户「按学习方法重做 + 加厚 + 引申讲透」裁定与「高度思考」设计答复的落盘版。
数据基线：`model/prep_family_full.json`（43 词加厚卷宗，151 个义项节点，逐节点 extension 引申理据 + basis 引证/组装分账）。
方法骨架：P-01 全家福原型图 / P-02 中心裁决 / P-10 按图索引（猜） / P-17 成长序（空间→时间→抽象）。

## 0. 总判断

介词不是「词+义项清单」，是一台小机器：一个空间关系图式 + 几条固定变形规则。
软件表达的对象是这台机器：核心图式可操纵、变形过程可观看、邻居分工可同屏对比、新用法可按图猜。
静态图卡与义项列表是这台机器的截图，不是机器本身。

## 1. 页面骨架（每词一页，方法四条即结构）

1. **入口·在的拆分**（有 cn_cut 的词）：先给一句中文「在……」句，点开看这个「在」如何被拆成本词与邻居的分工（PB-12 错位图交互版）。无 cn_cut 登记的词跳过本节，不编造。
2. **原型图舞台**（P-01）：参数化场景——射体（可动小物）+ 界标（容器/表面/点/路径等）+ 关系。孩子可点预设位置按钮（低龄与触屏优先）或拖动射体，句子与高亮随位置实时变。舞台下方一句裁决说明。
3. **中心裁决条**（P-02）：verdict 内容孩子话呈现——为什么中心是这张图（有据的证据点）；特殊形态见 §4。
4. **引申链**（P-01/P-06/P-17）：链上每站 = 同一舞台的一次变形（参数改动以动画/对比小图呈现：静→动、容器→表面、空间→时间、视点换边、加功能知识），站内含义项名、例句、**引申理据**（动了哪一步所以长出这个义）。链身按成长序分段着色：空间段 / 时间段 / 抽象段。basis=组装的站，成人层标注「组装非引证」，儿童层不打折但不出示假出处。
5. **对手同屏**：对手词共用同一场景一键切换（单变量对比），分工句出自卷宗 opponents/cn_cut。
6. **猜一猜**（P-10）：页末 1–2 条未讲用法（卷宗 guess 字段），先选「它挂在哪根链上/是什么意思」，再揭晓路径；不可推导项（登记类）揭晓时明说「这一条推不出来，是约定，整块记」。
7. **练习**：以语义反馈为核心——答错不给红叉了事，而是把所选答案渲染回舞台（「你选的图是这样——和句子要说的对上了吗」）。识解题（at/in the café 类）允许多答案，按图解释各自成立的条件。
8. **成人层**：机制、边界、接触等级、组装标注全量、来源（卷宗 adult 字段原样）。

## 2. 三种专用舞台（除通用关系舞台外）

- **时间轴舞台**：可缩放的时间带（年→月→日→钟点逐级放大），粒度决定介词（in/on/at 及 before/after/until/since/past 等时间站共用）。服务一切时间义项站：链上时间站点击即在此舞台演示。
- **路径舞台**：through/across/along/over（越过站）/to/from 等路径站——轨迹播放 + 可沿路径拖动；界标几何（穿过介质/越过表面/沿着边缘/抵达界标）即词义。
- **视点开关**：in front of/behind/beside 等投影词——「换边站」按钮翻转视角，前后随之互换，明示视点依赖。

旗舰手工调校：in/on/at/over 的通用舞台与时间轴、through 的路径舞台、in front of/behind 的视点开关。其余词用数据驱动的通用舞台（按 core 图式类型选渲染器：容器/表面/点/邻接/路径/环绕/组图）。

## 3. 词表与导航

面板索引沿用现行三面板（核心四将 / 有全家福 / 其余），徽标改为链节点数；43 词全部有全家福后，第三面板改名「其余介词」。点词进词页、对比进对比页的现行视图结构不变。

## 4. 特殊词形态（诚实分层即页面形态）

- **over**：裁决条双版并存（静态版/动态版两张中心图并列，各带证据与「未终局」注），链序标注从哪版出发。
- **on**：链上 on2「继续」站挂**断链标记**——独立成站，注「这一站从核心图推不出来，专著要求另立基本义」，不接假桥。
- **with / of**：无单一原型图——页面改为**关系组图**形态：几组关系图并列成家，页首明说「这个词的全家福没有一张证件照」。
- **by**：裁决条并存登记（中心未决），被动站注「无桥梁登记」。
- **upon**：短页 + 语域注（正式版 on），不外推 on 的材料。

## 5. 明确不做

计时加压；同义词合并教（over/above 必须分开）；翻译对照表；唯一答案判死其他合理说法；给不可推导用法编引申故事；拿库外词/句充数。

## 7. 验收口径

- 43 词页逐页可达；每页链节点数 == 卷宗 chain 长度；extension 文本逐站与卷宗一致（抽验 + 全量文本比对脚本）；
- 旗舰舞台交互实测：in 拖动/预设变句、over 变形站动画、时间轴缩放变介词、through 路径播放、behind 换边互换、在-拆分（in/on/at 三词入口）；
- guess 逐词与卷宗登记一致（until 为「无」并显示登记理由）；
- 零 pageerror、无 hash；朗读整句 en-GB/0.85、逐词按钮 0；
- 与基线（v6）内容对账：原 14 词的例句/出处不丢失（加厚只增不删，节点序以加厚卷宗为准）。
