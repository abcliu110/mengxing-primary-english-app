# 最终集成思考：词根词缀的规律如何加进主 App

> 前提（2026-11-02 最新状态）：原型线数据已终态——词库 2,473、可拆 926 全带 morphemes、词根区 102 谓词页在 laws 原型与 morphology 原型两文件中同源建成；
> 主 App（18MB）仍是老构词模块：手写数据 WORD_FORMATION_DB + 单渲染函数 renderVocabFormationView，4 个标签，无词根区、无规律层。

## 一、先想清楚：现在「加规律」到底是什么动作

不是给老四标签打补丁。老模块是**手写页**，新区是**谓词生成页**，两种生成方式不能长期并存。
融合的本质 = 把构词模块从手写页换成生成页，规律层是生成页之上的一层。所以顺序上规律不能孤立地先焊在老数据上焊死，
但规律层本身不依赖区数据（只依赖例词词形），可以先行落地、独立验收，再随区切换锚点。

## 二、加在哪（位置设计）

- 不设新的一级入口，仍在 单词大世界 → 构词模块内部（既定结论）。
- 模块内部：老 4 标签升级为 **6 面板 + 1 规律入口**。规律入口放最后一位，默认落地页不变，
  etym→后缀、morph→矩阵两条老深链不破。
- 规律入口内部就是 v4 双方案共用的那套：列表（双视图）→ 规律页（统一模板）→ 落地链接跳谓词页。

## 三、规律的数据怎么进（数据设计）

- **单一出处**：定版文本以 `laws-prototype/model/laws/vocab.yaml` 的 V-33～V-39 为源，生成 `AFFIX_LAWS_DB`
  注入主文件标记块（起止标记 + 生成脚本，仿 insert_wb.py，可再生，禁止手改 HTML 内嵌块）。
- 每条规律字段：`id / 标题 / kid句 / 机制 / 例词(英文词形数组) / 病例 / 练习 / part(部位) / station(站号) / 成人层`。
- **例词按词形解析，不搬 ID**：两库 ID 系统不同（主库 G3_0759 式 vs 原型库 ADD_ 式）。
  生成时按英文词形对主 App VOCAB_DB 建索引解析；解析不到的进待补清单输出报告，绝不硬造词卡。
  恒常律的 sign/signal、heal/health 等例词要先验主库覆盖，再定例词表。
- 新 2 条（恒常律、三读律）：首批可进数据，`id` 留空、列表标「新 · 编号待对账」，与图鉴对账后再回填编号。
  机制补强（类频率定产出性 → V-36 成人层；Bauer & Nation 七级 → V-39 分课骨架）只进成人层，不占儿童条目。

## 四、规律与区页面怎么咬合（双向引用，单一出处）

- **规律页 → 区**：每条规律底部「落地」链接跳对应谓词页（V-34 → 同化 in- 页；V-36 → -able/-ible 对手页；
  V-33 → 前缀面板；V-38 → 不拆名单页）。原型区的页锚体系（pf-/sf-/rt-/fx-/as-/cp-）原样搬入，生成器同源。
- **区页面 → 规律**：明细页顶部引用块只放规律 kid 句 + 「为什么」链接回规律页，讲解全文只存规律层一处，区页不重写。
- **面板就地件**（引用同一份数据，不是第二份文案）：
  - 前缀面板顶：V-33 覆盖条（前 4 = 58%、20 = 97%）+ 头部四将徽标；
  - 后缀条目：通电/封存灯（标记随原型 sf 页数据搬运）；
  - V-37 让路条：横切规律，挂后缀面板与屈折面板两处，同一份内容引用；
  - 三读律：正式立条位置在屈折（-ed / -s 明细页内嵌三读表），规律列表收一条、拼读区只互链不另立；
  - 恒常律：立条位置在规律层（横切），例词家族表在规律页内承载，词卡侧只回链。

## 五、老数据退役（WORD_FORMATION_DB）

逐项映射后删除老渲染分支，模块只剩生成一条路：
20 前缀 → pf 页；12 组后缀 → sf 页分组；25 复合词 → cp 页；派生词族矩阵 → rt 页。
映射表（期 0 对账表）逐项标 保留/合并/退役，butterfly 等词卡按新库 transparency 字段统一口径
（butterfly = 可拆但半透明；define/inflammable 按 2026-11-02 裁定为普通可拆，从假拆名单移除）。

## 六、建议分期

- **期 0 · 对账表**：老四组条目 × 新 102 页逐项映射 + 规律例词对主库的解析率报告。动手前最后一张表。
- **期 1 · 规律层先行**：只加 AFFIX_LAWS_DB + 规律标签/列表/详情，落地链接先指老面板的临时锚。
  风险最小、独立验收（7+2 条齐、例词解析率、jscheck、深链回归），先让你看到规律在主 App 里的真实样子。
- **期 2 · 区落地**：MORPH_DB（wordbank.json 精简字段：morphemes/morph_class/transparency，约数百 KB 级）
  + 面板生成替换老四标签；规律落地链接由临时锚切换到谓词页；验收 = 102 页逐页成员数与原型全等。
- **期 3 · 回链与清理**：单词卡按 transparency 回链明细页、butterfly 卡修正、全库假拆名单按 nosplit 230 + 最新裁定回写、老数据删除。
