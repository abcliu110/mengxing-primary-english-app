# 萌星主文件审计 · 产品动线与学习闭环

- 对象：`laws-prototype/mengxing-prototype-v1.html`（HEAD d4367cc，18.6 MB，61 个顶层视图）
- 维度：孩子与家长「用起来顺不顺、学完有没有闭环」。死链/孤儿/计数对账已由今晨完整性审计覆盖，本文不重复。
- 方法：静态结构普查 + Node DOM-stub 实跑模块数据（LAWDATA / RV.buildPool() 实测）+ 逐区代码核查。数字均为实测。

---

## 一、进入与导航

### 1.1 导航条：16 颗 pill 无层级平铺，手机上折行约 3 行

- 顶栏共 **16 颗 pill**：首页 + 13 个学习区 + 复习区 + 家长角 + 设置。容器 `.bar{display:flex;flex-wrap:wrap}`——不滚动、不分组、不分层，390px 宽下约折 3 行，占首屏高度可观，且每进一个区都要先扫过这 3 行。
- 层级混乱：学习区（孩子用）、复习区（孩子用）、家长角（成人用）、设置（其实是研制口径开关，见 §4.2）四种性质完全不同的入口同层混排，没有任何视觉分组。
- 首页头部自称「十四区」，顶栏却是 16 颗 pill，观感对不上（差额是首页 pill 本身与设置）。

### 1.2 首页卡与 pill 对应关系：家长角、设置无首页卡

- 首页有 **13 张学习区卡 + 复习区卡**，与 pill 一一对应到学习区；**家长角、设置只有 pill、没有首页卡**——家长第一次打开 App，在首页找不到「家长角」的任何说明，只能靠顶栏小字 pill。
- 首页另有 6 张「病症卡」（记不住 / 听不懂 / 说不出 / 写不长 / 读不快 / 错不完），按困境导流到深单元（u-co17、u-v33 等）。这是全 App 唯一的非目录式入口，值得肯定；但它只覆盖少数深单元，且排在 14 张区卡之后，首屏看不到。

### 1.3 各区结构模型对照：至少 5 种方言

| 区 | 视图数 | 结构模型 |
|---|---|---|
| 拼读 | 5（主页/详情/心脏/主线/规律） | 多视图分工型 + LAWDATA 规律 |
| 词汇解码 | 1（巨型单视图） | 单页 SPA 型：分类词表、词页、达标测全在一个 section 内切换 |
| 词根词缀 | 2（索引/详情） | 新规范两视图型 |
| 词源 | 2（索引/详情） | 新规范两视图型 |
| 语法 | 19（双目录页 + 共用规律页 + 7 个深单元 + 时态子应用 9 视图） | 联邦型：一个区名下挂着目录、规律库、深单元、时态子应用四套东西 |
| 动词 | 17（主页 + 16 子视图） | 子应用型：自成一国（自有复习页、报告页、诊断页） |
| 代词 / 冠词 / 连词 | 各 2（索引/详情） | 新规范两视图型（三区一致，全 App 最整齐的一组） |
| 介词 | 1（巨型单视图 pkmod） | 单页 SPA 型 |
| 表达写作 | 2（双目录页）+ 共用规律页 | 目录分册型 |
| 技巧 | 2（索引/详情） | 两视图型 |
| 复习 / 家长角 / 设置 | 各 1 | 单视图型 |

孩子在每个区都要重新学习「这个区是怎么组织的」：有的区点卡片进详情页，有的区在同一页内翻页（词汇、介词），语法区要在两个目录页之间先做选择，动词区则是一个完整子应用。

### 1.4 返回路径：标签方言至少 5 种，无统一返回组件

实测返回按钮标签：「← 回首页」（多数区主页）、「← 返回动词专区」（动词/时态 17 个视图）、「← 回目录」（时态子应用——不说回哪个目录）、「← 回语法区目录（GR）」/「← 回表达写作区（E/W）」、「← 返回」（介词区，不写目的地）、「← 返回列表 / ← 返回词表」（词汇区内）。详情页（各区 detail、共用规律页）的返回按钮由各模块自己渲染，没有全局统一组件；回首页主要靠顶栏 pill 和各页手写的回首页钮。

## 二、跨区动线

### 2.1 互链普查：多数区静态出链只有「回首页」

静态 HTML 跨区出链实测（不含 JS 渲染部分）：

| 出链方 | 跨区去向 |
|---|---|
| 首页 | 全部 14 区（卡片）+ 病症卡 → 深单元 |
| 词汇解码 | 语法 3、词根 3、拼读 2（全 App 互链最密的区） |
| 语法 | 拼读 3、词汇 3、动词 1 |
| 词根词缀 | 词源 1（互链卡） |
| 家长角 | 语法 3、拼读/词汇/表达/技巧各 1 |
| 拼读、词源、动词、代词、冠词、连词、介词、表达、技巧、复习 | **只有「回首页」** |

JS 渲染层的互链集中在三处：词页（VC，见 §2.2）、规律页的关联区互链卡（LAW 共享脚本 → 代词/冠词/连词各 2 处）、技巧页 → 规律页/时态站（TEC.goLaw / goTa）。除此之外，各区基本是「首页进、原路回」的辐条，没有横向动线。

### 2.2 词页（枢纽）覆盖：链向一半，词源深链为零

词页在词汇解码区内（词库 2,351 词，点词进词页），实测链向：

- **拼读落点**：已全量对账（10,868 对落点，Stewart 侧今晨数据）——最完整的一条链。
- **词根/构词**：VC 代码含词根呈现与 `data-go="morph"` 出口，词页 → 词族页深链已通（带高亮定位，昨夜备忘已验）。
- **词源**：**VC 代码中 `ET.` 调用为 0**——2,351 张词页没有一张能直达词源区对应词条页；词源故事只能从词源区自己的搜索进。词源区已核 1,816 词的身世档案与词页是两套平行呈现，孩子在词页上看不到「这个词的身世 →」。
- **反向链**：词族页 → 词页无返回链（昨夜备忘已指出，属词根区）；词源详情页未见链向词页/词族页的按钮证据。

### 2.3 单向 / 缺失动线系统清单

| 动线 | 状态 |
|---|---|
| 词页 → 词族页 | ✅ 有（深链+高亮） |
| 词族页 → 词页 | ❌ 无 |
| 词页 → 词源词条页 | ❌ 无（0 次调用） |
| 词源页 → 词页 / 词族页 | ❌ 未见 |
| 词页 → 拼读落点 | ✅ 有（10,868 对） |
| LAWDATA 规律页 → 复习区 | ✅ 自动入池 |
| 代词/冠词/连词规律页 → 复习区 | ❌ 练习不入池（见 §3） |
| 复习区 → 回机制重学 | ✅ 有（限入池题源；新区规律无此待遇） |
| 技巧页 → 规律页/时态站 | ✅ 有（单向，反向无） |

### 2.4 孤岛区

- **词源区**：入链只有首页卡 + 词根区 1 张互链卡；出链只有回首页。1,816 条已核档案基本靠区内搜索自给自足。
- **介词区**：入链只有首页卡（+家长角未列它）；区内无练习、无出链，是全 App 最封闭的大区。
- **连词/冠词/代词**：入链靠首页卡 + 语法区互链卡，出链只有回首页；学完即止步。

## 三、学习闭环（核心发现）

### 3.1 持久化全景：全 App 只有 5 个 localStorage 键

实测全文件 `localStorage` 只有两个存储体系：

- `mxReviewV1`——中央复习引擎（Leitner 五盒，间隔 [0,1,3,7,16] 天，含错题本与「回机制」）；
- 动词区私有四件套：`mx_vb_srs_v1 / mx_vb_loop_v1 / mx_vb_log_v1 / mx_vb_lifeline_v1`。

**除此之外没有任何区记录进度**：孩子在代词区学完 33 条、连词区做完小测，关掉页面即清零，App 不记得他学过什么；没有一个区有「已学完」标记（词源区 1,816 词看过哪些、词根区 102 页读过哪些，全无记录）。

### 3.2 复习池实测：1,200 题，覆盖不到一半的区

`RV.buildPool()` 实跑结果，池内 1,200 题构成：

| 题源 | 题数 | 占比 |
|---|---|---|
| 拼读过关词（gate） | 594 | 49.5% |
| 规律练习（LAWDATA quiz） | 281 | 23.4% |
| 理解探针 | 238 | 19.8% |
| 时态站练习 | 87 | 7.3% |

覆盖区：拼读、词汇解码、语法、表达写作、时态站、（LAWDATA 里的）小系统残余条目。**不在池内的**：

- **代词 33 条 + 冠词 21 条 + 连词 15 条 = 69 条规律的全部页内小测**——三区数据是模块私有数据（不在 LAWDATA 里），复习引擎根本看不见。这三区是最近两个月刚按最高标准建成的区，却是闭环外；
- **词根词缀**：规律页带练习（LAWREG 内含 quiz），不入池；
- **词源**：无练习体系，不入池；
- **动词**：不入中央池，走自家 SRS——全 App 存在**两套互不相通的间隔复习系统**，孩子要在复习区和动词区复习页两个地方分别复习，「今日队列」永远不含动词与三新区的内容；
- **介词、技巧**：不入池（技巧页有题也不在 LAWDATA 口径内）。

附带一处陈旧：复习区的族筛选栏至今挂着 **「🧭 小系统」**——该区已被撤销并入各专区，筛选名录与现行十四区对不上（池内 law|小系统 31 + probe|小系统 25 共 56 题仍以此名目呈现给孩子）。

### 3.4 家长可见性：只有动词区有学习报告

- `v-verb-report`（家长报告）读动词区日志，是**全 App 唯一的学情报告**：孩子练了多少、错在哪，只有动词区可查。
- 家长角本体是成人层条目索引（114 条教学法/支撑层 + 旗舰单元成人层展示），是「给家长看的道理」，不是「给家长看的孩子进度」。家长想知道孩子这周在拼读、代词、词源学了什么——无处可查（数据根本没存，见 §3.1）。
- 复习区有盒位与错题本统计，但只在孩子端复习页内，家长角没有汇总入口。

## 四、个性化、分级与搜索

### 4.1 无年级/水平分层，无推荐路径

- 全 App 没有按年级（1–6）或水平的分级入口，没有「新用户从哪开始」的引导：第一次打开就是 14 张区卡 + 16 颗 pill 平铺，低年级孩子和家长只能自己猜先点哪个。
- 文件内「分级」字样 78 处、「学习路径」25 处，均为条目内容内部用语（如分级阅读、条目内的路径），不构成产品层分流。
- 唯一的替代设计是首页病症卡（按困境找解法），但它在区卡之后、覆盖面窄，不能替代分级/推荐路线。

### 4.2 设置区：不是给家庭用的设置

`v-settings` 实测内容只有两组**课程口径裁定开关**（裁定 A 弱读产出取向、裁定 B POA 入模口径），且页面明说「切换只改本页呈现，不改数据」。没有年级设置、没有语音/字号/护眼、没有任何孩子或家长真正会用的选项。它占着顶栏一颗 pill 和「设置」这个名字，家庭用户点进去只会困惑——这是研制过程的留痕误入产品导航。

### 4.3 搜索：无全局搜索，查词路径藏得深

- **没有全局搜索**。局部搜索共 3 处：词汇区词表（vc-lsearch）、动词衣橱（wSearch）、词源区（etq）。词根区 2,473 词索引**连局部搜索都没有**（实测 v-morph 无 input），只能翻旗舰卡和列表。
- 查一个词的最短路径：首页 → 词汇解码区 → 词表搜索框 → 词页，共 3 步，且孩子多半不知道「词页」藏在词汇解码区里（首页卡文案列的是「词源故事、词根家族、变身机……」，不提查词）。
- 查一条规律：无任何搜索，只能记住它在哪个区、逐区翻目录；规律总量已达数百条（LAWDATA 390 条 + PN 33 + AR 21 + CJ 15 + LAWREG 16 + 拼读 PHONLAWS），靠翻目录找一条学过的规律对孩子不现实。

## 五、一致性体验

### 5.1 色板覆盖：枢纽区词汇解码反而不在定稿色板内

figma-all 定稿色板已覆盖的 scope：拼读（phx）、介词（pkmod）、语法（gkmod）、动词（vb）、时态（tn）、词根（mz）、代词/冠词/连词/词源（pn/ar/cj/et-scope）、规律页（lz-）。**未覆盖**：

- **vcmod（词汇解码 + 全部词页）**——全 App 的枢纽区不在色板内，仍是自有配色；
- 技巧（TEC）、复习（rv-）、家长角、表达写作自有样式。

即：最近建成的区都对齐了，最老的枢纽区和功能区还没有。

### 5.2 动画方言：白板只覆盖 69 条规律，时长标准有一区超标

- 白板动画标配只存在于**代词（33）+ 冠词（21）+ 连词（15）= 69 条**规律页，另有冠词/连词首页短片。LAWDATA 系 **390 条**规律页无白板（只有静态机制呈现）；动词区用 SVG 时间线、介词区用自有动画资产——动画方言至少 4 种。
- 时长：代词区标准为每条 30–50 秒；**连词区 CJ02 / CJ04 / CJ07 三条此前实测约 54–58 秒，超上限**（已登记在案，未调整）。其余各区动画无统一时长标准可依。

### 5.3 「给大人的说明」：两套机制并存，家长角目录与实际覆盖双向对不上

- 机制两套：老区（LAWDATA 系）用页面顶部「成人层」开关（全文 92 处）；新区代词/冠词/连词用页内折叠块「🧑‍🏫 给大人的说明」；词源区又有 et-adult 样式一支。家长要在不同区学不同的打开方式。
- 家长角「各区成人层在哪儿」目录只列 **拼读、词汇解码、语法、表达写作、技巧 5 区**：但代词/冠词/连词/词源明明都有成人层，未被收录；目录列出的区用的又是开关制，与新区折叠制并存——目录与实物双向错位。

## 七、最该先动的 3 件事

1. **把复习池接成全 App 的**：给复习引擎加一个统一题源接口，让代词/冠词/连词（69 条小测）、词根规律练习、技巧、介词都登记进中央池，并把动词区 SRS 与中央池打通（至少让「今日队列」合并呈现）；顺手清掉「小系统」僵尸族名。这是闭环断裂的最大面——内容都建好了，只差一根管子。
2. **给顶栏加一个全局搜索框，词页升为全 App 枢纽**：一框两查——查词直达词页/词源档案，查规律直达各区规律页；同时补上词页 → 词源深链与词族页 → 词页反向链。孩子「想查」的那一刻现在是最长、最容易放弃的路径。
3. **建一层薄进度 + 家长全区视图**：统一一个跨区进度存储（每条规律/每页打「学过」点，成本低），家长角据此出一页全区学情（仿动词报告的口径扩展到十四区），并把成人层目录补全到实际覆盖。没有这一层，家长无法信任这个 App 在「教」而不是在「摆」内容。
