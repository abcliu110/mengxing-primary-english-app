# 探针库建模文档 · probes.yaml

本体：`laws-prototype/model/laws/probes.yaml`(与本文同目录)。来源：探针库 v1(`~/workspace/content-depth/misunderstanding_probes_v1.md`,2026-11-01)。规模：**40 个探针**(8 组 × 5)。状态：已入模(version 1)。schema 依据：`laws-prototype/docs/DESIGN.md` §3.6。

## 一、入模口径

### 1.1 字段映射(v1 五字段 → 模型 schema)

| v1 字段 | 模型字段 | 处理 |
|---|---|---|
| (组内编号 P1–P5) | `id` + `source_ref` | id 按 DESIGN 惯例生成 `PRB-<规律编号去连字符>-<序>`(如 `PRB-S36-1`);`source_ref` 保留 v1 出处(如「一、S-36 P1」)供回查 |
| (所属单元) | `for_law` | 7 个旗舰单元直接对应规律编号;Boundedness 组的 5 个探针按其依据分别绑定 C-01、C-04、C-17、C-02、C-18(见 §1.3) |
| 预判误读 | `predicted_misreading` + `cognitive_source` | 原文拆两段:误读陈述(孩子视角)与「认知来源」括号注,分开存,不改写 |
| (v1 附一矩阵) | `misreading_type` | 取矩阵的主类型标签,一探针一型:母语迁移 / 过度泛化 / 字面化 / 主场·原型误植 / 物理直觉误植 |
| 探针题 | `task` | 分水岭题原文转入(题面中的英语例句以纯文本呈现,斜体标记去除) |
| 判读量规 | `rubric` 三态对象 | 原文一段拆为 `hit`(中招)/ `partial`(中间态)/ `pass`(过关)三键——**只拆分,不改判据语义**;原文明确「分计」的(如 Boundedness P5「完全看不出=中招;删 -s 留 many=中间态」)按原文分界落键 |
| 回补动作 | `remedy` | 原文转入(指向所属规律六步闭环的具体步与机制小节) |
| 依据 | `source_of_prediction` | 原文转入(条目边界 / 专家分歧 / S-43 难点地图 / 技巧误用警告,均可回指) |
| (新增登记) | `error_form_display` | 探针题面/选项中故意呈现的错形,登记为展示资产(见 §二) |
| (共用字段) | `status` / `version` | 全部 `已入模` / `1`,与规律条目共用状态口径 |

误读类型分布(40):过度泛化 16、主场·原型误植 10、字面化 7、母语迁移 6、物理直觉误植 1。与 v1 附一读表结论一致:字面化集中在有口诀、有演示、有数字处,是第二大误读来源。

### 1.2 使用口径(v1 附二,入模后不变)

- **位置**:前测置于第 2 步机制屏之后、第 4 步分级例之前;后测置于单元完成、第 6 步归档之前,同一探针可复用。
- **判读纪律**:三态量规只决定回补路径,不记成绩、不进评级;中招 = 探针命中其设计要暴露的误读通道。
- **中招率的地位**:只作教学诊断(看哪个误读通道最堵),**不作内容对错的裁决**——内容对错已由出处关把守。某探针长期全员秒过或全员中招,先修订探针,不动条目。
- **裁定中立**:本批探针不预设裁定 A(弱读产出)的结论;涉及产出的探针(如 PRB-S36-4)按「听辨先行、产出量规单列」写,裁定落档后只调量规产出档位,不动探针结构。

### 1.3 Boundedness 组的绑定

v1 第八组是跨条目的识解组(源文件组题为 C-01 / C-02 / C-04 / C-18,探针实测还用到 C-17 与 C-05)。入模按「一探针一主规律」绑定,依据字段中引用的其余条目保留在 `source_of_prediction` 里可回指:

| 探针 id | for_law | v1 组内号 | 主测点 |
|---|---|---|---|
| PRB-C01-1 | C-01 | P1 | 物理形状判可数(rice/furniture) |

## 二、探针题用词的词库依赖说明

按 WORDBANK 规则与 DESIGN §3.6 / §6-V3:探针题用词属内容侧用词,必须可归一命中词库,逐条以 `word_ids` 只引词库 id。本次入模的处理:

1. **绑定时点**:`word_ids` 不在本文件中逐条填写——词库补全(W0:真缺词 340 + 边缘词 60 逐词核查补入)尚在进行,待其收口后按 V3 口径(直接命中 / aliases 命中 / verb_form_of 归一)对 40 个探针的 `task` 用词统一回填绑定,并在总账记一笔。在此之前,探针题的用词以原文为准,不因绑定未完成而改写题面。
2. **存量基线**:词库覆盖审计(2026-11-01)对探针文件的例词口径覆盖率为 **80.6%**(直接命中 154 + 归一命中 26 / 提取词形 263);未命中部分多为补入清单内的真缺词与专名类,随 W0 收口处理。
3. **错形展示(豁免项)**:探针题面与选项中故意呈现的错拼/错形是设计资产,逐条登记在该探针的 `error_form_display` 字段,**不入词库、不算例词、V3 覆盖校验豁免**。全库共 12 个错形、分布在 6 个探针:

| 探针 | error_form_display |
|---|---|
| PRB-SR01-3 | hav、giv、blu |
| PRB-SR01-5 | littl、tabl |
| PRB-GR33-4 | amn't |
| PRB-C01-1 | rices、furnitures |
| PRB-C02-1 | breads |
| PRB-C18-1 | informations、advices、homeworks |

注:错句型展示(如 *open the light、*eat medicine、*You went there, isn't it?)是「病例式」题面而非错形资产,属探针题本体,不在此登记,也不受此豁免影响——其构成词仍按 V3 逐词查词库。

### 3.3 缺口如何关闭(机制,不是承诺凑数)

- DESIGN §4.1 入模第五步定死:每条规律入模时必须引用 ≥1 探针;**缺探针的条目在入模当场按立条纪律补写探针并登记进本库**——预判误读必须能指回该条目的边界/分歧、S-43 难点地图或技巧误用警告,指不回的不立探针、该条目停单回报。
- 因此覆盖率随入模波次(W1–W6)逐组自然收口,W7 探针库定版时做全量对账:428 条逐条核 `probes` 引用非空,且每个探针的 `for_law` 可解析。
- 支撑层组别(TM / LS / YL / CG / CB / VB / WA / NE 等)的条目以成人层呈现为主,其探针形态(面向教师/家长的理解自检 vs 不设探针)在对应波次入模时逐组裁定,裁定前在本表如实登记为无探针,不预填。
