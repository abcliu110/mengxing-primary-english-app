## 4. 字段变更（本节为全文唯一提及旧字段名之处）

原目录每条有「学段与剂量」字段，按在校阶段（小学/初中）标注适用形态。按产品裁定（不分学段，难度由区内顺序与前置关系承载），定版将该字段整体改为 **`order_hint`（区内顺序/前置关系 + 剂量）**，转换规则：

- 阶段分段标签一律译为顺序位置：先行形态（原前段形态）/ 进阶形态（原后段形态）/ 起步期 / 前段后期 / 全程适用 / 仅后段适用；
- 每条原有的**形态梯度**（先学什么、后放开什么、什么只认不产出）与**剂量原文**（含「剂量待定」）完整保留，只换标注坐标，不删内容；
- 学法路 `audience`（使用者）字段中的先后标注同步转换；
- 4 条因机械转换会产生病句或事实走样，整段人工改写并在此留名：TEC-V14（源课程覆盖范围的表述）、TEC-V16（CLEC 子库的被试构成）、TEC-L01（证据被试构成）、TEC-L03（间隔证据的年龄表述）；
- 证据字段措辞规范化 3 处：TEC-G08 `evidence_note` 两处、TEC-S25 `evidence_note` 一处（「跨学段」统一作「跨年龄段」类表述、「见学段注」改「见源条目注」），不改变证据内容；
- **逐字保留声明**：`mechanism / misuse_warning / evidence_note` 中涉及外部研究样本与源条目边界的在校阶段表述（如 EEF 对六年级学生的复制评估、CLEC 子库构成）属于事实引用、不是本库的分段口径，逐字保留。位置清单（共 11 处）：TEC-V14 `when`、TEC-S03 `evidence_note`、TEC-S08 `misuse_warning`、TEC-S12 `misuse_warning`、TEC-S20 `evidence_note`、TEC-S25 `mechanism` 与 `evidence_note`、TEC-S28 `misuse_warning` 与 `evidence_note`、TEC-L30 `misuse_warning`、TEC-P07 `misuse_warning`。另 TEC-L25 `order_hint` 中「六年级、八年级真实课堂」为源证据的样本事实，同此口径保留。
- 校验口径：定版后 `techniques.yaml` 与 `techniques_hitching.yaml` 中旧字段名为 0 出现；`order_hint` 与 `audience` 中无在校阶段分段词。

## 7. 排除与登记项清单（不转技巧、不删除、状态保持登记）

- **NE-23 Reading Recovery**：一对一干预项目（成本结构不可复制），且长期效果证据争议未定（短期随机试验与纵向追踪结论冲突）。其同源的 NE-22 印刷概念观察框架本身无争议，已独立成条 TEC-S11——不得以 RR 的争议牵连之，也不得以 CAP 的公认地位为 RR 背书。RR 的「早期干预、逐日观察」设计原则仅在源条目成人侧登记。
