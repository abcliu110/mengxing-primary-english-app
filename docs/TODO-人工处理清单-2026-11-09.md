## 二、产品定位决策（需人判断）

### 2.1 E/W/NE 区 59 条在儿童层可见，但概念偏抽象

这三个区（`zone = expr` / `expr2`，共 59 条规律）不在 `zone=parents` 成人层里，不会被成人层开关折叠，对小学生直接可见。其中若干条 `kid` 文字包含元语言概念：

- E-08：语用语境依存（「一句话说得对不对，要看是谁说的、对谁说的」）
- E-10：多维交际能力
- E-13：话轮管理概念（「聊天像打乒乓球」）
- NE 区整体偏向地道性与语域，是否适合小学低年级自学，需要产品决策。

**待决策**：保留在儿童层 / 下沉到成人层 / 按条目逐条判断。

### 2.2 学习路径：首页有「建议路线」文案，但无强制先修

LAWDATA 数据层里每条规律有 `"rel": "前置"` 字段（共 51 个前置关系链接），但没有代码把它们渲染成「建议先学 XX」提示，也没有进区前的先修检查。

**待决策**：是否在各大区入口加前置提示，或在主索引里根据 `rel` 关系显示「建议先修 S-01」。

## 三、数据/架构层问题（需重构或外部数据）

### 3.1 localStorage 结构隐患

代码对 `localStorage` 的错误处理是静默回退到内存存储，用户完全不知道数据没落盘。具体风险：

- **7 个独立 key**（`mxReviewV1`、`mxWrongBookV1`、`mxRushBestV1`、`mx_vb_srs_v1`、`mx_vb_loop_v1`、`mx_vb_lifeline_v1`、`mx_vb_log_v1`）之间没有事务性写入，跨 key 数据可能出现不一致
- **配额溢出**（`QuotaExceededError`）只被 `try/catch` 吞掉，全文未出现任何用户反馈
- **无版本号或 schema migration**：字段新增后无升级路径
- 浏览器隐身模式、Safari ITP、WebView 默认会阻断 localStorage，目前只是无声回退

**待处理**：加 schema 版本号、配额溢出时给用户提示、7 个 key 之间的事务性写入。

### 3.2 单文件 23 MB 加载性能

文件 21,831 行 / 23,369,008 字节，内嵌大量 base64 图片（20 张介词区截图）、一段 MP4 视频、全部 SVG 白板动画代码。

**现状**：单文件原型方便迭代，是架构决策。上线时必须做资源外置，无法靠改 JS 逻辑解决。

### 3.3 buildPool 的两个边界问题

- **POOL 只增不清**：`buildPool()` 首次调用后结果永久缓存，延迟加载的数据进不了题池，也没有任何「数据未就绪时延迟调用」的保护。
- **孤儿键只计数，不清理**：历史版本产生的 SRS 记录 key，如果对应题目已从 LAWDATA 删除，就成了永久孤儿键——占用 localStorage 空间、影响错题本统计基数，但代码选择只计数不处理。

**待处理**：加数据就绪检查、孤儿键清理机制。

## 四、可访问性剩余问题（内容层面）

### 4.1 57 张内容图片 alt 为空

全 App 58 张 `<img>` 标签中，57 张 `alt=""`（声明为装饰性图片），1 张有真实 alt。

这 57 张全是介词区的视频关键帧截图（`class="frame"` 的 base64 JPEG），承载教学内容（不同介词的空间关系图示），对屏幕阅读器用户完全不可见。`alt=""` 把它们声明为装饰性，但内容上它们不是。

**待处理**：逐张填描述性 alt 文字。这是人工任务，因为每张图描述不同介词的空间关系。

### 4.2 首页 22 个 SVG 图标无 aria 处理

22 张 `hm-ic` 内的 SVG 既没有 `aria-label`，也没有 `aria-hidden="true"`。按钮文字标签（`hm-name`）可用，但 SVG 作为无语义的路径集合，屏幕阅读器行为不可预期。

**说明**：补 `aria-hidden="true"` 是代码改动（可以自动做），但选择补描述性 label 还是 hidden 需要内容判断。如确认只补 hidden，可交回代码修复。

### 4.3 三处颜色对比度低于 WCAG AA

| 颜色组合 | 对比度 | 位置 | 字号 |
|---|---|---|---|
| `#99a` on `#fff` | 2.80:1（FAIL） | 动词衣橱来源标注、页脚 | 11.5–12.5px |
| `#8a8272` on `#f8faf5` | 3.62:1 | 词源区小字说明 | 约 12.5px |
| `--muted` on `--accent-soft` | 3.66:1 | 多处小字 | 12.5–14.5px |

WCAG AA 要求正常尺寸文字对比度 ≥ 4.5:1。这三处均不达标。

**待处理**：与设计对齐后确定替换色值。护眼色系本身偏浅，对比度达标可能需要加深文字色或换背景，属于设计决策，不是可以自动盲改的逻辑错误。
