# 白板动画问题诊断：茶壶壶嘴朝向错 + 人物不美观（2026-11-01）

> 对象：`docs/whiteboard/v5/scenes/fp_boundedness_1_v3.js`（家族模板）及其生成物 `gen_boundedness_1.js`（有界无界第 1 幕「咖啡馆」）。
> 方法：读源码 + 在本机 Windows（Edge + Segoe UI Emoji）实际渲染 🫖 和人物帧，对照 Linux（Noto Color Emoji）渲染结果。

## 问题 1：茶壶倒咖啡时，咖啡从壶把一侧流出（P0）

### 现象
倒咖啡时壶向右倾，水柱从壶的右侧流到桌面；但在 Windows 上，🫖 的壶嘴在**左边**、壶把在**右边**，看起来像是从壶把里倒咖啡。

### 根因
1. 茶壶不是自己画的，是系统字体里的 emoji `🫖`（`potImg()` 用 `fillText('🫖')` 预栅格化）。**emoji 的长相和朝向由各平台字体决定**：
   - Linux / Android（Noto Color Emoji）：壶嘴朝**右**（已实测）。
   - Windows（Segoe UI Emoji）：壶嘴朝**左**，壶把在右（已在本机 Edge 实测）。
   - Apple 等其他平台：也不保证一致。
2. 代码把「壶嘴在右」写死了：
   - `potTilt` 正角度 = 顺时针 = 右侧往下倾；
   - `potTip` 把出水点算在 `700 + 94·cos θ`（壶的右侧）；
   - 咖啡滩、落点（x≈806）也都在壶的右边。
3. 验收截图是在 Linux（Noto）上做的，壶嘴刚好朝右，所以没被发现；一到 Windows 就反了。

### 同类风险
- 同幕的刀 `🔪` 也是 emoji 旋转 -0.5 弧度后做「斩落」动作，刀刃朝向同样随平台变化。
- 所有「有方向的 emoji + 程序化物理」（倒、切、开、行驶、指向）都有同样问题。

### 解决方案
1. **茶壶改成 canvas 自绘矢量壶**（壶身、壶盖、壶把、壶嘴都用路径画），壶嘴明确画在倒水一侧；出水点 `potTip` 直接取自同一套几何坐标，水柱永远从壶嘴出。画风用和桌子一致的暖棕色 + 描边，与手绘风统一。
2. 刀 `🔪` 同样改自绘（或改用 cast 帧库里的手绘刀），不再旋转 emoji。
3. 加一条检查（并入 `runall.py`）：扫描 `scenes/*.js`，凡对有方向的 emoji（🫖🔪✂️🚗🚌✈️👉 等）做旋转/倾倒/出水计算的，一律报错，要求改自绘或帧库素材。
4. 验收截图增加 Windows（Edge + Segoe UI Emoji）一档，不能只看 Linux 截图。

## 问题 2：动画人物不美观（P1）

### 现象
人物穿帮、比例忽大忽小、换动作时有重影；画面上的大人比小孩还矮。

### 根因（逐帧实测）
| # | 问题 | 证据 |
|---|---|---|
| 1 | **借来的动作帧，语义对不上** | 「端咖啡」用的是 `l_coff2`，实际是 V06「脱外套」的结果帧——孩子胳膊上搭着一件橙色外套，不是咖啡；`l_coff0` 是穿着橙色外套的准备帧，所以孩子一会儿穿外套、一会儿没穿 |
| 2 | **帧里自带别的道具** | `l_think` 自带思考气泡、`l_idea0` 自带问号和一本书、`l_point` / 走路帧 `l_w0–3` 背着书包、提着礼物袋（来自「看望爷爷奶奶」），和咖啡馆场景无关 |
| 3 | **角色名和形象不一致** | 注释/讲解里叫 Linda（女孩），实际用的是 Leo（男孩，`l_` 前缀）的帧 |
| 4 | **缩放基准错，人物忽大忽小** | 所有帧都按 `l_coff0` 的 `bottom` 统一缩放（`sc = H0 / REF.bottom`），但每张帧的取景不同（`l_think` 上方有气泡，人就被缩小了），换动作时人物明显变矮变高 |
| 5 | **0.16 秒交叉淡化产生重影** | 两张完全不同的画（不同姿势、不同衣服）半透明叠在一起，会闪出“两个人”的残影 |
| 6 | **大人比孩子矮** | 店员 `woman` 设 `h: 500`，孩子 `H0 = 520` |
| 7 | **呼吸用非等比缩放** | `scale(1 - br·0.6, 1 + br)` 对手绘位图做横竖不同比例的拉伸，线条轻微变形；整体 `rotate(lean)` 连脚一起转，脚底会滑动 |
| 8 | **画风混搭** | 人物是铅笔线稿 + 橙色点缀，道具是彩色 emoji（📖❓🤔☕🍎🍞），桌子是平涂色块，三种画风同框 |

### 解决方案
1. **按场景补一张专用联排图**（沿用 CAST_V5 的绿幕关键帧流程，同一演员同一画风）：咖啡馆用的 6 个姿势——站立、双手端咖啡杯、托腮思考（不带气泡）、指向桌面、恍然大悟、开心笑；再加一组**不背包、不提袋**的走路 4 帧。帧里不画任何道具，气泡、问号由场景另外画。
2. **角色统一**：要么讲解里改叫 Leo，要么换成女孩演员（Mia 帧，`m_` 前缀），名字和形象一致。
3. **缩放改为按身体量**：`build_sprites.py` 打库时为每帧记录人物本身的头顶到脚底高度（排除道具/气泡），渲染时按这个高度统一缩放，换姿势身高不变。
4. **去掉交叉淡化**：姿势直接切换，只保留切换后的轻微落定（`settle`）；需要过渡时用同一姿势的中间帧，而不是两张不同的图叠化。
5. **比例**：大人身高设为孩子的 1.25–1.3 倍（例如孩子 520 → 大人 660–680）。
6. **呼吸改成只上下平移 1–2 像素**（不拉伸）；前倾只转上半身或干脆去掉，以脚底为固定点。
7. **道具画风统一**：本幕道具（书、杯子、苹果、面包、刀、壶）改用帧库手绘道具或 canvas 线稿 + 淡彩，不再混用彩色 emoji。
8. **加检查**：`check_cast` 校验同一幕里同一角色的帧来自同一演员前缀、帧里无道具标记、身高差 < 3%。

## 影响范围
- `fp_boundedness_1_v3.js` 是「家族模板」，`gen_scene.py` 会用它生成同家族各幕，所以**在模板里改一次，重新生成即可全部生效**；生成物 `gen_*.js` 禁止手改。
- 其它幕若也用了 emoji 做方向性动作，或借用不对口的动作帧，需要按第 3 条检查逐一排查。

## 建议顺序
1. 茶壶 + 刀改自绘，并加 emoji 方向检查（约 1–2 小时，可立即做）。
2. 人物缩放基准、去交叉淡化、大人比例、呼吸方式（约 1 小时，只改代码）。
3. 补咖啡馆专用联排图并替换借用帧、统一角色名（需要出新图，约半天）。
4. 道具画风统一（随第 3 步一起做）。
