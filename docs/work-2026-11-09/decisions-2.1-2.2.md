### 1.2 判定规则（按 kid 文字判，不是按概念名判）

逐条读的是 `lawdata.kid`（与 `yaml.headline_kid` 相同），辅以 `mechanism[].text_kid`。一条律判 keep，当且仅当同时满足 A、B；任一不满足即判 adult：

- **A 能懂**：kid 文字用孩子能直接理解的语言表达——具体例子、比喻、或可检查的问句；没有未解释的术语留在 kid 文字里。
- **B 能用**：孩子本人能照着它做点什么（判断、选择、练习、自我检查、自我安慰），而不必依赖教师/家长先替她设计课程、提供证据或替她判断。

判 adult 的具体情形（符合任一即 adult）：

1. **执行者是教师/家长/全班**：kid 文字的主体动作是“老师陪你”“要有人指给你看”“全班一起定规矩”这类课程安排，孩子无法自己发起。
2. **要点是背景知识**：研究结论、证据排名、流派立场、历史源流、干预性价比——孩子读了无法自己验证或执行。
3. **kid 文字含未解释的元语言/理论术语**：术语本身留在孩子要读的那行字里，且未落到做法（如 NE-26 的“互惠、累积”）。
4. **去重**：孩子版做法已在别条讲过，本条新增的只是教师口径、排序或分类（如 W-08 的四件事分见 W-02/W-04/W-12，W-11 与 W-07，NE-06 与 NE-14）。

### 1.5 成人层标记的字段口径：改 `aud`，不动 `zone`

主文件里“成人层”有两个不同的标记，不要混淆：

- **律的成人层标记是 `aud`**：`LAW.render` 认 `d.aud==='教师/设计层'`；`gen_roster.py`（约 148–151 行）layer 判 T 的条件是 `yaml.audience ∈ {教师/设计层, teacher, design}` 或 `lawdata.aud==='教师/设计层'` 或 `LAWDATA.aud==='教师/设计层'` 或 `zone==='parents'`。所以下沉一条律的正确做法是把 `lawdata.aud` 与 `yaml.audience` 写为 `教师/设计层`（两处都写，保持三处口径一致）。
- **`zone='parents'` 是另一类东西**：它是 `SUPPDATA` 里支撑性教学条目（TM/CB/LS 等 114 条）的分区字段，由 `tools/gen_laws.py` 之外的通道并入 `LAWDATA`；`LAW.open` 用 `zone` 算回跳区（`homeFor` 映射：`parents`→`家长角`，`expr`/`expr2`→`expr`）。把 E/W/NE 律的 `lawdata.zone` 从 `expr`/`expr2` 改成 `parents` 会把它逐出表达写作区导航、改掉回跳目标，属于改分区，不是改受众层。**因此补丁脚本只写 `aud`/`audience`，并断言 `zone` 不变。**

改完数据后的再生步骤（实施方执行，本次不做）：依次跑 `tools/gen_laws.py`（`LAWDATA.aud` 同步）→ `tools/gen_roster.py --check` / `--write`（索引行徽标与分组同步）→ `tools/gen_links.py`（LINKIDX 不受 aud 影响，但须确认无漂移）→ `tools/check_rel_coverage.py`（关系门禁）。主文件是生成物，**不许手改主文件**。

**为什么这样定**：

- **详情页底部块已有，不必重做**：关系数据与渲染链（总表 → `gen_links.py` → `LINKIDX.g` → `relSectionHTML`）已经跑通，推倒重做没有收益。
- **但底部块不够**：孩子点进详情页先读到的是 kid 文字，读到底才看到“先学这个”，顺序反了——先修提示应该出现在读正文之前。所以新增顶部条，底部块保留作“学完之后往哪走”的反向导航（q 槽）。
- **索引行加标记**：孩子在目录里就能看到哪条有前置，不用点进去才发现；行内只放编号，不展开标题，避免目录变臃肿。
- **区入口不做逐条先修**：先修关系是律与律之间的链（70 对里大量是同区内的链式，如 CO-03→CO-02→CO-01），区入口页没有“当前要学的律”这个上下文，逐条列等于把整张关系表贴在门口；区入口只适合放区级路线（首页已有）。
- **不做进区检查**：App 已有定下来的原则——分词帽子页诚实说明原话：“本 App 按已经定下来的原则「不分学段、用先修关系代替学段」”。先修是“代替学段”的柔性建议，不是门禁；进区拦截会打断自由浏览，且与“建议路线”的文案口径冲突。先修提示只提示，不锁门。
- **不强制**：与“不分学段”原则一致；孩子可以直接点进目标律，也可以跳过先修直接学；不记录、不扣分、不弹窗。

**字段规则（所有模板共用）**：
