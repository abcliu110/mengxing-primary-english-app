# 任务书：小学英语「同义 / 反义数据层」建库

> 本任务书自含全部背景，可直接转发执行。执行方为外部 AI；成果交回后由发包方抽查验收并入模，未过验收不入产品。体例与纪律仿《词源数据层任务书》（docs/etymology-datalayer-brief.md），该层的验收经验（双源互证、待核隔离、抽查退批）全部适用。

## 1. 背景与用途

发包方在做一个给中国小学生（兼顾初中）的英语学习 App。项目词库（`laws-prototype/model/wordbank.json`，2,473 条）已有音标、词素拆解、词频、可解码性、词源等数据层，但经全库检索核实：**没有任何同义 / 反义数据**——词条字段中不存在 synonym / antonym 字段，规律层的例词也不得自带同义说法。本任务就是补这一层：为词库显示集（2,351 词，即全库除去 122 条动词变形条目）建立**按义项挂接、逐条核源**的同义 / 反义关系档案，供 App 词汇区词页的「亲戚」栏目与辨析类练习调用。

定位纪律（重要）：

- 本层只存**事实与有出处的辨析**：关系、分级、语域、可替换边界（须有词典依据）。儿童版讲解文案不在本层写，由发包方在展示层另行撰写。
- **宁缺毋滥**：核不到可靠来源的关系不许写；查无关系的义项如实登记「已查无」，不许硬凑一对交差。这是全任务的第一红线。

## 2. 第一纪律：同义 / 反义是义项级关系，不是词级

同义词、反义词只在**某个义项**上成立，词与词之间笼统挂接必然出错。本库现成反例：

- **light**(G4_157，n./adj.，meaning「电灯，光线；轻的」)：形容词义「轻的」的反义词是 heavy；名词义「光线」没有直接反义词；动词义「点燃」的对应反面是 put out 一类。若按词级把 light ↔ heavy 挂成反义词对，孩子会把「光」也当成 heavy 的反面。
- **charge**(ADD_0446，v./n.，meaning「收费；负责；充电；指控」)：「充电」义的反义是 discharge（放电）；「收费」义与 discharge 毫无关系。词级挂接 charge ↔ discharge 会把放电安到收费头上。

因此：**每条关系必须挂在带编号的义项上**（见第 3 节 sense_ref)，任何「词对词」的记录格式一律不合格。

义项清单从哪来（义项地址口径）：

- **动词**：直接沿用已交付的义项网络数据（`model/verb_sense_networks_a/b/c.json`，279 词、549 义项），义项以 `{bank_id, sense_n}` 寻址，其义项划分与定义为词典逐字、出处在案，本层不得另立一套动词义项划分；与网络冲突时以网络为准。
- **其他词性**：词库词条的 `meaning` 只是打包的中文义字符串（如 charge 的「收费；负责；充电；指控」），**不是**义项清单。本层建库时须先按一级学习词典（见第 5 节）的义项划分，为每个词固定一份**限于小学 + 初中范围**的义项清单（超范围义项不收，登记排除），每义项带词典出处，再在其上挂关系。义项清单本身是交付物的一部分；某词义项清单定不下来，该词整词标待核，不许先挂关系。

## 3. 每词记录字段（JSON 记录）

一条记录 = 一个词条（按 `bank_id` 寻址），内含逐义项的关系集。字段缺一不可，缺失即标待核：

| 字段 | 说明 |
|---|---|
| `word` / `bank_id` | 词形（小写）与词库 id；内容侧引用只许用 id |
| `senses` | 义项数组，每义项一项（见下） |
| `status` | `verified`（双源互证通过）/ `待核`（未达标），只有 verified 可入产品 |
| `evidence_grade` | 证据等级（见第 5 节分级），如「一级双源互证」 |
| `disputes` | 词典间说法冲突（如一家列为近义、另一家不列）；无则写「无已知分歧」，有则两说并记，不许擅自裁定 |

`senses` 每义项结构：

| 字段 | 说明 |
|---|---|
| `sense_ref` | `{pos, sense_n, gloss_cn, sense_source}`:pos 与词库 `pos_tags` 一致；sense_n 为本层义项编号（动词与义项网络的 n 对齐）；gloss_cn 为该义项中文义；sense_source 为义项划分出处（动词写义项网络文件与条目，其余写词典名 + 条目） |
| `synonyms` | 同义关系数组（可为空，空时必须有 `relation_verdict` 说明，见下） |
| `antonyms` | 反义关系数组（同上） |
| `relation_verdict` | 当某类关系为空时必填：`checked_none`（已按第 5 节查过一、二级来源，确无可登记关系，注明所查词典）——「查无」是正式结论，不是缺项；未查完不得用此值 |
| `confusion_notes` | 中国学生易混注记数组，每条 `{with_word, boundary_cn, source}`:boundary_cn 写清可替换边界（如在哪种搭配/语境下可换、哪种下不可），**必须有词典依据**（学习词典的 which-word / usage 注记栏原文要点），无词典依据的辨析一律不写，不许凭语感自编 |

关系数组中每个伙伴词（partner）结构：

| 字段 | 说明 |
|---|---|
| `bank_id` / `word` | 伙伴词必须能解析到词库 id（见第 4 节挂接规则），词形仅作展示冗余 |
| `partner_sense_n` | 伙伴词在其自身记录中的义项编号——关系是义项对义项，两端都要落义项 |
| `grade` | 分级：同义分 `strict`（该义项上可互换）/ `near`（近义，不可无条件互换）；反义分 `gradable`（可分级对立，如 hot/cold)/ `complementary`（互补对立，如 alive/dead)/ `relational`（反向关系，如 buy/sell、teacher/student) |
| `register` | 语域：`neutral` / `formal` / `informal`，以词典标注为准 |
| `scope` | 使用层级：`primary_ok`（小学段可用）/ `junior_ok`（初中段可用）/ `adult_only`（仅成人层呈现）。判定依据为伙伴词在词库中的 `kebiao_level` / `dolch` / `freq_rank` 与语域标注，按此规则机械判定，不许凭感觉标 |
| `sources` | 出处数组 `{name, detail, url}`，到条目级（见第 5 节） |

## 4. 挂接规则（与词库的契约）

1. **伙伴词必须在库**：每个 partner 必须按 WORDBANK 规则 1 在词库中解析到 id。库外词**不许直接写入关系**：发包方词库的规矩是新词先入再用（规则 2)，本层执行方无权扩库——库外伙伴登记进交付说明的 `out_of_bank` 清单（词 + 出处 + 建议），由发包方裁定是否补词入再补挂。
2. **变形归原形**：伙伴词若为动词变形（词库中带 `verb_form_of` 的条目），关系一律挂其原形条目 id。
3. **对称闭合**：同义 / 反义在义项级互反——A 的义项 x 列 B 的义项 y 为反义，B 的记录中义项 y 必须回列 A 的义项 x。单向出现的关系须在该条 `disputes` 或注记中说明不对称原因（如两端义项划分粒度不同），无说明的单向关系视为记录错误。入模校验器将机检对称闭合。
4. **单向依赖**：本层引用词库 id，词库不反向依赖本层（WORDBANK 规则 4)；本层删除或重建，词库不受影响。

## 5. 核源纪律

**可用来源（按等级）**：

- **一级**：Oxford (OALD)、Cambridge、Longman 三家学习词典的条目页——其义项划分、同义/反义提示栏与 which-word / usage 辨析栏是本层的主要证据。
- **二级**：Collins(COBUILD / English Dictionary)、Merriam-Webster 的条目与同义辨析段落。二级可参与互证，但单独一家二级不足以标 verified。
- **仅作线索，不作证据**：各类 Thesaurus 聚合站（如 thesaurus.com)、WordNet、词频博客与「同义词大全」类页面——可用来发现候选关系，定案必须回到一、二级词典条目核实，线索来源不许写进 `sources`。
- **明确排除**：培训机构与自媒体的「同义替换表」「高分替换词表」类材料——多为词级笼统配对、无义项意识、且常含错误配对（如把 large 与 big 列为全面可替换），命中此类来源的配对一律按未核处理。
- 每条关系至少**两个独立来源互证**才可标 `verified`，其中至少一个为一级。只查到单一来源的，该词标 `待核` 并注明缺什么。
- **查无纪律**:`checked_none` 须实际查过至少两家一级词典与一家二级词典，并在 `relation_verdict` 中逐一注明所查词典名；未查满不许写查无（仿已交付的短语组合数据线口径：查无须注明所查词典）。
- **易混注记纪律**:`confusion_notes` 的每条 boundary 必须能在一级词典的辨析栏找到原文依据（如 Longman 对 say / tell 的搭配辨析、OALD 对 big / large 的 which-word 说明），`source` 到条目级；词典没有明说的边界，不许用执行方的语感补写——宁可不写注记。举例（仅示意所需粒度，执行时仍须按原文复核）：big 与 large 仅在「体积/规模」义上近义，large 不用于「重要」义（a big decision 不说 a large decision)，此类边界以词典辨析栏为准。
- 年代类字段本层没有，但**义项编号是高危字段**:sense_n 与伙伴端 partner_sense_n 必须逐项对得上所引义项清单与义项网络，不许约数糊弄。

## 6. 收词范围、优先级与排除口径

- **总盘子**：显示集 2,351 词全覆盖为最终目标——「覆盖」的含义是每个词都被**裁定过**：或挂有已核关系，或逐义项登记 `checked_none`，或整词待核并注明原因。不许用「没找到关系」冒充已裁定，也不许为凑覆盖率硬配关系。
- **第一批样板批 80–120 词**，验收通过后再扩批。选词优先级（同义辨析教学价值密度从高到低）：
  1. 高频动词与形容词（freq_rank 靠前、教材低年级先行）——辨析价值最高，先行；
  2. `has_polysemy` 多义词与四旗舰词（school / play / light / charge）所在的多义族——义项级纪律的试金石，必须在样板批接受检验；
  3. 名词、副词依次跟进。
- **扩批分波**：按 freq_rank 段与教材年级分波推进，每波交付说明含本波裁定分账（有关系 / 查无 / 待核）。
- **登记排除**（不收，交付说明中列明口径即可，不逐词出记录）：
  - 专名与缩略（词库 `sight_type` 为 `na:proper` 者，如月份、星期、称谓）；
  - 短语 / 多词条目（`na:phrase`)；
  - 动词变形条目（`verb_form_of` 非空者）——关系挂原形条目，变形条目不单独出记录。
- **功能词**（`is_function_word` 者）：照常逐词裁定，但预期多数义项为 `checked_none`；不许为功能词硬配同义 / 反义。

## 7. 交付格式

1. `synonym_antonym_batch1.json`：JSON 数组，每元素一条第 3 节记录。UTF-8，按词形排序。
2. `synonym_antonym_batch1_notes.md`：交付说明，含：实际收词数与分账（有关系 / 查无 / 待核各多少词、多少义项、多少条关系）；`out_of_bank` 伙伴清单（词 + 出处 + 建议）；分歧词清单（词 + 两说摘要）；被排除词与口径清单；义项清单定不下来而整词待核的清单与原因；执行中发现的字段规格问题（如有）。
3. 入模后的定版落位（发包方执行，执行方须知）：数据文件为 `laws-prototype/model/synonym_antonym.json`，活文档为 `laws-prototype/model/SYNONYM_ANTONYM.md`，并在数据总账 `laws-prototype/model/README.md` 登记一行（数据集名 / 文件 / 条数 / 状态）。每批扩批后同步更新三处。

## 9. 验收标准（发包方执行，执行方须知）

- 抽查率不低于 20%：抽中词逐义项、逐关系对出处复核。**高危错误一票否决**：任一已标 verified 的关系在所引出处中查无支持、或挂错义项（如把 discharge 挂到 charge 的「收费」义），整批退回重核。
- 抽查矛盾率门槛：抽查样本中「出处支持但分级/语域/scope 标注有误」类一般矛盾超过 2%，整批退回重核。
- `verified` 记录若被查出只有单一来源、来源打不开、或 `sources` 中混入线索级/排除级来源，整批降级待核。
- 对称闭合机检不过（单向关系无说明者非空）、字段完整率不足 100%（待核条目须在 notes 中说明缺项），均不过关。
- `checked_none` 抽查：抽中者复查其所注明的词典，若任一所查词典实际载有该关系而记录写查无，按高危错误计。

## 10. 与现有系统的挂接（发包方入模口径，执行方须知）

- **消费面**：词汇区词页的「亲戚」栏目（同义 / 反义面）从本层渲染，词页不另行手写第二份关系清单（WORDBANK 规则 3：一词一源）。
- **菜单完备性**（WORDBANK 规则 6）适用于本层：词页「亲戚」栏目呈现的关系集，由本层数据按谓词推导——该词全部义项的全部 verified 关系全量呈现，不许只挑几个「代表」关系；校验器含亲戚栏目完整性检查（页面关系集与本层 verified 集比对，遗漏非空不过关）。待核关系不进展示层。
- **与义项网络的关系**：动词义项的寻址与划分以义项网络为准（第 2 节）；本层若发现网络义项划分与一级词典现状不符，登记进交付说明的问题清单，不许在本层另行改写——由发包方决定是否回修网络。
- **后续练习**：辨析类练习（如「哪个词能替换句中词」）的题目与答案只能从本层 verified 关系生成，生成规则不在本任务范围。

## 11. 红线汇总

1. 不许词级挂接——每条关系必须落到义项对义项，两端编号齐全。
2. 不许凭模型记忆或语感写关系与辨析——每条事实都要落到可打开的一、二级出处；Thesaurus 聚合站与培训「替换表」不作证据。
3. 分歧不许擅自裁定，两说并记；库外伙伴不许私自写入，登记清单交发包方裁定。
4. 核不到就标待核，查无就如实登记查无并注明所查词典——不许降低标准凑满词数，不许为任何词硬配一对关系交差。
5. 本层只存事实与有出处的辨析，不写儿童讲解文案。
