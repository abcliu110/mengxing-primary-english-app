## 啊哈卡（分镜第 0 步）

| 幕 | 孩子先看到 | 先猜 | 揭晓 | 最后才出的「规则」 |
|---|---|---|---|---|
| ① 看图猜词（情景引入） | 一张大图（词条 emoji），右边英文被黄卡盖住 | 这个东西用英语怎么说？（3 秒倒数） | 揭开是本词，读音、音标、中文；音节拆成两色词块分开读，再合上 | 遮英文自测：英文再被盖住（🙈），看图自己说一遍（第 2 个 3 秒停顿）——「看见图就能说出词 = 会了」 |
| ② 词的来历（规律拆解） | **有互证词源**：时间轴最左端是很久以前的写法（如原始日耳曼语 \*fōts）<br>**有真实构词**：两块词块（teach、-er）+ 一个空格子<br>**都没有**：本词字母排成一排，第一个元音字母被盖住（词尾不发音的 e 不盖） | 今天它变成了哪个词？／拼起来是哪个词？／听读音，盖住的是哪个字母？（3 秒） | 词块沿时间轴一站站「换装」成今天的词／两块落进格子拼成本词／揭开字母 | 本族词或外来词（来自 ETYM_DB 的 k）／合成词或加词缀／「这个词的来历两本词源词典还没对上，先不讲」——**不编来历** |
| ③ 排句子（地道应用） | 上面是中文句，下面一堆打乱的英文词块，中间一排空格子 | 按英文顺序哪个词块排第一？（3 秒） | 词块一块块落进格子，整句逐词点亮朗读；本词词块橙色 | 本词在句子里这样用；句法提示（syntax_contrast）、拼写提醒进讲解字幕 |

## 遮字幕测（只看画面能说出什么）

- ①：看到图 → 盖住的卡揭开是一个英文词 → 再被盖住，图还在：能说出「看图说这个词」。
- ②：老写法一站站变成今天的词（时间轴）／两块拼成一个词／盖住的字母是哪个：能说出「这个词是从老写法变来的／是拼出来的／中间那个字母是 a」。
- ③：乱序词块排进格子成一句：能说出这句英文的顺序。

## 知识点不丢（R1 修订）

旧板上的知识点在新模板里的去处（`v5/check_wordcard_tpl.py` 的 `knowledge()` 逐词核对：板上词块 / 标签、讲解字幕、朗读字幕任一处出现即算）：

| 旧板内容 | 新去处 |
|---|---|
| 单词、音标、词性 + 中文 | ① 板上（词块 + 标签）+ 朗读字幕 |
| 音节拆解 | ① 两色音节词块（拼不回原词的词组照原样标出） |
| 「象形词源」 | **删除**（R37-02 已认定为自造，不是词源）；改为 ② 的真实词源链（ETYM_DB，Wiktionary + Etymonline 互证）或真实构词（MORPH_DB） |
| 巧记小故事（etymology / memory_tip） | ② 讲解字幕，明标「💡 巧记（帮助记忆，不是真实词源）」 |
| 记忆联想 memory_assoc | ② 讲解字幕，明标「🧠 记忆联想（非词源）」 |
| 常用搭配动词 / a·the·my + 词 | **删除**（R37-03 模板填充，不是知识点） |
| 例句 + 中文 | ③ 词块排句 + 朗读字幕；占位句（Let's learn and use…）不当例句，改用 This is a/an 本词. 且不出中文 |
| 句法对比 syntax_contrast、拼写提醒 spelling_alert | ③ 讲解字幕 |
| 积木拆词 affix_root（含未核实拆分） | 不上白板（真实构词走 MORPH_DB）；词卡正文照旧显示 |

## 指标

- 每幕 ≥1 个 3 秒预测停顿，规则（C.rule）在第一个停顿之后；不用讲解员姿势；板上文字面积 ≤ 40%（`src/insightcheck.py` 实测 1–17%）。
- 时长 12–24 s / 幕（旧版 30–60 s 逐行写字）。
