- 术语小词典：
  - ☐ 单复数：一个叫单数（a book），两个以上叫复数（three books）。英语的名词要跟着变。
  - ☐ 时态：动词的样子告诉你事情什么时候发生：go（平时）、went（过去）。
  - ☐ 三单：他、她、它一个人做事（第三人称单数），一般现在时的动词要加 -s：She likes cats.
  - ☐ 不规则变化：不按加 -s、加 -ed 的规矩变：child → children，go → went，read → read（读音变）。
