## 1. 定位

- 首页新开「🔀 中英对照总枢」横幅，和「六大第一性原理总枢」「📖 单词身世总枢」并列（放在单词身世横幅下面）。
- 一句话：**中国孩子学英语最常犯的错，大多是把中文的习惯直接搬进英语（负迁移）；也有很多地方中英文本来一样，可以直接用（正迁移）。** 先讲一样的，再讲不一样的。
- 和第一性原理的分工：第一性原理讲「英语自己为什么这样」，本总枢讲「中文和英语哪里一样、哪里不一样」。同一个知识点只放一处，另一处放一句话 + 跳转链接。

## 3. 每幕标准

- 结构沿用溯源幕思路，换成对照版：**① 中文怎么说 → ② 照搬成英语会怎样（标 ❌，错句不朗读，进 `r2skip`）→ ③ 英语怎么说 + 为什么 → ④ 更多例子 → ⑤ 口诀 / 金句卡**，最后 🔮 小预测题（给一句中文，猜英语该怎么说）。
- 徽章：中英对照本身是语言事实，标 📜 只用于有出处的历史说法（如 ze_pronoun 的古英语变格）；记忆比喻（国王、树干树枝）标 💡；为小学生简化的说法标 ✂️。
- R2：画面上每个英文词单读 + 例句，白板上 ≥3 词的正确句子都要朗读；错句、成分标签进 `r2skip`。
- R4：新做的幕从一开始就用引擎 v2 + 讲解员，分镜里列 `actionWords`；搬迁幕第一步「原样搬 + R2」，第二步再升 v2 + 讲解员（升级前保留 `_classic` 回退文件，同 port 做法）。
