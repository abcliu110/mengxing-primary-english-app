# SOP：白板动画（手绘讲解风）

> 适用：王炸实验室里讲「句子结构 / 语法规律」的页签，即重点在文字和结构怎么重新排列的内容。
> 第一个落地的页签：② 竹节句 vs 树干句手术台（`labTab: 'bamboo_tree'`），5 个案例全部完成。
> 有动作、有角色表演的内容（比如动词矩阵）继续用 VV 卡通动画，不套这套风格。

## 1. 风格规范（用户确认过的样子）

- **白板**：画布 960×600。上方 0–544 是白板（米白底 `#fdfdfb` + 30px 浅格子），下方 544–600 是**讲解字幕条**。
- **一笔一笔画**：线条用 `stroke-dashoffset` 逐渐画出来，带轻微手抖（`wl` / `roughRect` / `ellipse` / `cloud`），描完再淡入涂色。
- **写字**：文字用 clipPath 从左往右「写」出来，拿马克笔的手跟着笔尖走；没在写的时候，手退到右下角。
- **布局固定**：
  - 左半边（x < 480）：汉语竹节句 → 圈出动词 → 竹竿 → 中式英语病句 → 红笔标错 → 一句规则。
  - 右半边：英语树干句，地面 → 树干 → 树冠 → 主干牌子（谓语上戴王冠）→ 树枝挂件。
  - 底部（y 448–530）：完整的地道英文句（绿色，谓语下划橙线）+ 中文 + 口诀。
- **配色**：黑 `#1f2937` 正文，红 `#e11d48` 错误/术语，绿 `#059669` 正确/竹子/树冠，棕 `#92400e` 树干/树枝，蓝 `#2563eb` 挂件，紫 `#7c3aed` 括号/修饰，橙 `#f59e0b` 王冠/谓语。
- **字体**：中文 WenQuanYi / 苹方 / 微软雅黑；英文一律等宽 `Courier New`（波浪线、删除线、插入符按每字 0.6×字号定位，换字体会错位）。

## 2. 讲解与术语（必须做）

- 每画一步，字幕条换一句解释：`N("术语：", "解释")`。术语红色加粗，后面是小学生能看懂的大白话。
- **页面里出现的每个难懂术语都要解释**：竹节句、树干句、谓语动词、主干、挂件、马甲、定语、后置、系动词、过去式……
  - 动画里：第一次出现时用字幕条解释。
  - 页面上：动画下方的「📖 术语小词典」。案例 ① 的词条是基础词条，每个案例都会显示；其他案例再加上自己的词条（`terms` 数组）。
- 字幕一句不超过约 48 个汉字；超长会自动缩小字号，但应该先改短。

## 3. 做一个新案例的步骤

1. **看数据**：读 `BAMBOO_TO_TREE_CASES[i]` 的 `zhSentence / chinglish / diagnosis / trunk / branches / englishOk`。动画里的句子必须和数据一致。
2. **写分镜**（5 幕）：竹节句 → 圈动词/括修饰 → 竹竿 → 中式病句标错 → 树干 + 王冠 → 挂件 → 完整句 + 口诀。
3. **写脚本**：在 `docs/whiteboard/src/wb_cases.js` 里加 `{ build(k){...}, terms:[...] }`。
   - 按调用顺序自动排时间（`k.go`），不用手算秒数；需要停顿时用 `k.wait(秒)`。
   - 常用工具：`header / leftHead / rightHead / zh / circle / bracket / bamboo / note / mono / squiggle / underline / strike / caret / above / redX / miniCrown / bolt / tree / sign / chip / arrow / final`，说明见 `wb_engine.js` 里的注释。
   - 坐标：中文按「每字 = 字号」排，`zh()` 返回 `cx(i)` 用来圈字；英文 `mono()` 返回 `x0(词) / x1(词)`。
4. **预览**：打开 `docs/whiteboard/src/preview.html`，或运行 `python3 preview_shots.py /tmp`，看 55% 和结尾两张图，检查**重叠、出界、错位**。
5. **写进主文件**：运行 `python3 insert_wb.py`（按 `// <<WB_ENGINE_START>>` 到 `// <<WB_ENGINE_END>>` 的标记整段替换，可以重复运行）。
6. **验收**（全部通过才提交）：
   - `node --check`：抽出主文件里所有 `<script>` 拼成 `/tmp/m.js` 再检查。
   - `python3 appwb.py /tmp`：在 App 里逐个打开案例，不能有页面错误，SVG 里不能出现 `NaN` / `undefined`。
   - 回归：`/workspace/work/vv/tools/appshot.py 5 2 /tmp/x.png`，确认动词矩阵还正常。
7. **提交**：直接提交到 `master` 并推送，不新建分支；同时更新 `HANDOFF.md`。

## 4. 常见坑

- **涂色盖线**：`F()` 会自动插在最近一笔描边的**下面**（`back` 参数控制往前几笔，树干用 2）。所以色块能盖住后面的树干线，又不会盖住自己的边框。新工具里要先描边再 `F()`。
- **文字量宽**：文字宽度在 `mount` 时用 `getBBox` 量；字体晚加载会在 `document.fonts.ready` 后重新量（`remeasure`）。
- **一句只能一个谓语**：案例 ② 有 and，所以有两个谓语，画两棵树并用 and 搭桥。规则和术语表都写了「没有 and 等连接词时」。
- **离开页签**：播放循环用的是全局 `superLabAnimId`，切页签时 `startSuperLabCanvasLoop` 会取消它；舞台从 DOM 消失时循环也会自己退出。
