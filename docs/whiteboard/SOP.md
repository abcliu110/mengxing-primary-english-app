# SOP：王炸实验室白板动画

> 适用范围：十二大王炸实验室里**所有讲规律的页签**，统一使用白板讲解动画。
> 已完成样板：② 竹节句 vs 树干句（`docs/whiteboard/src/cases/bamboo_tree.js`，5 个案例）。新页签以它为准。
> ① 万能动词×向量转盘继续用 VV 卡通动画，不改。

---

## 1. 风格规范（用户已认可，不要改风格）

| 项目 | 规范 |
|---|---|
| 画布 | 960×600。上方 0–544 是白板（米白底 + 30px 浅格子），下方 544–600 是**讲解字幕条** |
| 画线 | 线条一笔一笔画出来（`stroke-dashoffset`），带轻微手抖；描完边再淡入涂色 |
| 写字 | 文字从左往右「写」出来，拿马克笔的手跟着笔尖走；不在写的时候，手退到右下角 |
| 节奏 | 每个案例 **40–60 秒**，边画边讲，播完自动循环 |
| 配色 | 黑 `#1f2937` 正文 · 红 `#e11d48` 错误/术语 · 绿 `#059669` 正确/结论 · 棕 `#92400e` · 蓝 `#2563eb` · 紫 `#7c3aed` · 橙 `#f59e0b` 重点/王冠 · 灰 `#64748b` 注释（引擎里 `k.C.xxx`） |
| 字体 | 中文用默认 ZH 字体；英文单词、音标、句子用等宽 `MONO`（`k.mono()` 的定位依赖等宽，每字宽 0.6×字号） |
| 版面 | 标题行 y≈52；内容区 y 80–530；**不要画到 y>535**，不要出左右边界（x 12–948） |
| 结尾 | 底部给出本案例的「结论 / 正确答案」（绿色框，`k.final()` 或自己画），字幕给**口诀** |

## 2. 讲解与术语（必须做）

1. **每画一步，字幕换一句**：`N("术语：", "大白话解释")`。术语红色加粗，后面是小学生能懂的话。一句不超过约 48 个汉字。
2. **页面里出现的难懂术语都要解释**：页签标题、卡片文字、案例名里的术语都算，比如 元音、辅音、清辅音、浊辅音、音标、重音、弱读 /ə/、名词、动词、形容词、材质、过去式、时态、进行体、完成体、助动词、情态动词、不及物动词、宾语、表语、宾补、感叹句……
   - 动画里：第一次出现时，用字幕解释。
   - 页面上：每个案例的 `terms` 数组 → 自动生成「📖 术语小词典」。**第 1 个案例放这个页签的基础词条**（每个案例都会显示），其他案例只放自己新出现的词条。
3. 页面原有的比喻（门派、护卫、照妖镜、骨骼、炼金……）要在动画里用一句话说清楚它指什么。

## 3. 内容规则

- **数据一致**：动画里的单词、例句、规则必须和主文件里该页签的数据数组一致（数据导出见 `docs/whiteboard/lab_data.json`，以主文件里的数组为准）。不能自己改例句；数据里明显错了：直接改主文件数据（见第 6 节），并记到交接文档。
- **一个案例 = 页签上一个按钮**（数据数组里的一项）。数组项里条目很多时（比如一个门派 6 个单词），挑 3–4 个画完整过程，其余可以在最后一屏快速列出。
- **先讲为什么，再讲怎么做**：每个案例都要有「问题 → 原理 → 示范 → 结论/口诀」。

## 4. 做一个页签的步骤

1. **读数据和页面**：主文件里搜 `tab === "页签名"`，看页面现有文字；读对应数据数组。
2. **写分镜**：每个案例 5–8 幕，先列出要解释的术语。
3. **写脚本**：新建 `docs/whiteboard/src/cases/<页签名>.js`：
   ```js
   WB_LAB.<页签名> = [
     { build(k) { const { C, N } = k; N("", "开场白"); k.header("副标题", "大标题", false); ... }, terms: [["术语", "解释"], ...] },
     ...
   ];
   ```
   - 时间按调用顺序自动排（`k.go(秒)` 返回开始时间并推进游标），停顿用 `k.wait(秒)`。
   - 引擎工具（`wb_engine.js` 里 `kit()`）：
     - 底层：`P(路径, 开始, 时长, {color,w})` 画线；`T(文字, x, y, 开始, 时长, {size,color,weight,anchor,font})` 写字；`F(路径, 开始, {color,op,back})` 涂色（自动垫到最近一笔描边下面）；`N(术语, 解释)` 字幕。
     - 手绘形状：`wl` 抖动直线、`roughRect` 方框、`ellipse` 椭圆圈、`wave` 波浪线、`cloud` 云朵、`rectD` 填色矩形。
     - 组件：`header / head / zh / circle / bracket / bamboo / note / mono / squiggle / underline / strike / caret / above / redX / miniCrown / bolt / tree / sign / chip / arrow / final`。
     - `k.estW(文字, 字号)` 估算文字宽度，用来排版。
   - 需要新图形（时间轴、音节块、火车车厢、天平……）直接在页签文件里用 `P/T/F` 写小函数，**不要改 `wb_engine.js`**；确实需要通用的新工具，记到交接文档里统一加。
4. **预览**：`python3 docs/whiteboard/src/preview_shots.py <页签名> /tmp/out 0.3,0.6,1.0`，逐张看图：**重叠、出界、文字压线、字幕太长**都要修。浏览器里看动画：`preview.html?tab=<页签名>&case=0`。
5. **写进主文件**：`python3 docs/whiteboard/src/insert_wb.py`（可重复运行；没登记案例的页签会保留旧 Canvas）。
6. **验收**（全部通过才提交）：
   - `node --check`：抽出主文件所有 `<script>` 拼成一个 js 检查；
   - `python3 docs/whiteboard/src/appwb.py <页签名> /tmp/out`：每个案例都要 `mounted: True`、`bad: None`，`errors: []`；
   - 回归：`appwb.py bamboo_tree` 和动词矩阵 `appshot.py 5 2` 仍然正常。
7. **提交**：每做完一个页签提交一次，直接推 `master`，不新建分支；同时更新 `HANDOFF.md` 的进度表。

## 5. 常见坑

- 涂色 `F()` 必须紧跟在它对应的描边 `P()` 后面调用；一个形状有两笔描边（比如树干左右两条线）用 `back: 2`。
- 时间是自动排的：工具调用顺序 = 画的顺序。想让两样东西同时画，用 `k.go(时长, 0)` 拿同一个开始时间，再直接调 `P/T`。
- 中文 `k.zh()` 按「每字 = 字号」排版，含英文或数字的混排行不要用它来圈字。
- 音标里的特殊字符（ʊ ə ː θ ˈ）用 MONO 字体能显示，但宽度可能不准，圈音标时留出余量。
- 引擎在 `mount` 时测量文字宽度，SVG 必须已经在页面里。
