# 欧洲文化密码模块 · 设计文档（讨论稿 v0.2）

> 状态：讨论中，尚未开工。日期：2026-10-29
> 核心观点：很多英语词和习语的「怪」，根子在欧洲（尤其英国）的**气候、地理、生产方式、宗教、神话、历史**。懂了背景，一大片词就讲得通了。
> 关联：路线图 `MODULE_ROADMAP.md` 的 U「用英语讲中国」（两者合起来就是文化双向）、I 星期月份、T 来源比例；实验室 `metaphor_code`（人体、颜色、动物隐喻）。

---

## 0. 教学原则

1. **每个词都配一个中文对照**：一样的、比喻不同的、完全相反的三类（见 §7）。中西对照是这个模块的灵魂。
2. **可信度徽章**（沿用 v0.3 骨架）：
   - 📜 真实词源：holiday = holy day、goodbye = God be with you
   - 🏛️ 文化背景：英国多雨，所以人们爱聊天气
   - ❓ 来源不明 / 多种说法：raining cats and dogs、13 不吉利
3. **宗教内容只作为文化背景来讲**：用「西方人过去普遍信基督教，所以……」这种叙述口吻，不讲教义，不评价。神话同样处理。
4. **去重**：颜色、动物隐喻在 `metaphor_code` 已有，这里只补「为什么」（气候、宗教原因）并链接过去；星期月份并入 I，这里只放神话那一面。
5. **年级**：每一章选 3–5 个低年级就懂的词做「主菜」，其余放进「拓展」。

## 1. 气候篇：一个多雨、少阳光、偏凉的海岛 🌧️

**背景**：英国是温带海洋性气候，常年多雨多云，阳光稀少，夏天凉爽宜人。

| 英语 | 背后的气候 | 中文对照 |
|---|---|---|
| 见面先聊天气：Lovely day, isn't it? | 天气多变，是最安全的寒暄话题 | 中国人见面问「吃了吗？」 |
| **Shall I compare thee to a summer's day?**（莎士比亚） | 英国的夏天凉爽美好，用来比喻爱人 | 中国的夏天是「赤日炎炎」，很少用来夸人 |
| **east wind（东风）**：又冷又干，不受欢迎 | 东风从欧洲大陆吹来，冬春寒冷；西风来自大西洋，温和湿润（雪莱《西风颂》） | 中文「东风」是春风、好运：「万事俱备，只欠东风」。**完全相反！**★ |
| sunny（开朗的）、a place in the sun（好位置） | 阳光稀少，所以阳光 = 珍贵 = 美好 | 中文也有「阳光男孩」，但同时有「烈日」这种负面说法 |
| save for a rainy day（未雨绸缪） | 雨天 = 困难时候 | 未雨绸缪（意思一样，比喻不同）★ |
| under the weather（不舒服） | 天气影响心情和身体 | — |
| raining cats and dogs（倾盆大雨）❓ | 来源不明 | 倾盆大雨 |
| foggy（模糊的）：I haven't the foggiest. | 伦敦雾 | 「一头雾水」★ |
| white Christmas | 北欧和中欧冬天下雪，圣诞配雪景 | 「瑞雪兆丰年」 |

## 2. 地理篇：被海包围的岛国 ⛵

**背景**：英国四面环海，航海、捕鱼、海上贸易塑造了大量说法。对比中国是大陆农耕文明，大量成语来自土地和农事。

| 英语 | 背后的地理 | 中文对照 |
|---|---|---|
| **in the same boat**（处境相同） | 航海 | 同舟共济（中文也有！）★ |
| all at sea（完全不知所措） | 迷失在海上 | 摸不着头脑 |
| plain sailing（一帆风顺） | 航行顺利 | 一帆风顺（巧合一致）★ |
| learn the ropes（学会门道） | 水手学习帆船缆绳（常见解释） | 入门、摸清门道 |
| on board / welcome aboard（加入团队） | 上船 | — |
| the coast is clear（没人了，安全了） | 海岸上没人巡逻 | — |
| a drop in the ocean（沧海一粟） | 海 | 沧海一粟（几乎一样）★ |
| **like a fish out of water**（浑身不自在） | 捕鱼文化 | 「如鱼得水」是它的反面 ★ |
| There are plenty more fish in the sea.（天涯何处无芳草） | 海里鱼多 | 天涯何处无芳草 ★ |
| **对比**：拔苗助长、守株待兔、胸有成竹 | — | 中文来自土地和农事 |

**一句话总结**：英语爱用海，中文爱用土地。这和 T 来源比例、格林定律一起，构成「英语从哪来」的地理底色。

## 3. 生产与饮食篇：小麦、奶酪、牛羊和马 🍞🐑🐎

**背景**：欧洲冷凉，适合种小麦、放牧牛羊；马是骑士和农耕的主力。中国南稻北麦，以耕牛为主。

| 英语 | 背景 | 中文对照 |
|---|---|---|
| **bread and butter**（生计、饭碗） | 面包黄油是主食 | 饭碗、「混口饭吃」★（主食不同） |
| breadwinner（养家的人） | 挣面包的人 | 顶梁柱 |
| the best thing since sliced bread（最好的东西） | — | — |
| butter sb. up（拍马屁） | 往人身上抹黄油 | 拍马屁（马又出现了） |
| Say cheese!（拍照说「茄子」） | 奶酪 | 中国人拍照说「茄子」★ |
| black sheep（害群之马） | 放牧 | 害群之马（羊 vs 马）★ |
| until the cows come home（很久很久） | 放牧的牛傍晚才回家 | — |
| straight from the horse's mouth（消息可靠） | 看马的牙齿判断年龄（常见解释） | — |
| Don't look a gift horse in the mouth.（别挑礼物的毛病） | 同上 | — |
| on one's high horse（摆架子） | 骑士骑高头大马 | 趾高气扬 |
| not my cup of tea（不合我的口味） | 茶从中国传到英国后，成了英国国饮 | 中国的茶反过来进入了英语 ★（tea 来自闽南话 te） |

## 4. 宗教篇：基督教留下的日常词 ⛪

**背景**：过去欧洲人普遍信仰基督教，很多日常词就这样来的。（只作为文化背景讲。）

**📜 真实词源（藏在日常词里）**
- **holiday** = holy day（神圣的日子）
- **goodbye** = God be with you（愿上帝与你同在），慢慢缩成了 goodbye
- **Christmas** = Christ + mass（基督的弥撒）
- **Halloween** = All Hallows' Eve（万圣节前夜；hallow = holy）
- **Valentine's Day**：纪念圣瓦伦丁

**🏛️ 习俗**
- 别人打喷嚏，要说 **Bless you!**（中国人有时说「有人想你了」）
- **Sunday 休息日**：一周的安排和中文「星期日」来历不同（并入 I）

**📖 来自《圣经》故事、已经变成日常习语的**
- **olive branch**（和平的橄榄枝）：鸽子衔回橄榄枝的故事。中文「橄榄枝」就是从英语来的 ★
- **a good Samaritan**（乐于助人的好心人）
- **Adam's apple**（喉结）
- **forbidden fruit**（禁果，越不让碰越想碰）
- **a wolf in sheep's clothing**（披着羊皮的狼）。中文同样的说法也来自这里 ★
- **speak of the devil**（说到谁谁就来）↔ 说曹操，曹操到 ★★（经典对照）

**数字**
- **13 不吉利**❓（说法很多，常见的是和「最后的晚餐」有关）↔ 中国人忌讳 4（谐音「死」）★

## 6. 历史与社会篇：国王、骑士和姓氏 👑

- **姓氏来自职业**📜：Smith（铁匠）、Baker（面包师）、Taylor（裁缝）、Miller（磨坊主）、Cook（厨师）、Fisher（渔夫）、Carpenter（木匠）
- **姓氏来自血缘**📜：Johnson = son of John、Mc / Mac（苏格兰，意思是「……的儿子」）
- **对照**：中国姓氏多来自封地、官职、祖先名号。姓名顺序是「名在前、姓在后」（并入 R）
- **£ 符号**📜：来自拉丁语 libra（磅）的首字母 L
- **knight / castle / crown / king-size**：城堡和骑士文化
- **用刀叉吃饭**，中国用筷子：餐桌文化对比

## 7. 文化对照的三种关系（总结图）

1. **一模一样**（文化相通）：同舟共济 ↔ in the same boat、沧海一粟 ↔ a drop in the ocean
2. **意思一样，比喻不同**：害群之马 ↔ black sheep、说曹操 ↔ speak of the devil、未雨绸缪 ↔ save for a rainy day
3. **完全相反**：东风、龙（欧洲的 dragon 是邪恶的怪兽，被屠龙骑士圣乔治打败；中国的龙象征吉祥）、红色（中国喜庆；英语 in the red = 亏损）、白色婚礼 ↔ 中国传统白色用于丧事

★ 第 3 类最容易造成误解，应该放进总结幕重点讲。

## 12. 「词根文化溯源幕」：标准动画结构

所有带文化背景的词根，统一按 5 步做一幕（≤ 90 秒）：

1. **地图定位** 🗺️：在简化的欧洲或地中海地图上，点亮这个词诞生的地方（罗马、希腊、英格兰……）

3. **词族生长** 🌳：场景里的每个动作「长出」一个词，挂到词根树上
4. **现代彩蛋** ✨：这个词根今天藏在哪些品牌、地名、科技词里

## 13. 示范幕：port —— 地中海的港口

### 13.1 词源事实（📜，制作前需核对 etymonline）
- 拉丁语里有两个相关的词，同出一个更古老的词根（原始印欧语 *per-，意思是「穿过、渡过」）：
  - **portus = 港口**（也和 porta「城门」同源）
  - **portare = 搬运**
- **直接来自「港口」的**：port（港口）、airport（空中的港口）、**passport**（通过港口或城门的许可）、**opportunity**（拉丁语 ob portum，原指「把船吹向港口的顺风」，所以有「好时机」的意思）★
- **来自「搬运」的**：import（运进来）、export（运出去）、transport（运过去）、report（带回来）、support（从下面托着）、portable（能搬的）、porter（搬运工）、important（「运进来的东西」→ 有分量的）
- **教学处理**：两条线用同一个港口场景串起来——船靠港，工人把货搬进搬出。但要标注：「港口」和「搬运」是两个亲戚词，不是同一个词（徽章：📜 真实词源 + 💡 场景串联）。
- **现有数据核对**：词库里 airport、passport、import、export、important、report、support、transport、sport 都已有 `port (港/运)` 家族串记，方向正确。sport 来自 disport（de + portare，把自己从工作中「搬开」→ 娱乐），可以作为彩蛋。

### 13.2 地理背景
- 地中海被欧洲、亚洲、非洲三块陆地环抱。**Mediterranean = medi（中间）+ terra（陆地）**，意思是「陆地中间的海」📜
- 罗马帝国靠地中海航运连接各地，港口就是贸易、旅行和机会的入口
- 对照中国：古代运输更多依靠运河和陆路（大运河、丝绸之路），所以中文「码头」「关口」里有「水」和「关」

### 13.3 分镜（6 个镜头）
1. **地图**：地中海亮起，Mediterranean 拆成 medi + terra，三块陆地向中间靠拢。（`fade` / `move`）
2. **船进港**：罗马商船驶入港口，港口亮起 **port**。顺风箭头把船推进港 → 弹出 **op-portunity：顺风进港 = 好机会** ★（`arc` 风线）
3. **搬运工**：porter 扛货。货箱往城里走，出现 **im-port**；往船上走，出现 **ex-port**；从一个港口运到另一个港口，出现 **trans-port**；消息带回城里，出现 **re-port**。每个前缀用方向箭头表示，衔接 ⑤ 向量律
4. **城门盖章**：旅人在港口或城门口出示文书，盖章 → **pass-port**
5. **穿越到现代**：船变成飞机，港口变成机场 → **air-port**；集装箱变成手提箱 → **port-able**
6. **定格总结图**：中间是港口，两条线分出来（港口线 / 搬运线），中文对照「码头、关口、出口、进口」

- -port / -mouth：港口、河口（Newport、Portsmouth、Plymouth）
- -ford：可以涉水过河的浅滩（**Oxford = 牛过河的地方**）📜
- -ham / -ton：村庄、农庄（Birmingham、Southampton）
- **Portugal**：来自港口城市 Portus Cale（今天的波尔图一带）📜，正好和 port 呼应 ★
