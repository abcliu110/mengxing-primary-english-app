# SOP：六大第一性原理总枢 · 白板动画（白板 + 演示道具）

> 适用范围：首页横幅「英语『大道至简』六大第一性原理总枢（融会贯通沙盘）」进入后的 `first_principles_hub` 视图，6 条原理 × 4 幕 = **24 段动画**。
> 基础规范完全沿用 `docs/whiteboard/SOP.md`（画布、配色、字体、字幕、术语小词典、验收、提交方式）。**本文只写与王炸实验室不同的地方。**
> 分镜见 `STORYBOARD.md`，进度见 `HANDOFF.md`。

## 1. 方案选择（2026-10-29 定）

| 方案 | 结论 | 原因 |
|---|---|---|
| 纯白板（同王炸实验室） | 作为底子 | 风格统一；引擎现成；适合「问题 → 推导 → 结论」 |
| Lottie / 视频 / 3D 库 | 不用 | 要外部素材流水线，主文件是单个离线 HTML，数据驱动，改一个例句就要重做素材 |
| **白板 + 会动的演示道具** | ✅ 采用 | 有些幕讲的是身体感觉和空间，光画线讲不透：声带震不震、双唇闭合、一刀切开、点/面/体、上公交 vs 钻进小车、镜头从小拉到大、令牌从动词跳到侍卫 |

**原则**：道具也是「手绘风」（抖动线、马克笔描边、淡入涂色），不能出现和白板风格冲突的写实图、渐变、阴影。

## 2. 与王炸实验室的不同点

| 项目 | 王炸实验室 | 第一性原理总枢 |
|---|---|---|
| 登记键 | `WB_LAB.<labTab>` | `WB_LAB.<原理 id>`：`fp_economy / fp_iconicity / fp_boundedness / fp_one_king / fp_vectors / fp_zoom_focus` |
| 案例序号 | 页签自己的 idx | `fpState.actIdx`（第几幕，0–3）；原理用 `fpState.lawIdx` 找 id |
| 每段时长 | 40–60 秒 | **35–55 秒**（每幕只讲一个点，下面还有对照表和沙盘题） |
| 结构 | 问题 → 原理 → 示范 → 结论 | **问题（常见错误或疑问）→ 道具演示「为什么」→ 2–3 个例子套用 → 一句话原理 + 口诀**。最后一屏要回扣这条原理的总公式 `mentalFormula` 里对应的那一句 |
| 文件 | `cases/<页签>.js` | `cases/fp_<原理>.js`，共 6 个文件；道具写在 `cases/fp_props.js`（6 个文件共用） |
| 画布位置 | 替换 `superLabCanvas` | 替换 `firstPrinciplesCanvas`（740×320 → 白板 960×600），页面上方的 `topBanner` 条和下方「本幕核心推导例句」条**保留不动** |
| 动画循环变量 | `superLabAnimId` | `fpAnimId`（见第 5 节，不能和实验室共用一个 id，否则切页签互相取消） |

## 3. 演示道具（`cases/fp_props.js`）

道具 = 一个小函数，用 `P/T/F` 画静态部分，用**引擎 v2 的动效**（第 4 节）做会动的部分。只在 6 个 fp 文件里用。

| 道具 | 用在 | 画法 | 会动的部分 |
|---|---|---|---|
| `mouth(x,y,o)` 口腔侧面图 | ① 全部 4 幕 | 简笔侧脸：嘴唇、舌头、上颚、喉咙里的声带（两条短线） | 声带：`buzz` 抖动 + 旁边「🔊/🔇」；嘴唇：开/合两帧切换；舌尖位置点亮 |
| `gate(x,y)` 守门员 | ①-4 | 音节方块 + 小人站门口 | 第二个辅音「关门」：门板旋转 |
| `letterMorph(ch, pic)` 字母变画 | ②-1 | 先写大字母，再在同一位置描出山/蛇/包/杯 | 字母淡出、图画描出（交叉淡化） |
| `knife(x,y)` 一刀切 | ③-1、③-4 | 苹果/面包/鸡的简笔画 + 刀 | 刀沿虚线划下，物体分成两半（左右平移 8px） |
| `ring / target` 画圈与靶心 | ③-2 | 一堆小狗/笔，任意圈一个 → 靶心锁定 | 圈出现、靶心十字缩小锁定 |
| `building(x,y)` 外壳 vs 功能 | ③-3 | 学校楼房轮廓（外壳）↔ 书本+铅笔图标（功能） | 外壳描边亮起 / 消失 |
| `throne(x,y)` 王座 | ④-1、④-2 | 王座 + 皇冠 | 两个动词抢王座：被挤下去的那个画红叉 |
| `token(x,y)` 令牌 | ④-3 | 金色小圆牌写 `-s` / `-ed` | 令牌沿弧线从动词飞到 Does/Did |
| `dims(x,y)` 点·面·体 | ⑤-1 | 0D 点、2D 纸面、3D 盒子（等轴测线框） | 依次描出；小人/时间标签落进去 |
| `vehicle(kind)` 公交 vs 小车 | ⑤-3 | 公交侧面（能站人）、小汽车（矮顶） | 小人走上去（站直）/ 弯腰钻进去 |
| `vec(x1,y1,x2,y2,kind)` 方向箭头 | ⑤-2、⑤-4 | to 实心箭头、from 反向、for 虚线指向靶心；on 贴合、off 分离 | 物体贴上/弹开（平移） |
| `zoom(cx,cy,s)` 镜头 | ⑥-3 | 取景框四个角 | **整块白板缩放**：从最小的点慢慢拉远到最大 |
| `xmasTree` 挂件树 | ⑥-1 | 核心名词是树干，短语是挂件 | 挂件依次挂上 |
| `spotlight` 聚光灯 | ⑥-2 | 句首聚光圈 | 疑问词从句尾跳到句首 |
| `timeGrid` 时间轴 × 镜头 | ⑥-4 | 复用 `cases/tense_matrix.js` 的时间轴画法（复制过来改，不要跨文件引用） | 镜头图标切换 |

## 4. 引擎 v2：动效（先做，单独提交）

现在的引擎只会「画出来 / 写出来 / 淡入涂色」，没有移动、抖动、缩放。做道具前先在 `wb_engine.js` 的 `kit()` 里加一组**按时间计算、可拖动进度条**的动效（render(t) 里算位置，不用 setInterval）：

| 工具 | 作用 |
|---|---|
| `k.group(开始)` | 开一个分组，之后画的元素放进这个 `<g>`，返回组 id |
| `k.move(组, 开始, 时长, dx, dy, {ease})` | 分组平移（令牌飞、刀划、物体分开、疑问词跳句首） |
| `k.arc(组, 开始, 时长, 路径)` | 沿路径移动（令牌飞弧线） |
| `k.buzz(组, 开始, 时长, 幅度)` | 小幅抖动（声带震动），幅度 0 = 不震 |
| `k.fade(组, 开始, 时长, 到)` | 分组淡入/淡出（字母变画、外壳消失） |
| `k.rot(组, 开始, 时长, 角度, cx, cy)` | 旋转（守门员关门） |
| `k.camera(开始, 时长, x, y, 缩放)` | 整块白板（不含字幕条）的取景框缩放平移（镜头拉远） |

要求：
- 进度条拖到任意时刻，画面都要正确（动效全部是 t 的函数）。
- 加完先在 `bamboo_tree` 和 `tense_matrix` 回归，确认旧案例画面不变，再单独提交「引擎 v2」。
- 拿笔的手：动效进行时手退到右下角，不跟着动。

## 5. App 接线（新增）

- `wbStageHtml(tab, idx)` 里的 `<svg id="wbStage">` 在总枢页里会和实验室重名：总枢用 `wbStageHtml(lawId, actIdx, false, "fpWbStage")`，给函数加第 4 个参数 svg id（默认 `wbStage`）。
- `startFirstPrinciplesCanvasLoop()` 开头：如果找到 `#fpWbStage`，走 `startWBLoop(stage, "fp")`，动画 id 记在 `fpAnimId`；否则走原来的 Canvas（没做完的原理保持旧画面）。
- 术语小词典：放在「本幕核心推导例句」条下面（`wbGlossHtml(lawId, actIdx)`）。
- `insert_wb.py`：`READY` 加 6 个 fp id，`case_files` 加 `fp_props.js`（必须排在 6 个 fp 文件前面）。
- 预览/验收脚本：`preview_shots.py fp_economy …` 直接可用；App 验收新写 `appfp.py <lawIdx> <输出目录>`：进入 `first_principles_hub`，逐幕点「下一幕」，每幕检查 `mounted / bad / errors / NaN`。

## 7. 做一条原理的步骤

1. 读 `FIRST_PRINCIPLES_DB` 里该原理的 4 幕（`label / topBanner / subEn / subZh / cards`）和 `mentalFormula`、`unifiesList`、`quiz`。
2. 对照 `STORYBOARD.md` 该原理的分镜；分镜和数据不一致时，**以主文件数据为准**，改分镜。
3. 写 `cases/fp_<原理>.js`，4 个案例，`terms` 第 1 幕放该原理的基础术语。
4. 预览截图 0.25/0.5/0.75/1.0 四张，看重叠、出界、字幕长度、道具动效在拖动进度条时是否正确。
5. `insert_wb.py` → `node --check` → `appfp.py` → 回归（`appwb.py bamboo_tree`、`appshot.py 5 2`）。
6. 提交推送 `master`，更新 `HANDOFF.md` 进度表。
