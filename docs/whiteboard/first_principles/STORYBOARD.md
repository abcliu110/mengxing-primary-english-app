## ① 口腔省力同化律 `fp_economy`

**基础术语（第 1 幕 terms）**：音素、元音、辅音、清辅音、浊辅音、声带、音标、复数、三单、过去式、同化。

### 1-1 为什么 -s 和 -ed 都有三种读音？（≈50 秒）
1. 问题：白板写两排 `books /s/ · bags /z/ · buses /ɪz/`、`worked /t/ · played /d/ · wanted /ɪd/`，字幕「两套规则要背 6 种读音？其实只有一条」。
2. 【道具 mouth】画口腔侧面 + 喉咙里的声带。手按喉咙示意。字幕「声带：喉咙里两片小肉，说话时可能震动」。
3. 【动 buzz】读 /k/：声带不动，标 🔇「清辅音：声带不震」；读 /ɡ/：声带抖动，标 🔊「浊辅音：声带震」。
4. 套用：`book` 尾音 /k/ 🔇 → 尾巴跟着 🔇 读 /s/；`bag` 尾音 /ɡ/ 🔊 → 尾巴 🔊 读 /z/。箭头「顺势」。
5. 同一条线套到 -ed：`worked /t/`（🔇）、`played /d/`（🔊，元音都震）。
6. 留一个钩子：`buses / wanted` 用灰色写「?」，字幕「第三种读音，下一幕讲」。
7. 结论绿框：「清配清，浊配浊：尾巴跟着前一个音的声带走」。口诀：**前音不震尾不震，前音一震尾也震。**

### 1-2 为什么 s/sh/ch/x 加 -es，t/d 加 -ed 多读 /ɪ/？（≈45 秒）
新术语：摩擦音（嘶嘶音）、舌尖音、吞音。
1. 问题：写 `bus + s`，读成「bus-s」——两个 /s/ 粘成一个，听不出复数。画两个圆圈撞在一起变成一个（红叉）。
2. 【道具 mouth】标出 /s/ 和 /s/ 舌尖在同一个位置，字幕「发音位置一模一样 → 粘成一个音，叫吞音」。
3. 插入小方块 /ɪ/ 把两个音隔开：`bus | ɪ | z` → `/ˈbʌsɪz/`。
4. 套用 `watch → watches /ˈwɒtʃɪz/`、`box → boxes`。
5. 同理 -ed：`want + t` 粘住 → 插 /ɪ/ → `/ˈwɒntɪd/`；`need → needed /ˈniːdɪd/`。
6. 结论绿框：「尾音和词缀撞车 → 插 /ɪ/ 隔开」。口诀：**同位相撞，插个 /ɪ/ 来帮忙。**

### 1-3 为什么 a 变 an？in- 变 im-？（≈50 秒）
新术语：冠词、前缀、鼻音、双唇音。
1. 问题：读 `a apple`，两个元音中间「卡一下」（画波浪 + 小停顿符号）。
2. 加 /n/ 当小桥：画一座小拱桥 `an | apple`，字幕「/n/ 像小桥，让气流顺过去」。
3. 判断看「第一个音」不看字母：`an hour`（h 不读，划掉 h，标 /aʊ/）、`a useful book`（u 读 /j/，是辅音 → 用 a）。
4. 【道具 mouth · 动】`in + polite`：读 /p/ 时双唇先合上；嘴唇两帧切换「张 → 合」。
5. /n/ 被提前合上的嘴唇「带成」/m/：`in` 的 n 擦掉改写成 m → `impolite`；套用 `impossible`。
6. 结论绿框：「元音撞元音加 /n/ 架桥；/p b m/ 前 n 变 m」。口诀：**元音前面搭座桥，双唇前面 n 变 m。**

### 1-4 为什么 run 变 running 要双写 n？（≈50 秒）
新术语：音节、闭音节、开音节、短元音、长元音、双写。
1. 问题：写 `run + ing`，学生写成 `runing`。
2. 【道具 gate】把 `run` 画成一个音节房间：辅音 r / 元音 u / 辅音 n，n 是守门员，字幕「闭音节：元音被辅音关在门里，读短音」。
3. 不双写：`ru | ning`，n 被后面的 -ing 拉走，门开了，u 跑出来读长音 /uː/（红叉，写「像 ruling 里的 u」）。同样 `ta | ping` 读成 tape 的 /eɪ/。
4. 【动 rot】双写：派第二个 n 来，门关上：`run | ning`，u 保住短音 /ʌ/。
5. 套用 `swim → swimming`、`big → bigger`、`hot → hottest`、`stop → stopped`，每个圈出被双写的字母。
6. 结论绿框：「辅元辅 + 元音尾巴 → 双写最后的辅音，保住短元音」。口诀：**辅元辅，加尾巴，派个守门员看家。**

## ② 字母象形与音义同源簇 `fp_iconicity`

**基础术语**：字母、象形、辅音丛（辅音连缀）、词根、词源、音义联想。
**讲法提醒**：这条原理里「字母象形」「音义同源簇」很多是**帮助记忆的联想**，不是严格的词源（见 HANDOFF §4）。字幕措辞用「可以想成…」「像…」，不说「来源于…」，tw- 那幕除外（tw- = two 是真词源）。

### 2-1 M / S / B / C 像什么？（≈45 秒）
1. 问题：「字母只是符号？试试把它当成一幅画。」
2. 【道具 letterMorph · 动 fade】大写 M → 描成两座山 → 再描成上下嘴唇；旁边写 `mountain · mouth`。
3. S → 一条弯弯的蛇 / 水波；写 `snake · swim · smile`（画一张弯弯的笑脸）。
4. B → 鼓起来的包；写 `bag · box · bed · baby`。
5. C → 一只弯着抓杯子的手；写 `cup · cap · catch`。
6. 结论绿框：「看字母形状，帮你记住一串词」。口诀：**M 是山，S 是蛇，B 是包，C 来抓。**

### 2-2 fl- 飘 · gl- 亮 · sl- 滑（≈50 秒）
1. 问题：写 `fly flag flower`，字幕「三个词开头都是 fl-，巧合吗？」
2. fl-：吹一口气（画气流线），旗子飘起来；连 `fly · flag · flower`。
3. gl-：画闪光的玻璃杯（星星线）；`glass · glad`（笑脸发光）。
4. sl-：画滑梯，小人滑下来；`slide · slow · sleep`（眼睛慢慢闭上）。
5. 三列并排，开头字母用三种颜色圈出。
6. 结论绿框：「开头的辅音丛常常带着同一种感觉」。口诀：**fl 飞，gl 亮，sl 滑下来。**

### 2-3 str- 绷直 · sp- 向外（≈45 秒）
1. 问题：`straight street strong strict` 四个难词，一个画面记住。
2. 画一根两头拉紧的绳子（越拉越直），字幕「str- 三个辅音挤在一起，读起来像拉紧的绳子」。
3. 绳子变成一条笔直的大街（street）→ 绷紧的手臂肌肉（strong）→ 一把直尺（strict 严格）。
4. sp-：从中心向外放射的线；`speak`（嘴里向外的声波）、`sport`、`space`（星星向外）、`spring`（小芽冒出来）。
5. 结论绿框。口诀：**str 拉直线，sp 往外喷。**

### 2-4 tw- 家族都等于 2（≈45 秒）
新术语：词源。
1. 问题：「为什么 12 是 twelve，20 是 twenty？」
2. 写大大的 `two = 2`，圈出 tw。
3. 树形展开：`twelve = 2 + 10`（十个手指 + 剩下 2 个）、`twenty = 2 × 10`、`twice = 两次`、`twin = 双胞胎`（画两个小人）。
4. `between = be + twain`：画两棵树，中间站一个人，字幕「在两个之间」。
5. 结论绿框：「看到 tw-，想到 2」。口诀：**tw 一出现，成双又成对。**

## ③ 物理边界感统摄律 `fp_boundedness`

**基础术语**：名词、可数名词、不可数名词、单数、复数、冠词、量词（容器词）。

### 3-1 一刀切测试法（≈50 秒）
1. 问题：「为什么 bread、paper、homework 不能加 s？」
2. 【道具 knife · 动 move】苹果一刀切开 → 两半不再是「一个苹果」，标「有边界：可数」。
3. 一块面包切开 → 两块还是面包；一杯水倒一半 → 还是水。标「没边界：不可数」。
4. paper、homework：字幕「撕开还是纸；作业是一大类，不是一个个」。
5. 想数怎么办？给它套容器：画杯子 `a glass of milk`、纸张 `two pieces of paper`，**-s 加在容器词上**（圈出 pieces 的 s）。
6. 结论绿框：「切开就坏 → 可数；切开不变 → 不可数，用容器来数」。口诀：**一刀下去还是它，不可数来不加 s。**

### 3-2 a 就是 one，the 就是 that（≈45 秒）
新术语：定冠词、不定冠词。
1. 公园里画 4 只小狗。写 `There is a dog in the park.`
2. 【道具 ring】随便圈一只，旁边写 `a = one`，字幕「第一次说，还没指定是哪只」。
3. 【道具 target · 动】圈变成靶心锁定同一只：`The dog is running.`，写 `the = that`，字幕「我们都知道是哪只」。
4. 世上只有一个：画太阳 `the sun`；房间里唯一的门 `Open the door, please!`
5. 结论绿框。口诀：**第一次见用 a，大家都知道用 the。**

### 3-3 go to school vs go to the school（≈50 秒）
新术语：零冠词。
1. 问题：两句并排，差一个 the。
2. 【道具 building · 动 fade】画学校楼房：`go to the school` → 楼房外壳亮起，小人是家长去开会。
3. 楼房淡出，只剩书本和铅笔：`go to school` → 「去上学（做学校该做的事）」。
4. 同理三组快速套用：`in bed`（睡觉）vs `on the bed`（床上面）、`by bus`（坐车的方式）vs `on a bus`、`play football`（运动）vs `buy a football`（一个球）。
5. 结论绿框：「看得见的实物加冠词；只讲做什么事不加」。口诀：**说楼房加 the，说上学不加。**

### 3-4 chicken 既可数又不可数（≈45 秒）
1. 左边画一只活蹦乱跳的小鸡：`a chicken`，右边画盘子里的鸡肉：`some chicken`。
2. 【道具 knife · 动】小鸡变成鸡肉：外框（边界）虚掉，字幕「一只鸡有完整边界；鸡肉没有」。
3. 套用：`a glass`（杯子）vs `made of glass`（玻璃材料）；`a room`（一个房间）vs `make room for you`（腾出空间）；`two fish` vs `some fish`（鱼肉）。
4. 结论绿框：「有完整外壳就可数，变成材料就不可数」。口诀：**整只能数，切成肉就不数。**

## ④ 一山不容二虎单核谓语律 `fp_one_king`

**基础术语**：谓语动词、be 动词、实义动词、形容词、主语、助动词。

### 4-1 为什么不能说 I am like apples？（≈45 秒）
1. 写错句 `I am like apples.`，am 和 like 下面画两顶皇冠。
2. 【道具 throne · 动 move】两个国王抢一个王座，打架（抖动），字幕「一个句子只能有一个谓语动词国王」。
3. 路线 A：like 下台 → `I like apples.`（动作王）；路线 B：换形容词 → `I am happy.`（状态王，happy 不是动词，需要 am 撑腰）。
4. 结论绿框。口诀：**一个句子一个王，be 和 do 不同堂。**

### 4-2 第二个动词怎么办？穿马甲（≈50 秒）
新术语：不定式 to do、动名词 doing。
1. 写错句 `I want go home.`，go 没地方坐。
2. 【道具 throne】want 坐王座，go 穿上「to 马甲」：画一个向右的箭头 → `I want to go home.`，字幕「to 像指向将来的箭头：想做、打算做」。
3. 第二件马甲 doing：`I enjoy reading.`、`She is swimming.`，画循环箭头「正在做 / 享受过程」。
4. 套用：`plan to visit · hope to see`、`finish doing · good at drawing`。
5. 结论绿框：「王座只坐一个，其他动词穿 to do 或 doing」。口诀：**想做穿 to，在做穿 -ing。**
（数据卡片只讲了 to do / doing 两件；topBanner 提到的 done 用一句字幕带过，不展开。）

### 4-3 令牌守恒：does/did 来了，动词变原形（≈50 秒）
新术语：动词原形、一般疑问句、否定句、情态动词、三单。
1. 写 `She likes apples.`，-s 画成金色令牌。
2. 【道具 token · 动 arc】变疑问：Does 跳到句首，令牌从 like 飞到 Does 头上 → `Does she like apples?`，like 变回原形。
3. 过去令牌：`She went home.` → `Did she go home?`：went 的「过去令牌」飞给 Did，went 变回 go。
4. 否定和情态：`He doesn't play.`、`She can swim.`——令牌在侍卫手里，后面永远原形。
5. 结论绿框：「一句只有一块令牌，侍卫拿了，动词就变原形」。口诀：**侍卫拿令牌，动词回原形。**

### 4-4 五副基本骨骼（≈50 秒）
新术语：宾语、表语、补语、双宾语。
1. 字幕「再长的句子，去掉装饰，只剩 5 副骨骼」。画 5 行骨架方块。
2. ① S+V `Birds fly.` ② S+V+P `The cake smells delicious.` ③ S+V+O `I love my family.`
3. ④ S+V+IO+DO `Pass me the book.`（画两个靶：人 → 物）⑤ S+V+O+C `Reading makes me clever.`
4. 字幕「动词像插线板，决定后面能插几个部件」。
5. 结论绿框。口诀：**先搭骨架再挂花。**

## ⑤ 三维几何向量时空律 `fp_vectors`

**基础术语**：介词、维度（0 维点 / 2 维面 / 3 维体）、短语动词、方向。

### 5-1 at 点 · on 面 · in 体（≈55 秒）
1. 问题：`at 7:00 · on Monday · in May`，为什么三个不一样？
2. 【道具 dims · 动】依次描出：一个点（0 维）、一张纸（2 维）、一个盒子（3 维）。
3. 空间：小人站在门口这一点 `at the door`；书放在桌面 `on the desk`；人在房间里 `in the room`。
4. 时间：钟面上一个刻度 `at 7:00`；日历上一页 `on Monday / on Children's Day`；一大段时间像盒子 `in May / in summer / in 2026`。
5. 结论绿框：「点 at，面 on，体 in；时间和空间一个道理」。口诀：**点钟 at，哪天 on，月季年份都用 in。**

### 5-2 on 贴上 · off 分开（≈45 秒）
1. 问题：「take off 为什么既是脱衣服，又是飞机起飞？」
2. 【道具 vec · 动 move】外套贴到身上 `put on`；开关触点接上 `turn on`（灯泡亮）；脚踏上公交 `get on`。
3. 反方向弹开：鞋子离开脚 `take off`；飞机离开跑道 `takes off`；灯灭 `turn off`；`get off · fall off`。
4. 结论绿框：「贴上、接通用 on；离开、断开用 off」。口诀：**贴上 on，分开 off。**

### 5-3 get on the bus vs get in the car（≈45 秒）
1. 两辆车并排：公交（高、能站人）、小汽车（矮顶）。
2. 【道具 vehicle · 动 move】小人走上公交，站直走动：`get on the bus`，字幕「能站着走的车，当成一个平面」。
3. 小人弯腰钻进小汽车坐下：`get in the car`，字幕「要弯腰钻进去的，当成一个盒子」；出来 `get out of the car`。
4. 套用：`on the train / plane / ship`；骑在上面 `on a bike / on a horse`；`in a taxi`。
5. 结论绿框。口诀：**站着上车用 on，弯腰钻进用 in。**

### 5-4 to · for · from 三个方向箭头（≈50 秒）
1. 画三种箭头：to 实线箭头直达终点、from 从起点出发、for 虚线指向靶心（还没碰到）。
2. `listen to me`：声波一路传到耳朵；`go to school`、`give a book to me`。
3. `come from China`、`borrow from you`（书从你那里离开）vs `lend to`（书到别人那里）。
4. `look for my pen`：眼睛虚线朝着目标找，还没找到；`wait for the bus`、`buy a cake for mom`。
5. 对比 `look at`（目光打在一点）· `look for`（找）· `look after`（跟在后面照看）。
6. 结论绿框。口诀：**to 到终点，from 离起点，for 心里想着它。**

## ⑥ 焦点先行与镜头缩放律 `fp_zoom_focus`

**基础术语**：修饰语、核心名词、短语、语序、疑问词、感叹句。

### 6-1 长修饰放名词后面（≈50 秒）
1. 中文：「树下那个穿蓝衣服的男孩」，字幕「中文先说一大串，最后才说男孩」。
2. 【道具 xmasTree】英文先立树干 `the boy`，再挂挂件 `[in blue]`、`[under the tree]`。
3. 一个词的轻修饰放前面：`a red apple · a cute cat · my English book`。
4. 两个词以上挂后面：`the girl in a red dress`、`the book on the teacher's desk`、`something important`。
5. 结论绿框：「一个词放前，两个词以上放后」。口诀：**先立树干，后挂树枝。**

### 6-2 疑问词抢句首（≈45 秒）
1. 中文：「你周末打算去【哪里】？」疑问词在后面。
2. 【道具 spotlight · 动 move】Where 从句尾跳到句首，聚光灯打在它身上；are 跟着提到主语前：`Where are you going this weekend?`
3. 套用：`Where is my bag?`、`When do you get up?`、`How much is this shirt?`
4. 感叹句：`What a clever boy (he is)!`、`How fast (he runs)!`，括号里的部分变灰（可以省略）。
5. 结论绿框：「最想知道、最想夸的词放第一个」。口诀：**焦点先出场。**

### 6-3 镜头从小拉到大（≈50 秒）
1. 中文地址：北京 → 星光学校 → 3 号楼 → 201 室，字幕「中文从大到小推镜头」。
2. 【道具 zoom · 动 camera】镜头先对准一扇门 `Room 201`，慢慢拉远：`Building 3` → `Star School` → `Beijing`，同心圆一圈圈画出来。
3. 写出整句：`I am in Room 201, Building 3, Star School, Beijing.`
4. 时间同理：钟 `at 9:00` → 那天上午 `on Tuesday morning` → 月份 `in September`。
5. 结论绿框：「英语从小到大，中文从大到小，正好相反」。口诀：**英语拉镜头，从小到大走。**

### 6-4 3 段时间轴 × 3 种拍法（≈55 秒）
新术语：时态、一般态、进行态、完成态、时间信号词。
1. 画时间轴：过去 ◀ 现在 ▶ 将来。
2. 三个镜头图标：📸 快照（一般态）、🎥 录像（进行态）、🏁 结算（完成态）。
3. 快照：`every day → do/does`、`yesterday → did`、`tomorrow → will do`，在时间轴上点出位置。
4. 录像：`Look! / now → be + doing`；结算：`already / just → have/has + done`。
5. 结论绿框：「先看时间选位置，再看拍法选动词形式」。口诀：**先选时间，再选镜头。**
（和王炸实验室 ⑨ 时态矩阵重叠：只做总览，不逐格讲；数据只给 5 格，不画满 3×3。）
