### 决策 13　按需加载（仍然双击即用）
- 目标：点到哪个模块才载入哪个模块；**仍是单个 HTML、双击就能用，不需要服务器**。
- 方案：
  1. 每个模块的白板脚本（`cases/*.js`）写成不执行的 `<script type="text/plain" id="wbmod-<模块>">`（可选再压缩成 base64 + gzip，浏览器用 `DecompressionStream` 解压，不支持时退回不压缩版本）。
  2. 第一次进入模块时 `wbLoadModule('<模块>')`：取出文字 → 生成 `<script>` 执行 → 登记 `WB_LAB`；之后不再重复加载。
  3. 大数据（如 `VOCAB_DB` 以外的模块数据）同理分块；首页只载入首页需要的部分。
  4. `insert_wb.py` 负责打包；验收加「首屏可交互耗时」对比（Playwright 记录，前后不能变差）。
- 不用 `fetch` 读外部文件（`file://` 下会被拦），所以全部内容仍在同一个 HTML 里。
- **进度（2026-10-29）**：✅ 已完成——19 个白板模块 + VV 动画素材（1.7 MB）改为按需加载；未做 gzip 压缩（解压是异步的，会让渲染变异步，收益小）。首页可交互 256.7 → 237.9 ms（沙箱中位数），64 幕渲染逐字节不变。词库数据首页要用，暂不分块。

## 2.6 人物动作库（决策 19）

> 规则 R4：句子里有动作词，画面上就要有人做这个动作，和朗读同步（读到 carry，小人正在搬）。
> 演员：讲解员小人（决策 16，形象待用户确认）或场景角色（搬运工、旅客、公主……），都用同一套简笔骨架，所以动作可以共用。

**骨架**：圆头 + 躯干 + 两段式手臂（上臂、前臂）+ 两段式腿（大腿、小腿），关节用角度描述；一个「姿态」= 一组关节角度，一个「动作」= 几个姿态按时间插值（全部是时间 t 的函数，进度条拖到哪都正确）。可以拿道具（箱子、卡片、书、文书），道具挂在手上跟着走。

**动作库 v1（可复用、可扩展）**

|---|---|---|
| 走 walk | go、come、walk、pass through | 左右腿交替迈步 + 手臂摆动，整体平移 |
| 跑 run | run、hurry、race | 步子更大、身体前倾、手臂弯曲大幅摆动 |
| 搬 carry | carry、port「搬运」、import / export / transport | 弯腰抱起箱子 → 直起身 → 抱着箱子走 |
| 拿 take | take、get、pick up | 伸手 → 握住 → 收回胸前 |
| 放 put | put、put down、put away | 手往前下方伸 → 松手 → 物体留在原处 |
| 指 point | look、this / that、here / there | 一只手伸直指向目标，头转向目标 |
| 举 hold up / lift | hold up、lift、show、support（从下面托住） | 双手举过头 / 托在物体下面 |
| 跳 jump | jump、hop | 下蹲 → 腾空 → 落地回弹 |
| 转身 turn | turn、turn around、turn back | 身体左右翻转（镜像） |

- `k.scene("house" | "classroom" | "park" | "kitchen" | "street", { x, ground })`：地面线 + 2–4 个参照物（房子带门、黑板课桌、树和长椅、灶台餐桌、马路斑马线）；单色墨线 + 浅色填充（V3）；场景组随镜头擦除。
- 门是可动部件（开 / 关），in / out / into / out of 都以门或房子轮廓为参照。

### E. 样板（D6）：「He takes the dog out.」
分镜：① 屋里：男孩站在门内，狗趴在旁边（简笔房子剖面 + 门）→ ② **take**：男孩弯腰从挂钩拿起牵绳（预备：伸手；发力：抓住；结果：牵绳在手）→ 扣到狗项圈上，狗站起摇尾巴 → ③ 男孩推开门（门转开）→ ④ **out**：男孩牵着狗走出门到门外小路，狗沿路径跟随、牵绳下垂随动 → ⑤ 定格：男孩和狗在门外，门开着；朗读「He takes the dog out.」与 ②–④ 同步。验收：和用户参考插画并排截图对照，人物动作、宾语、方向三样都看得出来才算达标。

## 2.9 白板动画标准画法 v5.1（决策 31 定稿，用户 2026-10-30 10:54 确认「完美，就这样」）

> 样板：`takeout_wb/v51/`（`He takes the dog out.`，提交 `368f1e4`）。新幕一律照这个画法做；与 §2.5–§2.8 冲突处以本节为准（§2.7 运动品质、§2.8 动词表 / R4v2 仍有效）。

### A. 画布与画风
| 项 | 规格 |
|---|---|
| 画布 | Canvas 2D，世界坐标 1920×1080，30 fps 等效；播放器按容器缩放 |
| 底色 / 墨线 / 强调 | 白板 `#FBFBFB`；墨线 `#0A0503` 约 6 px；**只有一种强调色** 橙 `#EF7226`（浅橙 `#E9A67C` 只作辅助） |
| 字体 | 中文手写 WK 子集、英文 Kalam（woff 内嵌，按需子集化，约 7 KB） |
| 场景线条 | rough.js：`roughness ≈ 1.0–1.6`、`bowing ≈ 1.2–2`，**种子固定**（每次画出来一模一样）；填充只用 hachure 排线（`hachureGap 14`、`angle -41`），描完线再淡入 |
| 场景内容 | 只画讲清动词必需的东西（例：房子 + 门 + 画框 + 狗碗）；不画满屏装饰 |

### B. 人物 = 关键姿势帧（不用代码画人）
- 每个动词动作 **3 帧**：准备 → 发力 → 结果（样板：k1 弯腰拿钩 / k2 扣项圈 / k3 起身狗跳）。
- 位移动作用 **4 帧循环**：走路 w0–w3、小跑 / 狗跑 d0–d3；**按走过的距离换帧**（每 50 世界像素换一帧），不按时间换，避免滑步。
- 来源：AI 生成绿幕图 → `build_assets.py`（Pillow / NumPy）抠图、去溢色、找锚点（脚底 `bottom`、水平锚点 `ax`、手 `hand`、项圈 `collar` 等）→ WebP data URI。
- 关键帧之间允许硬切（有限动画），但**同一角色比例、脚底线不变**；人与道具的连接（牵绳等）用锚点实时连线（二次曲线 + 下垂量随距离变化）。
- 结果帧留在画面上，不收回。

### C. 镜头节奏（一句一幕，约 12 秒，四拍）
| 拍 | 时间（样板） | 做什么 |
|---|---|---|
| ① 立场景 | 0–3 s | rough 线条按顺序画出（笔尖跟着走）、地点标签（如「家里」）、之字形笔触揭开人物准备帧 |
| ② 动词重音 | 3–5.5 s | 快推（约 0.3 s，`power3.inOut`，放大 ≈2×）到动作接触点；准备 → 发力 → 结果换帧；橙圈圈住接触点 + 动词橙字弹出（`back.out`）；**弹字随后缩小让到角落，不挡人物**；橙圈在角色离开前淡出，不留空圈 |
| ③ 运动 / 方向 | 5.5–9 s | 拉回中景 + 横移跟随；走路帧库；**跨边界那一刻**（门线）弹出方向词（`out!`） |
| ④ 总结 | 9–12.5 s | 手画橙箭头、逐字手写 `take out / 带……出去`；拉远看全图，背景浅灰收尾，整句再念一遍 |

### D. 时间轴与播放器
- 画面是纯函数 `drawFrame(ctx, t)`：**只由 t 决定**，可任意拖动、逐帧出片。
- GSAP：`gsap.timeline({paused:true})`，只用 `tl.time(t)` 取值（镜头 x/y/z、跟随权重、弹字、走路进度、间距、收尾灰度），时间轴永远不自己跑。
- rough.js 的线条先展开成折线（`flatten`，贝塞尔细分 10 段），才能「画到一半」并让笔尖跟随；两遍描边同时推进，模拟马克笔。
- huashu-art-motion：笔、逐字手写、之字形揭开（`DG.zigzag` + `revealMask`）、`B.pop` 弹字。
- App 内播放：自写 `requestAnimationFrame` 循环（▶/❚❚、拖动条、点画面暂停、循环），**不带 React / Remotion Player**；Remotion 只在开发端导出 MP4 / 截图。
- 字幕：底部整句逐词点亮，动词与方向词用橙色，和朗读同时。

### E. 英文朗读（R2）
- Web Speech API，`en-US`，语速 `0.85`，优先自然音色（Samantha / Google / Microsoft / Natural）。
- 朗读点写在场景文件的 `CUES`：动作时分段念（`He takes` → `the dog` → `out!`），总结时念词组（`take out`），最后整句自然念一遍。
- 上一句没念完就到下一个点：时间轴停住等，最多 4 秒；暂停 / 拖动 / 循环立即停止朗读。
- 🔊/🔇 开关，状态存 `localStorage.wbVoice`；**所有 localStorage / speechSynthesis 访问必须包 try/catch**（预览框 sandbox iframe 里会抛错，整段脚本停掉——2026-10-30 实际踩坑）。
- 浏览器要求用户先点一下才出声，所以不自动播放；没有语音的设备照常播放、看字幕。

### F. 体积与性能预算
- 单句一幕单文件 ≤ 650 KB（样板 616 KB：角色帧约 467 KB 为主）；rough.js + GSAP + 播放器共用，并入 App 时只打一份。
- 帧图用 WebP，按显示尺寸缩放后再内嵌；不内嵌未用到的帧。
- 控制台 0 报错，包括 sandbox iframe 和 `file://` 打开两种情况。

### G. 文件结构（每幕照抄样板）
`<case>/v51/scene*.js`（场景 + 时间轴 + CUES）、`player*.js`（播放器，可共用）、`build*.mjs`（esbuild 打单文件）、`shots*.py`（Playwright 9 时间点联络表）；产物 `out/<case>.html` + `out/<case>_keyframes.png`。

### H. 不做
手写 SVG 小人 / 骨骼绑定；讲解员手势顶替场景角色动作（R4v2）；多个强调色；弹字长期压在人物上；结果帧收回；画面依赖实时时钟或随机数（种子必须固定）。

## 2.7 商业动画标准（决策 22，用户 2026-10-29：白板动画也要达到商业动画标准）

V1–V8 是「白板味」；本节是「动画质量」——对标商业儿童教育动画（如 Duolingo、Khan Academy Kids、RSA Animate 级白板视频）的运动品质。适用于每一幕、每个角色和每个元素。

### A. 动画十二法则落地（人物和元素都要）
| # | 法则 | 本 App 的做法 | 验收 |
|---|---|---|---|
| M1 | 预备（anticipation） | 跳、跑、扔、举之前先反向蓄力 0.1–0.2 秒（下蹲、后摆） | 大动作前都有蓄力帧 |
| M2 | 挤压与拉伸 | 弹出的卡片/词块落地压扁再回弹；小人跳起拉长、落地压缩，体积不变 | 弹出、落地不是刚体硬停 |
| M3 | 跟随与重叠 | 马尾、领巾、衣摆、书包带比身体慢半拍停下；手臂比躯干晚到 | 停下时有余摆，不是全身同时冻结 |
| M4 | 缓入缓出 + 分类缓动 | 禁止线性移动（进度条除外）；出现用回弹、移动用缓入缓出、强调用轻微过冲 | 代码里无裸 linear |
| M5 | 弧线运动 | 手、头、抛物都走弧线，不走直线 | 轨迹截图是弧 |
| M6 | 次要动作 | 讲话时小人有眨眼、点头、手势；待机时呼吸起伏、偶尔眨眼（3–5 秒随机） | 小人永不完全静止 |
| M7 | 时间与节奏 | 关键动作 0.3–0.6 秒，强调停留 ≥0.8 秒，避免全程同速；镜头节奏「快-慢-停」 | 不出现所有动作同一时长 |
| M8 | 夸张与表演 | 表情和姿态比真人夸张 20–30%；关键情绪（惊讶、恍然大悟、得意）有专门表情 | 情绪点有对应表情切换 |
| M9 | 剪影清晰 | 每个关键姿态只看剪影也能认出动作 | 关键帧剪影测试 |
| M10 | 姿态到姿态 + 中间帧 | 关键姿态由骨架插值，关节按层级旋转（肩→肘→手），不是整张图平移 | 无「纸片平移」式动作 |
| M11 | 秩序与吸引力 | 一次只让一个焦点在动，其他元素安静；视线引导（小人看向/指向下一个焦点） | 同屏不超过一个主运动 |
| M12 | 嘴型对口播 | 朗读时口型按语音节奏切换（闭/半开/全开），句末闭嘴 | 朗读时嘴在动，停读即停 |

### B. 技术硬指标
- 60fps 目标、任何时候不低于 50fps（中档笔记本 Chrome）；不掉帧、不闪烁、无布局抖动。
- 高 DPI 清晰：SVG 矢量，线条在 2× 屏不发虚。
- 时间轴可暂停、可拖动、可重播，拖到任意时刻画面正确（无状态残留）。
- 动画与朗读同步误差 ≤ 0.2 秒（以朗读 onstart/onend 事件驱动，不靠估算时长）。
- 尊重「减少动态效果」系统设置：降级为淡入，内容不缺。

### C. 制作流程补充（商业流程）
1. **分镜带时间码**：每个镜头写清时长、焦点、小人姿态、口播句、动作词。
2. **动画样片（animatic）**：先出低保真时间轴预览确认节奏，再精修。
3. **精修**：按 M1–M12 逐条加；
4. **录屏审片**：每幕录一段视频（或逐秒截图）自审，对照 A、B 两表打勾；
5. **用户审片**：第一个达标幕（port）给用户看升级前后对比，用户认可后作为「样板幕」，其他幕对齐样板。

### D. 不通过的典型
人物整张平移滑动、所有东西同时出现、线性匀速、停下时全身同时冻结、小人静止站桩、口型不动、朗读和画面错位、掉帧卡顿。
