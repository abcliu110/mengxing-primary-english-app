- **a / an**（rule）：按词首第一个音选择：元音音 → an，辅音音 → a（hour 看音、useful 看音）
- **in-（不）**（prefix）：在唇音 p、b、m 前同化为 im-：impolite、impossible
- **in-（入）/ inborn / input**（exception）：不是「不」职，不套同化：拼写读音不变（ph-xc-inborn-input）

不变量：
- a/an 的判断依据是音不是字母：h 不发音按元音算，/j/ 开头按辅音算
- 同化只对表示「不」的 in- 成立；判断顺序：先分职，后同化
- 本幕只展开 im- 一支，il-、ir- 不作例证（模型口径：留待后续）
