# 事实表 · gen_stock_irregular_plural_2（生成器导出，逻辑审查对照）

- **child → children、ox → oxen**（词表）：加 -en 组；本幕注明古英语有一类词复数加 -en、现在常用的只剩这几个；锚例句 One child, two children. One ox, two oxen.
- **sheep → sheep、deer → deer、fish → fish**（词表）：单复数同形组，一只和一群写法一样，本幕注明很多是动物名字；锚例句 One sheep, ten sheep. One deer, five deer. One fish, many fish.
- **leaf → leaves、knife → knives、wolf → wolves**（词表）：f 或 fe 变 v 再加 es 组；例外对照 roof → roofs 只加 s，本幕提醒遇到新词查一查
- **person → people**（单词）：换个词组：复数常用 people，完全换了一个词；锚例句 One person, many people.
- **例句 There are three sheep on the farm.**（例句）：本幕预测揭晓句：三只羊仍写 sheep，不加 s

不变量：
- 不加 s 的复数在本幕分四种：加 en、不变、f 变 ves、换个词（本幕口诀原文：孩子牛加 en，羊鹿鱼不变，叶刀狼变 ves，人换 people）
- 同形组与特殊变形在模型中同属不规则复数分组：sheep、deer、fish 单复数同形，child→children 列入特殊变形组（模型主张 g02-irregular-groups）
- f 或 fe 结尾只有一小队常用词变 ves，其余只加 -s；名单封闭，不得按像不像类推名单外的词，本幕 roof→roofs 即此例（模型主张 g01-ves-list 及其 boundary；本幕✂️不全是）
- 这批老词是古英语遗留的高频词、保留老样子，名单外不可类推（模型主张 g02-etym 及其 boundary）
