# 事实表 · gen_stock_hd_relations_1（生成器导出，逻辑审查对照）

- **look at（看的过程）**（单词）：目光投过去的过程；锚例句 Look at the sky! 并注明未必看见
- **see（看见的结果）**（单词）：画面进眼睛的结果；锚例句 I can see a bird! 并注明看见了
- **watch（专注盯看）**（单词）：专注盯移动屏幕或比赛；搭配 watch TV、watch a game
- **read（看文字）**（单词）：看文字书报地图；搭配 read a book、read a map

不变量：
- 汉语一个『看』按动作过程与结果拆分：look at 管过程，see 管结果（本幕开场判据）
- 四个『看』分工不得互换：watch 限专注盯移动屏幕或比赛，read 限文字书报地图（本幕台词分工）
- 收尾恒例同句对照过程与结果：Look at the tree, I can see a bird!（本幕收尾判据）
