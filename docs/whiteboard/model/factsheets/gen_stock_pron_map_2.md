- **牙齿组音标 /θ/ /ð/**（词表）：舌尖夹在牙缝发音；例词 think、this，锚例句 I think this is fun.
- **牙床组音标 /t/ /d/ /s/ /z/ /n/ /l/**（词表）：舌尖顶住上牙后面的牙床发音；例词 ten、dog、sun、zoo、nose、leg
- **上颚组音标 /ʃ/ /ʒ/ /tʃ/ /dʒ/ /r/ /j/**（词表）：舌头往后抬向硬上颚发音；例词 ship、measure、chair、jam、red、yes
- **软腭与喉组音标 /k/ /g/ /ŋ/ 与 /h/**（词表）：舌根抬起碰软腭发 k、g、ng，喉咙轻轻呼气发 h；例词 cat、go、sing 与 hat
