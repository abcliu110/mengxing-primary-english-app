- **动词变形对 He goes / He went**（句型）：本幕标注 goes 为三单 -s，went 为过去式，同主语 He 下并置两形
- **冠词对照 I like cat.（误）与 a cat / cats**（例句）：本幕把无冠词的单数 cat 句打叉，给出加 a 的单数式与复数 cats 两改法
- **连词对 because / so**（词表）：本幕标注二者互斥，不得在同一对因果句中双用
- **存在与拥有对 There be / have**（句型）：本幕在铁律行标注二者互斥，不得拼作同一种有

不变量：
- 一般现在时肯定句里主语是第三人称单数时动词加 -s 或 -es：o 结尾加 -es，故 He goes；does 出场后实义动词恢复原形，-s 转由 does 承担（模型同源主张 g19-third-s；例外 xc-g19-does）
- because 与 so 干同一件活，同一对句子只能选一种接法，两个一起用等于把同一件事接了两遍（模型同源主张 g15-because-so）
- 汉语的有分两轨：某地有某物用 There be，某人拥有某物用 have 或 has，两轨不交叉，不存在 There have 这种拼法（模型同源主张 g36-there-vs-have）
- 单数可数名词指称具体事物时要亮明身份用冠词，但这不是无条件铁律：泛指活动与功能读法可零冠词，本幕 a cat 属指具体一只的读法（domains 裁定 dom-countability-articles 与 dom-contrast-pitfalls；模型同源主张 g06-zero-activity）
