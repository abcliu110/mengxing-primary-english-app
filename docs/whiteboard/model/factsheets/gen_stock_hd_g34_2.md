- **感叹句三大公式**（句型）：本幕公式卡：What + a / an + 形容词 + 单数可数名词；What + 形容词 + 复数 / 不可数名词（绝不加 a）；How + 形容词 / 副词 + 主谓
- **例句 What beautiful flowers they are! What fine weather it is!**（例句）：What 组的例句对：flowers 为复数、weather 为不可数，均不加 a
- **例句 How fast he runs!**（例句）：How 组的例句：感叹副词 fast

不变量：
- 感叹名词用 What，感叹形容词用 How：单数可数名词用 What + a/an，复数与不可数名词只用 What 不加 a/an，形容词或副词用 How（g34-exclamatory）
- 本幕口诀：感叹句看尾巴，先把主谓划掉它；剩下核心是名词用 What，剩下只是形容词或副词一律用 How（本幕判据）
