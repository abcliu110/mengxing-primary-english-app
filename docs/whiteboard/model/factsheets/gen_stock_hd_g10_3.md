# 事实表 · gen_stock_hd_g10_3（生成器导出，逻辑审查对照）

- **例句 Would you like some juice? Can I have some bread, please?**（例句）：邀请问句与请求问句都保留 some，本幕称黄金特例
- **例句 There isn't any milk in the fridge. Would you like some tea instead?**（例句）：前半否定句用 any，后半邀请问句用 some，同组对比默认分工与特例
- **例句 Can I have some water, Mum?**（例句）：常错句 Can I have any water, Mum? 在本幕被订正为 some；Mum 为台词点名的称呼

不变量：
- 黄金特例：邀请、请求的问句仍用 some，盼着对方说 Yes（本幕判据）
- 请求与邀请问句用 some 是强偏好不是铁律：用 any 并非语法错误，只是语气中性、疏远；不得把 any 版请求句设为改错题的错句（g10-request-some；xc-g10-any-ok）
- 默认分工恒为肯定句用 some，否定句与一般疑问句用 any，特例只限邀请与请求问句（g10-basic-split）
