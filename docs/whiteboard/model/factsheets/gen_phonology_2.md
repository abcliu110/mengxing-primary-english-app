# 事实表 · gen_phonology_2（生成器导出，逻辑审查对照）

- **bus / watch / box / kiss**（example）：词尾为嘶嘶音 → 加 -s 时插 /ɪ/，读 /ɪz/，拼 -es
- **want / need**（example）：词尾为 /t/、/d/ → -ed 插 /ɪ/，读 /ɪd/（与嘶声插音同理）
- **goes / potatoes**（exception）：拼 -es 却读 /z/：词尾不是嘶嘶音，-es 只是 o 结尾拼写习惯（ph-xc-goes-potatoes）

不变量：
- 插音只发生在词尾为嘶嘶音（s、z、sh、ch、/dʒ/）或 /t/、/d/ 时
- 不是吞掉一个音，而是多加一个 /ɪ/：音节数只增不减
- 拼 -es 不等于读 /ɪz/，判断先看词尾音、后看拼写
