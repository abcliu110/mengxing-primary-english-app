# 事实表 · gen_stock_five_patterns_p2_3（生成器导出，逻辑审查对照）

- **例句 We planted twenty young trees on Tree Planting Day.**（例句）：本幕金句：We 是主语，planted 是谓语，twenty young trees 是宾语，on Tree Planting Day 是时间挂件；planted 直接射中宾语，中间什么都不加
- **直达宾语短语 discuss the plan / marry her / enter the room**（短语）：本幕『画蛇添足』判据例：及物动词直接接宾语，不加介词
- **宾语制服 to do / doing**（句型）：本幕定义：两个动词连用时，第二个要换成 to do 或 doing 才能当宾语；锚例句 I want to buy a dictionary, and I enjoy reading stories.

不变量：
- 及物动词恒直接接宾语、不加介词：乱加介词是画蛇添足（本幕判据）
- 第二个动词作宾语恒穿制服 to do 或 doing，具体穿哪件由前面的动词决定（本幕台词；模型主张 g40-one-finite、st-cl-verb-decides）
- 盼着将来去做的事用 to do：want / plan / hope / decide + to do（本幕词表；模型主张 st-cl-verb-decides）
