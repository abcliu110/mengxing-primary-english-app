- **例句 I don't have any crayons. Do you have any?**（例句）：前句否定用 any，后句一般疑问也用 any，同组呈现 any 的两个地盘
- **例句 Do you have any comic books? Yes, I have some.**（例句）：问句用 any，肯定答句换回 some
- **some / any 常规分工卡**（规则）：肯定：I have some storybooks.；否定：I don't have any crayons.；疑问：Do you have any?（本幕分工卡原样）

不变量：
- some 与 any 都可接可数名词复数或不可数名词；默认分工恒为肯定句用 some，否定句与一般疑问句用 any（g10-basic-split）
- 问答恒守分工：any 用于发问，肯定答句用 some 回（本幕判据：问答对）
- 例外方向恒定：邀请与请求问句盼对方说 Yes 时仍用 some（g10-request-some；本幕口诀）
