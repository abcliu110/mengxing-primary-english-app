# 事实表 · gen_phonology_1（生成器导出，逻辑审查对照）

- **声带（发音器官）**（organ）：静止（清）/ 震动（浊）两态，画面抖动与所发音同步
- **词尾 -s / -ed**（suffix）：读音未定 → 只由前一个音清浊定为 /s//z/ 或 /t//d/
- **books / bags**（example）：前音清 → 尾读清 /s/；前音浊 → 尾读浊 /z/（③ 同化段喉咙演示）
- **stopped / played（模型例 ph-ex-stopped-played）**（example）：-ed 与 -s 对等演示：/p/ 不震 → /t/；元音 /eɪ/ 震 → /d/（④ 过去式段）
- **aged / learned（模型例外 ph-xc-aged-learned）**（exception）：作形容词时读 /ɪd/，习惯保留，不按清浊选（④ 段末上屏）
- **dogs**（example）：收尾 🔮 预测：/ɡ/ 震 → -s 读 /z/，孩子先猜后揭晓
- **buses / wanted**（example）：只在开场作钩子出现（/ɪz/、/ɪd/），本幕不展开，插音在第 2 幕

不变量：
- 尾巴读音只由前一个音的清浊决定，不由拼写字母决定
- 声带可视化与发音同步：清音时声带静止、浊音时声带震动冒波纹
- 判定不早于证据：-s 与 -ed 各有一对例子过完喉咙剖面演示，规则卡（C.rule）才出现
- 步骤条六步依次点亮且与进程同步：④ 在 -ed 段起点、⑤ 与口诀旁白同刻、🔮 在收尾 dogs 预测起点
- 答案指示同一时刻不矛盾：音注出现『→ /z/』不早于答案卡 swap 时刻
- 本幕不设『省力』统一律：只讲清浊顺行同化这一台机关
