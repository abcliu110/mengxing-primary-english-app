# 事实表 · gen_phonology_4（生成器导出，逻辑审查对照）

- **run / swim / big / hot / stop / sit**（example）：辅元辅 + 重读 + 元音起首后缀 → 双写末尾辅音，短元音不变
- **visit / open**（exception）：重音不在末音节 → 不双写（ph-xc-doubling-unstressed）
- **fix / snow**（exception）：w、x、y 结尾 → 不双写（ph-xc-doubling-wxy）
- **hopping / hoping**（contrast）：双写与否是拼写记号：双写标短音，不双写标长音

不变量：
- 双写只改拼写、不改读音：双写前后词的读音里辅音只有一个
- 双写是倾向不是铁律：重音位置与 w/x/y 排除条件先行检查
- 英式 travel→travelling 的 l 双写为例外名单，本幕未展开（模型已登记 ph-xc-doubling-british-l）
