# T7 领域纲领 v1 · 说明（domains.yaml 导读）

`model/domains.yaml` 共 **13 条纲领**：任务清单的 12 个领域中，「词义与框架」自词汇域拆出独立成域（理由：Fillmore 框架语义是独立的真机制，与词源史分属两条线，混编会重蹈旧库"一个故事包打一切"的假统一病）；其余 11 个领域与清单一一对应。每条纲领的 unifies 均逐项对应已入模/已修正的真实记录 ID（grammar 的 g*、boundedness 的 cl*/xc*、VF-*/sf-* 编号、frameworks 的库内条目号、expressions 的 EXP_*），无虚列。重叠共管处（如 g03/g06 同属语法域与可数性域）在条目内已注明。

## 每条纲领一句话 + 它推翻的旧库代表性说法

| 纲领 | 一句话 coreView | 推翻的旧说法（代表） |
|---|---|---|
| 词汇与词源 | 来历必须可溯源：查得到的是真词源，查不到的只能是帮记的联想，联想永不冒充来历。 | MH 词源字段的 watch「注视→手表」、news「东南西北缩写」等联想冒充词源 |
| 语法（形态与句法） | 形式跟着功能走：每种形式变化都在替听话人传递一条信息，学语法 = 学形式在干什么活。 | G19 三单 -s「勋章转移」补偿叙事、G28「焦点先行思维」自造标签等六处假机制 |
| 可数性与冠词 | 形式跟着看法（识解）走：先决定看成一个个还是一摊，数法与冠词随之而定；汉语量词是正迁移资源。 | 「物理边界感统摄律」与 G03「没有固定形状，所以不能加 a 或 -s」（旧库三份拷贝） |
| 时态与体 | 时态 = 时间（过去/非过去）× 看法（镜头放哪）：全景、钻进事件、对准留给现在的痕迹；将来是借来的表达，不是"体"。 | 时态矩阵的「将来体」命名与现在完成时口诀「过去做完」 |
| 介词 | 每介词一个原型场景（in 容器 / on 面 / at 点），其余用法都是从原型推出来的亲戚，时间用法是借图。 | T09 时长轴定义（>1 天 in、=1 天 on、<1 天 at）——被自家 in the morning / at night 推翻 |
| 句型构式 | 模具本身带意思：双宾模具自带"让某人收到"，动词填进去会被模具染色。 | 句型③「80% 动词及物」伪统计、句型②「turn 管颜色、get 管天气」虚构分工 |
| 疑问与信息结构 | 疑问词按"缺哪块信息"分工、词形有真词族出身（*kʷo- vs *to- 两大家族）；语序是信息包装，焦点常落句尾。 | T05「wh- 换 th-/h- 即得回答词」伪构词律、Where「w+here」拆字 |
| 语音与拼读 | 无单一机制，三条真依据组织：拼读对应是统计倾向（系统拼读为骨干）、节奏是连续统、发音的"为什么"多在真实音变史里。 | 「同位相撞」自造术语、闭音节 a「永远发 /æ/」、音节计时/重音计时二分定论 |
| 词义与框架 | 词义活在场景里：buy/sell/pay/cost 是同一幕买卖戏换机位，先认戏再认词。 | FR09「on foot 因为脚踩地面接触所以用 on」伪因果注脚 |
| 日常表达与会话 | 无单一机制，按言语行为组织：回应句的对错不在句子本身，在它跟角色与上文合不合。 | 全库第三轮按场景机械填充的收尾句（29 条错误中 26 条同源） |
| 写作 | 写作是请读者看一幅画：说清楚、加细节、排顺序；公式是支架不是炼金术。 | 「炼金术」框架「一键炼成 100 分」「95% 考场作文逃不出三大母题」伪统计 |
| 隐喻与文化 | 概念隐喻是真思维习惯（讲映射必写失效边界），习语谚语多是文化存货——三类分开标，不能推的明说背下来。 | 「密码」体例把隐喻/习语/谚语混装成可破译系统、second-hand 归类错位 |
| 易错与对比（中英差异） | 错误集中在汉语没有或不一样的地方，按系统差异点组织；把倾向说成铁律本身就是最大的易错源。 | 维度 5「单数可数名词绝要加冠词铁律」（与自家零冠词内容跨库自相矛盾）、fish「绝不加 s」 |

## 诚实标注

- 三个领域（语音与拼读、日常表达与会话，以及部分采"双机制"表述的词汇域）没有单一机制，coreView 已如实声明组织方式——这是按质量纪律刻意为之：假统一正是本次重写要根除的病。
- 时态域的认知语法讲法证据内部不一致（研究 D 节），纲领 basis 中已标注"方向有据、低龄待验"；词源精细加工对儿童的证据为成人外推，同样已标注。
- 语法纲领由 grammar.yaml 草案校订收编（coreView 保留原表述，unifies 由散文改为 ID 清单，conflicts 拆为三条）；两处文本今后以 domains.yaml 为准，grammar.yaml 草案保留作历史。
