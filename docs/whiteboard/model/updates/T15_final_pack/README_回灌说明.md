# T15 最终回灌包 · 使用说明

## 这是什么

把 T16 定版后的白板动画（149 幕新载荷 + 1 台含元素库的新引擎）写回主文件
`萌星小学英语_最终合并版.html` 的一次性回灌包。其余 400 幕保持原样不动。

- 场景级内容更新 134 幕：第一性原理 24 幕按知识模型重生成、T12 勘误批次、
元素库改造（茶壶/杯/碗/刀/书/球/门等）、讲解文案修正等。
- 纯引擎换代 15 幕：内容不变，但必须跑新引擎才生效的修复
（poly 头图换元素书、结尾口诀卡被旧引擎误吞的 12 幕等）。

## 怎么用（备用方式）

> 注：本包已由开发侧直接回灌进仓库主文件；以下双击流程是备用件，
> 适用于拿到旧版主文件、需要自行回灌的场合。

1. 把 `payloads.json`、`回灌.bat`、`回灌.ps1` 三个文件复制到主文件
`萌星小学英语_最终合并版.html` 所在的同一个文件夹。
2. 双击 `回灌.bat`，等待窗口显示「」。
3. 脚本会先自动生成一份带时间戳的备份
（`萌星小学英语_最终合并版_备份_yyyyMMdd_HHmmss.html`），
再逐条校验、替换并做全量自检；任一步失败都会中止并中文报错、
指明是哪一幕，正式文件保持原样。
4. 完成后双击主文件即可使用；如需还原，用备份文件改回原名即可。

## 安全保证

- 脚本不联网，只读写同目录的主文件、备份与临时文件。
- 替换前逐条核对现有载荷的 sha256，文件被改过即中止，不会误伤。
- 替换后全量自检：549 个载荷逐个解码、每条标志内容核对、
动画以外的数据库区域逐字节比对一致，全部通过才换入正式文件。

## 文件清单

- `payloads.json` — 回灌数据（149 条 + 新引擎 blob）
- `回灌.bat` / `回灌.ps1` — 一键脚本（Windows PowerShell 5.1+）
- `manifest.md` — 逐幕清单与变化摘要
- `recipe.md` — 载荷工艺说明（沿用 T15_pack 口径）
