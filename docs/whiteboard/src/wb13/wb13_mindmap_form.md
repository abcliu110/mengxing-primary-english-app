# 思维导图 25 页 · 形态定义与分组表

> 形态已定（见下 §1），25 页分组表取自 `docs/whiteboard/v5/mindmap_groups.json`（gen_mindmap.py 生成）。

## 1. 形态定义（定稿）

- **一页 = 一个子主题**（VOCAB_DB 子主题首次出现顺序 = 幕序号，idx 0–24）。
- **上：讲解幕**（`auto.js` 的 `mindmapBuild` 版式）：讲解员从中心节点开始，一枝一枝画出来，边画边朗读（R2）；一次只展开一枝，不重叠、不拥挤；枝多时分幕或板擦转场；最后可缩放看总览（总览只是收尾，不是主体）。节点里的动作词照 R4 演出来。（MASTER_DESIGN 决策 28 画法；HANDOFF §2 主题思维导图讲解幕一节）
- **下：交互导图保留在下方**（原 `drawThemeMindMap` canvas 可拖动缩放，节点点击开词卡），讲解幕不取代它。
- **分组规则**：`mindmap_groups.json` 按 pos / meaning / senses[0].scene 规则分组；规则分不出的放「更多」组；1–2 词的「更多」组规则补进正式组（2026-10-31 分组修正后：剩下的「更多」都 ≥3 词）。
- **生成方式**：场景由 `v5/gen_mindmap.py` 从 VOCAB_DB + `mindmap_groups.json` 生成，**勿手改场景**，改规则/数据后重跑；回归 `python3 v5/app_check6.py`。
- **已知缺口（R37-06，待重做导图时一起处理）**：导图 25 幕的『常用搭配动词 / 评价形容词』框取的是该主题第一个词的 collocations（如『动物大世界』= The bird can fly.），内容不对，应去掉——本立项不改场景，只登记缺口。
