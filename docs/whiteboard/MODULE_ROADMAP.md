## A. 中英思维对照（最高优先级）

专治中式英语的根源。和六大原理同一层级。

1. **英语句子必须有主语**：「下雨了」说 It's raining。形式主语 it 一次讲透。
2. **修饰语的位置**：中文修饰语一律放前面，英语长修饰语放后面（the boy in red）。这是从句的总开关。
3. **形合 vs 意合**：英语必须用 and、but、so、because 把句子连起来。
4. **单复数和时态必须体现在词身上**：衔接 ③ 边界感、④ 单核谓语。
5. **「是」不等于 be**：「我是喜欢」→ I like。这是小学最高频的错误之一。

落地选项：总枢第 ⑦ 条，或独立的「中英对照总枢」（4–5 幕）。

## B. 拼写潜规则（并入「自然拼读总规则」）

- 英语单词几乎不以 v 结尾，所以写 have、give、love。
- 词尾很少放 i：用 y（happy、try），加词尾时 y 变回 i（tries、happier）。
- c、g 在 e、i、y 前面读软音（city、giant）。
- q 后面几乎总跟着 u。

## C. 词汇总规律

- **高频词 80/20**：最常用的约 100 个词，大约占书面英语的一半（Oxford English Corpus，近似值）。
- **语块与搭配**：make a mistake、have breakfast、heavy rain。
- **一词多性**：a run / to run。
- **合成词重音**：BLACKboard 和 black BOARD 意思不同。并入 `stress_rhythm`。

## D. 说话的分寸（语用）

## F. 小品词的意义系统（短语动词总钥匙）★ 推荐

几个小词各有固定的「方向义」，短语动词不用死记：

- **up**：向上，或者「做完、做到底」：stand up、eat up、clean up、use up。
- **down**：向下，或者「减少、记下来」：sit down、slow down、write down。
- **out**：出来，或者「彻底、消失」：go out、find out、run out、sold out。
- **off**：离开、断开：take off、turn off、get off。
- **on**：接触、继续：put on、turn on、go on。
- **back**：回来：come back、give back。

承接 ⑤ 向量时空律里的 on/off，可以做成独立页签。

## G. 空间隐喻（metaphor_code 加一个「密码四」）

- **上 = 多 / 好**：prices go up、cheer up、feel down。
- **前 = 未来，后 = 过去**：look forward to、look back。
- **时间就是钱**：spend time、save time、waste time。

## H. 数字的秘密（真实词源）

- **eleven / twelve**：古英语意思是「剩一个、剩两个」（数完十个手指之后），所以它们不按 -teen 的规律走。
- **thirteen–nineteen**：都是 -teen，也就是「three + ten」。
- **first、second 不规则**：它们不是从 one、two 变来的。second 借自拉丁语「跟随的」。
- **dozen 一打**：12 进制的痕迹。
- 可以和格林定律（ten ↔ December）互相链接。

## I. 星期与月份的故事（真实词源）

- **Sunday / Monday**：太阳日、月亮日。
- **Tuesday–Friday**：北欧神 Tiw、Woden、Thor、Frigg。Thursday = Thor's day。
- **Saturday**：土星（Saturn）。
- **September–December**：拉丁语里的 7–10（septem、octo、novem、decem）。罗马历把新年放在三月，所以「九月」叫「第七月」。
- 低年级友好，故事性强。适合作为格林定律前面的「词源入门」。

## J. 英式 vs 美式

- 拼写：colour / color、centre / center。
- 词汇：lift / elevator、rubber / eraser。
- 日期写法：英式「日 / 月」，美式「月 / 日」。
- 和教材版本相关，适合做成对照表页签。
