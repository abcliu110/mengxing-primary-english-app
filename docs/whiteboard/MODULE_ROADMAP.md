## A. 中英思维对照（最高优先级）

专治中式英语的根源。和六大原理同一层级。

1. **英语句子必须有主语**：「下雨了」说 It's raining。形式主语 it 一次讲透。
2. **修饰语的位置**：中文修饰语一律放前面，英语长修饰语放后面（the boy in red）。这是从句的总开关。
3. **形合 vs 意合**：英语必须用 and、but、so、because 把句子连起来。
4. **单复数和时态必须体现在词身上**：衔接 ③ 边界感、④ 单核谓语。
5. **「是」不等于 be**：「我是喜欢」→ I like。这是小学最高频的错误之一。

落地选项：总枢第 ⑦ 条，或独立的「中英对照总枢」（4–5 幕）。

## B. 拼写潜规则（并入现有「王炸 01：自然拼读五大黄金发音法则」/「9 步自然拼读阶梯」，不新开页签）

- 英语单词几乎不以 v 结尾，所以写 have、give、love。
- 词尾很少放 i：用 y（happy、try），加词尾时 y 变回 i（tries、happier）。
- c、g 在 e、i、y 前面读软音（city、giant）。
- q 后面几乎总跟着 u。

- **一词多性**：a run / to run。
- **合成词重音**：BLACKboard 和 black BOARD 意思不同。并入 `stress_rhythm`。

## F. 小品词的意义系统（短语动词总钥匙）★ 推荐

几个小词各有固定的「方向义」，短语动词不用死记：

- **up**：向上，或者「做完、做到底」：stand up、eat up、clean up、use up。
- **down**：向下，或者「减少、记下来」：sit down、slow down、write down。
- **out**：出来，或者「彻底、消失」：go out、find out、run out、sold out。
- **off**：离开、断开：take off、turn off、get off。
- **on**：接触、继续：put on、turn on、go on。
- **back**：回来：come back、give back。

承接 ⑤ 向量时空律里的 on/off，可以做成独立页签。

## G. 空间隐喻（metaphor_code 加一个「密码四」）

- **上 = 多 / 好**：prices go up、cheer up、feel down。
- **前 = 未来，后 = 过去**：look forward to、look back。
- **时间就是钱**：spend time、save time、waste time。

## H. 数字的秘密（真实词源）

- **eleven / twelve**：古英语意思是「剩一个、剩两个」（数完十个手指之后），所以它们不按 -teen 的规律走。
- **thirteen–nineteen**：都是 -teen，也就是「three + ten」。
- **first、second 不规则**：它们不是从 one、two 变来的。second 借自拉丁语「跟随的」。
- **dozen 一打**：12 进制的痕迹。
- 可以和格林定律（ten ↔ December）互相链接。

## I. 星期与月份的故事（真实词源）

- **Sunday / Monday**：太阳日、月亮日。
- **Tuesday–Friday**：北欧神 Tiw、Woden、Thor、Frigg。Thursday = Thor's day。
- **Saturday**：土星（Saturn）。
- **September–December**：拉丁语里的 7–10（septem、octo、novem、decem）。罗马历把新年放在三月，所以「九月」叫「第七月」。
- 低年级友好，故事性强。适合作为格林定律前面的「词源入门」。

## J. 英式 vs 美式

- 拼写：colour / color、centre / center。
- 词汇：lift / elevator、rubber / eraser。
- 日期写法：英式「日 / 月」，美式「月 / 日」。
- 和教材版本相关，适合做成对照表页签。

## v0.2 深挖：按语言层级系统扫描

> 方法：按语音 → 词形 → 句法 → 词义 → 语用 → 书写逐层找「一条规律管一大片」、又能对准中国学生痛点的知识点，再和现有页签比对去重。
> 去重发现：`stress_rhythm` 法则 C 已有 /ə/ 弱读与连读；`confusables` 已有 look/see/watch、borrow 类辨析；`past_clans` 已有过去式四大门派。

### K. 中国学生发音五大坑（语音层）★
中文音节大多以元音收尾，结构简单，所以：
1. **词尾加元音**：book 读成 book-e，good 读成 good-e。英语大量以辅音收尾。
2. **th 读成 s / z**：think → sink。中文没有咬舌音。
3. **v 读成 w**：very → wery。v 要上齿咬下唇。
4. **辅音丛拆开**：street 读成 si-tree-t。str 要一口气读完。
5. **l / n、r / l 混淆**：有方言背景的孩子更常见。
用 `fp_props.mouth` / `lips` 做口型对比。和 ① 省力律、`stress_rhythm` 互相链接。

### L. 英语只剩 8 个词尾（词形层）★★
英语所有的屈折变化，一共只有 8 个词尾：
-s（复数）、-'s（所有格）、-s（三单）、-ed（过去式）、-ing、-en（过去分词）、-er（比较级）、-est（最高级）。
记住这 8 个，就掌握了英语词形变化的全部「正规军」，剩下的都是不规则的老兵（`past_clans`、不规则复数）。
可以做成「8 格工具箱」总览图，挂在 ③ 边界感、④ 单核谓语之间。

### M. 代词是古英语的活化石（句法层）
英语名词丢掉了「格」，所以只能靠语序：Dog bites man ≠ Man bites dog。
只有代词还保留着格：I / me / my / mine、he / him / his。
可以解释为什么不能说 Me like it、Him is my friend。

### N. 中文一个字 = 英语好几个词（词义层）★
- 借：borrow / lend
- 说：say / speak / talk / tell
- 穿：wear / put on / dress
- 看：look / see / watch / read（`confusables` 已有，这里只链接）
- 带：bring / take（方向不同，衔接 ⑤ 向量律）
- 教 / 学：teach / learn / study
总纲：中文按「动作」分，英语按「方向、状态、对象」分。可以做成一个「一字多词」总览，具体辨析链接到 `confusables`。

### O. 核心义：万能动词地图（词义层）★
get、take、make、have、go、come、put、give 这几个动词意思最多，但每个都有一个核心画面：
- **get**：进入某个状态或拥有（get up、get angry、get a gift）
- **take**：拿走、带走（take a bus、take a photo、take off）
- **make**：从无到有地造出来（make a cake、make a mistake、make friends）
- **put**：放到某处（put on、put away）
一个核心画面放射出一组用法，适合用白板「辐射图」来做。和 F 小品词组合起来，就是短语动词的完整钥匙。

### P. 大数换算：万和亿哪去了（数字层）★
英语三位一组：thousand、million、billion。
中文四位一组：万、亿。
- 一万 = ten thousand
- 十万 = one hundred thousand
- 一百万 = one million
- 一亿 = one hundred million
用数位条「逗号对齐」动画演示。小学高年级应用题和阅读里会遇到。并入 H 数字的秘密。

### Q. 否定疑问句的 Yes / No（语用层）★
- Don't you like it? → Yes, I do.（喜欢）/ No, I don't.（不喜欢）
- 中文答「对，我不喜欢」，英语却说 No。
总规则：英语的 yes / no 跟着「事实」走，不跟着对方的问法走。并入 A 中英思维对照。

### R. 大写与标点（书写层）
- 大写：句首、I、人名地名、星期、月份、节日都要大写（中文没有大小写）。
- 标点：英语没有顿号「、」，句号是实心点「.」，书名用斜体或引号。
- 姓名顺序：名在前、姓在后；Mr / Ms + 姓。
低年级实用，可以做成小测。

### S. 实词 vs 虚词（总览）
虚词（the、of、and、to、a…）数量少，但出现频率最高；实词数量多，但每个词出现得少。
词库里已经有 `is_function_word` 字段，可以直接做「全书虚词覆盖率」可视化，和 C 的高频词 80/20 合并。

### T. 英语词汇从哪来（来源比例）
一项经典统计（Finkenstaedt & Wolff, 1973）显示，英语词汇里法语来源和拉丁语来源各约三成，日耳曼本土词约四分之一。
但日常最高频的词绝大多数是本土词。
这是「词汇三层楼」和格林定律的数据底座。数据要引用原文，不要写死精确百分比。

## v0.3 顶层审视：缺的不是模块，是骨架

> 结论：候选模块已经够多了。真正缺的是让所有模块变成「一套课程」的骨架：路径、课标、可信度、练习闭环、例外处理、性能。骨架要先于新模块搭好，否则模块越多，越像一堆散页。

### 0. 纠错（复核 App 现状后发现）
- 自然拼读**已有**：「王炸 01：自然拼读五大黄金发音法则」和「9 步自然拼读阶梯」。所以 B 只补进去，不新开页签。
- 朗读**已有基础**：App 里已经用了 `speechSynthesis`。白板的朗读开关（SOP §6）可以直接复用，K 发音坑、Q 语调、语调地图的制作成本会明显下降。
- 错题本**已有**：消错规则是「跨至少 2 个学习日、连续答对 3 次」。新模块的练习可以直接接入。

### 1. 总地图与学习路径（骨架 ①）
- 一张「元地图」把六大原理、王炸实验室、新模块串起来。每个模块标出：前置模块 → 本模块 → 后续模块。
  例：⑤ 向量律 → F 小品词 → O 核心义动词。
- 给出 2–3 条推荐路径：「发音线」「语法线」「词汇词源线」。
- 落地：总枢页面顶部加「我在地图哪儿」入口。

### 2. 课标对齐（骨架 ②）
- 每个模块标注《义务教育英语课程标准（2022 年版）》的级别：一级（3–4 年级）、二级（5–6 年级），以及「拓展」（超出课标、给学有余力的孩子）。
- 同时标注核心素养四维：语言能力、文化意识、思维品质、学习能力。
- **缺口**：现有内容和候选模块几乎都在语言能力、思维品质上，**文化意识明显薄弱**，所以新增 U 模块。
- 格林定律、T 来源比例、M 代词活化石应标成「拓展」，避免家长误以为是考点。

### 3. 可信度徽章（骨架 ③，全 App 统一）
现在只在文案里口头区分，改成统一的视觉徽章：
- 📜 **真实词源**：格林定律、tw- = two、星期月份、eleven
- 💡 **记忆联想**：M 像山、S 像蛇、fl- / gl- / sl-
- ✂️ **简化说法**：为了小学生理解做的简化（如「单核谓语」）
- ⚠️ **有例外**：规律不是 100% 成立
每个白板案例的 header 旁边都显示徽章。这样既保护教学的严谨性，也让家长放心。

### 4. 例外角（骨架 ④）
- 每条规律的最后一幕，或者一个固定角落，列出 2–3 个典型例外，并说明原因（多数是古英语残留或外来词）。
- 没有可靠统计的，不写「覆盖 X%」，只写「大多数」。
- 好处：孩子遇到例外时不会觉得「规律是骗人的」，反而会更信规律。

### 5. 正迁移：这些你已经会了（补进 A）
A 现在只讲中英差异，还应该讲相同之处，降低孩子的焦虑：
- 基本语序都是主谓宾：我吃苹果 = I eat apples。
- 短的形容词都放名词前：红苹果 = red apple。
- 疑问词意思一一对应：什么 what、谁 who、哪里 where。
结构：先讲「一样的」，再讲「不一样的」。

### 6. 练习闭环（骨架 ⑤）
- 每个模块看完白板，接 3–5 道小测，题型优先用「认出 → 选择 → 拼写」。
- 答错进现有错题本，复用现有的消错规则。
- 模块完成度存在 `localStorage`，总地图上点亮。**不接第三方统计**（儿童隐私）。

### 7. 认知负荷规范（写进 SOP）
- 每幕 ≤ 90 秒，只讲一个核心点；每个模块最多 4 幕。
- 每幕结尾必须定格在一张「总结图」上，方便截图复习。
- 新术语每幕最多一个。

### 8. 工程与性能（骨架 ⑥）
- 主 HTML 已约 5 MB（单文件）。再加 10 个以上模块之前，要先定性能预算：
  - 白板案例按需加载（点开页签才注入脚本）。
  - 目标：中低端手机首屏可交互时间不变差。
- 回归：每加一个模块，都跑 `appfp.py` 和 `appwb.py`，再做一次首屏耗时对比。
