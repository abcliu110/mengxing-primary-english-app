# 单词身世 · 内容深度与动画表达规范（v0.1）

> 日期：2026-10-29　｜　入口：**首页**，和第一性原理总枢并列（用户已定）
> 用户最关心三件事：①每个菜单内容的**深度**和**广度**；②动画**怎么实现**；③动画**是否完美表达了内容的深刻含义**。
> 本文是这三件事的标准。每一幕在制作前和验收时都要过一遍这个标准。

---

## 0. 先对现有设计稿做一次自我批评

| 状态 | 内容 | 问题 |
|---|---|---|
| ✅ 有深度 | port 港口、goodbye 缩短、cow / beef 分层、window = 风的眼睛、hippopotamus 河里的马、格林定律 p→f | 一个场景能讲通一组词，背后有一个洞见 |
| ⚠️ 有沦为「冷知识清单」的风险 | 品牌表（11 行）、神话日常词表（15 行）、地名人名清单、借词国家表 | 一行一个词，词与词之间没有关系，看完只记住「好玩」，没有方法 |

**整改原则**：清单不直接做成动画。每一章先提炼**一个洞见**，再从清单里挑 **≤ 6 个最能证明这个洞见的词**进动画，其余的词进词卡，作为 🥚 彩蛋或身世标签。

## 1. 深度标准：每一幕必须走完四层

| 层 | 问题 | port 示例 |
|---|---|---|
| **L1 是什么** | 这个词什么意思？ | port = 港口 |
| **L2 为什么** | 它为什么叫这个？背后是什么场景、历史、地理？ | 地中海是「陆地中间的海」，罗马靠港口连起整个帝国 |
| **L3 怎么推** | 这条规律能推出哪些别的词？ | 方向前缀 + port：im 进、ex 出、trans 穿过、re 回来 → 一次推出一整个家族 |
| **L4 我会用** | 孩子能不能用它解开一个**没教过**的词？能不能反观中文？ | 结尾出题：「sup（从下面）+ port = ？」；中文「进口、出口」的「口」，本来也是港口和关口的「口」★ |

**只走到 L1、L2 的，是冷知识；走到 L3、L4，才是方法。** 验收时，L3 和 L4 缺一不可。

## 2. 广度标准：每一章的配额

| 项 | 配额 |
|---|---|
| 核心洞见 | **1 句**（看完能复述） |
| 动画里的词 | 课标词 4–6 个 + 🥚 彩蛋词 ≤ 3 个 |
| 词卡延伸词 | 不限，标 🥚 |
| 中文对照 | ≥ 1 处（一样 / 比喻不同 / 相反，三类选一） |
| 严谨提示 | 有争议的地方必须出现 ❓ 或 ⚠️ |
| 幕数 | 每章 3–4 幕，每幕 ≤ 90 秒 |

**广度靠章节数量铺开（总共十几章），不靠单幕塞词。**

## 3. 每章的「深刻含义」：一句话洞见

动画的一切动作都服务于这一句话。写不出这句话的章节，不开工。

| 章 | 一句话洞见 |
|---|---|
| 港口（port） | **港口是罗马世界的大门；一个「门」字根，长出了进、出、穿越、带回、机会。** |
| 欧罗巴（Europe） | **一块大陆的名字，来自一个神话；神话给今天的世界命名。** |
| 蓝牙（Bluetooth） | **一千年前统一丹麦的国王，今天在「统一」你的耳机和手机——名字是借故事的力量。** |
| 气候 | **一个民族最缺什么，它的语言就最珍惜什么**（少阳光 → sunny 是夸人的；东风在中英文里意思相反）。 |
| 地理 | **岛国用海思考，农耕国用土地思考。** |
| 饮食 | **主食决定了「饭碗」的比喻**（bread and butter ↔ 饭碗）。 |
| 宗教 | **信仰沉淀成日常寒暄；人们忘了来源，词还记得**（goodbye、holiday）。 |
| 神话 | **古老的故事还在给新事物取名**（Apollo → Artemis，Nike）。 |
| 维京与诺曼 | **词汇是社会阶层的化石：农民养 cow，贵族吃 beef。** |
| 借词地图 | **英语是一门「收集者」语言，全世界都往里装过单词。** |
| 地名人名 | **东西会带着它出生地的名字去旅行**（hamburger、china）。 |
| 动植物 | **名字是古人第一眼看到的画面**（河里的马 = 河马，中英一致）。 |
| 辟谣角 | **好故事不等于真故事；查证本身就是一种能力。** |
| 格林定律 | **声音会成体系地「集体挪位」，所以长得不一样的词，可能是亲戚**（foot ↔ pedal）。 |

## 4. 动画怎么表达含义：动作语法

**铁律：动作即语义。** 每一个动作都必须代表一个意思，不允许纯装饰的动作。
引擎 v2 已有的能力：`group`、`move`、`arc`、`buzz`、`fade`、`rot`、`hide`、`camera`，以及道具 `arrow`、`chip`、`circle`、`bracket`、`underline`、`strike`、`redX`、`tree`、`note`、`zh`。

| 含义 | 动作 | 引擎实现 |
|---|---|---|
| **词根不变** | 词根块始终是同一种颜色，固定在画面中心 | `chip` 固定位置 + 统一配色 |
| **前缀的方向**（im 进 / ex 出 / trans 穿过 / re 回 / sup 托） | 货物沿箭头方向真的移动 | `move` / `arc` + `arrow`；衔接 ⑤ 向量律 |
| **拼合成词** | 前缀块飞过来，「咔」地吸附到词根上 | `group` + `move` + 一次短 `buzz`（吸附感） |
| **时间穿越**（古 → 今） | 镜头拉远，旧场景褪成线稿，新场景浮现在同一位置 | `camera` 缩放 + 交叉 `fade` |
| **音变**（p → f） | 旧字母先抖一下，在同一位置淡出，新字母淡入 | `buzz` → `fade` 交叉；位置不变，表示「同一个音挪了位」 |
| **省力缩短**（God be with you → goodbye） | 字母一个个消失，剩下的向中间靠拢 | 逐个 `hide` + `move` 合拢；衔接 ① 省力律 |
| **风和顺势**（op-portunity） | 风线推着船进港 | `arc` 风线 + 船 `move` 加速 |
| **中英对照** | 左右分屏，两边做镜像动作 | 两个 `group` 同步 `move` |
| **意思相反**（东风） | 同一支箭头，一边是暖色，一边是冷色，一边旋转 180° | `arrow` + `rot` + 颜色 |
| **辟谣** | 盖上一个 ✗ 印章 | `redX` + `rot` + `buzz` |
| **分层**（cow / beef） | 画面上下两层：城堡里和牛棚里，词各自落进自己那一层 | 两个 `group`，各自 `move` 到不同高度 |

### 需要新增的能力（最小集）
1. **`map` 道具**：简化的欧洲和地中海轮廓（自绘多边形），支持按区域点亮。
2. **`morph` 辅助**：「同位置换字母」的封装（`buzz` + 交叉 `fade`），格林定律和音变都用得到。
3. **`path` 运动**：沿折线移动（船环游世界、维京船航线）；现有的 `arc` 只能走一段弧。
4. **`stamp` 道具**：盖章（护照、辟谣共用）。
5. **徽章组件**：📜💡✂️⚠️❓ 和 🥚，显示在 header 旁边和词卡上。

## 5. 「是否完美表达」的四道验收关

每一幕都要过这四关，任何一关不过就返工：

1. **静音测试** 🔇：关掉所有文字说明，只看动作，孩子能不能猜出大意？（比如：货物往城里走，就是 import。）
2. **一句话测试** 🗣️：看完以后，能不能说出这一章的一句话洞见？
3. **预测测试** 🔮：每章结尾出一个没教过的词，让孩子用规律去猜（如 sup + port = support、hippo + campus？）。猜对，说明 L3 到位了。
4. **严谨测试** 📜：每个 📜 都有出处，每个 ❓ 都真的标出来了，没有把联想说成历史。

再加两条体验检查：每幕结尾定格在一张能截图复习的总结图上；每幕只引入一个新概念。

## 6. port 示范幕：按本规范逐层对照

| 镜头 | 动作（引擎） | 表达的含义 | 深度层 |
|---|---|---|---|
| 1 地图 | `map` 点亮地中海；medi + terra 两块 `chip` 拼合；三块陆地 `move` 向中间靠拢 | 「陆地中间的海」→ 为什么港口这么重要 | L2 |
| 2 进港 | 船沿 `path` 驶入；`arc` 风线推船加速；op + portunity `group` 吸附 | 顺风进港 = 机会 | L1 + L2 |
| 3 搬运 | 货箱沿 4 支 `arrow` 移动：进城、上船、去别的港、带消息回来；每个前缀吸附到 port 上 | 方向前缀 + 同一个词根 = 一个家族 | **L3** |
| 4 城门 | `stamp` 盖章；pass + port 吸附 | 通过港口或城门的许可 | L1 + L2 |
| 5 穿越 | `camera` 拉远；船淡成飞机，港口淡成机场；air + port 吸附 | 古今同一个逻辑 | L3 |
| 6 定格 | 中间 port，左边港口线、右边搬运线（标 📜 + 💡：两个亲戚词）；分屏对照中文「进口 / 出口 / 口岸」 | 一句话洞见 + 中文反观 | **L4** |
| 7 预测 | 出题：sup（从下面）+ port = ？停 3 秒再揭晓 support | 用规律解开新词 | **L4** |

时长预算：每个镜头 10–14 秒，一共约 85 秒。
