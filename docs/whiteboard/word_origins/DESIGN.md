## 1. 单词环游世界：借词地图 🌏 ★★★

在世界地图上点亮一个国家，就飞出一组英语里的借词。孩子会发现：英语是一门「收集全世界单词」的语言。

| 来源 | 词（📜） | 场景 |
|---|---|---|
| **中文** | tea（闽南话 te）、ketchup（闽南话「鲑汁」，通行说法）、kung fu、tofu（经日语）、lychee、kowtow | 海上茶叶贸易；和 U「用英语讲中国」联动 ★ |
| **马来语** | **orangutan = orang（人）+ hutan（森林）= 森林里的人**、bamboo（可能经葡萄牙语、荷兰语转入❓）、amok | 东南亚热带雨林 |
| **阿拉伯语** | coffee（经土耳其语）、sugar、algebra、zero、giraffe、alcohol | 古代阿拉伯商路与数学 |
| **印地语** | shampoo（原意是「按摩」）、pajamas、jungle、bungalow | 英国与印度的历史 |
| **日语** | tsunami、karaoke、**emoji（e 绘 + moji 文字，和 emotion 无关）** ⚠️ | 现代流行文化 |
| **荷兰语** | cookie（小蛋糕）、yacht、boss | 荷兰航海贸易，接上航海主题 |
| **美洲原住民语言** | chocolate、tomato（纳瓦特尔语，即阿兹特克人的语言）、raccoon、skunk、moose | 大航海 → 新大陆 |
| **意大利语** | pizza、**piano**、balcony | — |
| **德语** | **kindergarten = 孩子的花园**、hamburger | — |
| **法语** | restaurant、ballet、menu | 诺曼征服（见 §5） |

**分镜构想**：一艘船（又是航海）环游世界，每靠一个港口就装上一箱单词。最后回到伦敦，箱子打开，单词飞进字典。

## 2. 地名、人名变成东西 🍔 ★★★

**地名 → 物品**（📜）
- **hamburger**：德国汉堡（Hamburg）
- **china**（瓷器）：中国 ★（china 小写是瓷器，China 大写是中国，衔接 R 大写规则）
- **turkey**（火鸡）：欧洲人搞混了来路，以为它是经土耳其运来的
- **jeans**：意大利热那亚（Genoa，法语 Gênes），那里的水手穿这种布
- **denim**：法国尼姆（de Nîmes，来自尼姆的布）
- **tangerine**（橘子）：摩洛哥丹吉尔（Tangier）
- **cheddar**（切达奶酪）：英国切达村
- **peach**：拉丁语「波斯的苹果」（persicum）
- **marathon**：希腊地名

**人名 → 物品**（📜）
- **sandwich**：三明治伯爵（Earl of Sandwich），据说他不愿离开牌桌，让人把肉夹在面包里
- **teddy bear**：美国总统西奥多（Teddy）·罗斯福拒绝射杀一只小熊的故事 ★
- **cardigan**（开衫）：卡迪根伯爵
- **Braille**（盲文）：发明者路易·布莱叶
- **watt / volt / Celsius**：瓦特、伏特（Volta）、摄氏度（Celsius）——和小学科学课联动

**中文对照**：东坡肉（苏东坡）、宫保鸡丁（丁宝桢官衔「宫保」）、景德镇 → 瓷器

## 3. 动植物名字里的画面 🦛 ★★★

拆开就是一幅画，非常适合做白板动画（📜）：
- **hippopotamus** = hippo（马）+ potamus（河）= **河里的马**（中文「河马」也一样！）★
- **dinosaur** = deinos（可怕的）+ sauros（蜥蜴）= **可怕的蜥蜴**（中文叫「恐龙」，意思相近）★
- **octopus** = octo（八）+ pus（脚）= **八只脚**（衔接 October 原本是第八月）
- **dandelion**（蒲公英）= 法语 dent de lion = **狮子的牙齿**（叶子边缘像锯齿）
- **daisy**（雏菊）= day's eye = **白天的眼睛**（早上开花、晚上合上）
- **pineapple** = pine（松果）+ apple，因为它长得像大松果
- **porcupine**（豪猪）= 带刺的猪
- **rhinoceros** = rhino（鼻子）+ ceros（角）= **鼻子上长角**（中文「犀牛」）
- **chameleon**（变色龙）= 地上的狮子
- **butterfly**：来源有多种说法 ❓

**中文对照**：英语靠希腊语、拉丁语拼出画面；中文靠偏旁和造词，如河马、海马、长颈鹿。两者都是「看名字就能想到样子」。

## 4. 辟谣角：流行的假词源 ⚠️ ★★★

教孩子「好故事不一定是真的」，同时示范怎么查证（呼应可信度徽章）：

| 流行说法 | 真相 |
|---|---|
| SOS = Save Our Souls | ⚠️ SOS 只是一串好发、好认的摩尔斯电码（··· −−− ···），这个解释是后人编的 |
| kangaroo 是土著语「我听不懂你说什么」 | ⚠️ 来自澳洲土著语言 Guugu Yimithirr 里对一种袋鼠的称呼 |
| posh = Port Out, Starboard Home（去程左舷、回程右舷） | ⚠️ 没有证据，是后编的解释 |
| sincere = sine cera（不打蜡的雕像） | ⚠️ 民间编出来的说法 |
| emoji 和 emotion 同源 | ⚠️ 来自日语「绘文字」，只是碰巧长得像 |
| island 和 insula 同源 | ⚠️ island 来自古英语 īegland，s 是后人模仿 isle 加上去的 |
| salary 来自罗马士兵用盐发工资 | ❓ 和盐有关是对的，但「用盐当工资」缺乏证据 |

**意义**：这是「思维品质」素养的最佳载体。也给整个 App 的词源内容立个规矩：查不到出处，就不写成定论。

## 5. 维京人与诺曼人：英语的历史事件层 ⚔️ ★★

**维京人（北欧海盗）** 📜：大约从 8 世纪末开始侵袭、定居不列颠，留下了大量日常基本词：
- **sky、egg、knife、skin、leg、window**
- **window = wind（风）+ eye（眼睛）= 风的眼睛**：古时候的屋顶通风孔 ★★
- **they / their / them** 都来自古诺尔斯语（连代词都借了！衔接 M 代词活化石）
- **Thursday**（Thor）
- 地名结尾：-by（村庄，如 Derby）、-thorpe

**诺曼征服（1066 年）** 📜：法国诺曼人成了英国的统治者：
- **活的动物用英语本土词**（cow、pig、sheep，农民养）↔ **餐桌上的肉用法语词**（beef、pork、mutton，贵族吃）★★
- 这是 T「来源比例」和「词汇三层楼」的故事版

**分镜**：龙头船靠岸，单词跳下船；接着诺曼骑士登陆，城堡里的餐桌上摆出 beef，城堡外的牛棚里站着 cow。

## 6. 字母的真实身世 🔤 ★★

字母表源于古代腓尼基字母（📜，简化讲）：
- **A** 来自一个牛头（aleph = 牛），倒过来看 ∀ 像两只牛角
- **B** 来自房子（beth）
- **M** 来自水波纹（mem = 水）
- **alphabet = alpha + beta**（希腊字母的头两个）
- **upper case / lower case**：印刷工把大写铅字放在上层的字盒里，小写放在下层 📜 ★

**⚠️ 和 `fp_iconicity` 的关系**：总枢里「M 像山」是 💡 记忆联想，这里「M 来自水」是 📜 真实历史。两者并排展示，正好教孩子区分「联想」和「历史」。

## 7. 日常词里的古老画面 🌅 ★★

📜：
- **breakfast** = break（打破）+ fast（禁食）：一夜没吃，早上「打破空腹」
- **goodbye** = God be with you（已收入欧洲文化篇）
- **alarm** = 意大利语 all'arme「拿起武器！」
- **muscle** = 拉丁语「小老鼠」，肌肉动起来像皮下有只小老鼠在跑 ★
- **nightmare** 的 mare 是古英语里夜间压在人胸口的妖怪，不是母马
- **o'clock** = of the clock（按钟表算）
- **companion** = 一起吃面包（已收入欧洲文化篇）
- **school** = 希腊语 scholē，原意是「闲暇」（有空才能去学习）★
- **calculate** = 拉丁语 calculus「小石子」：古人用石子计数（中文对照：算盘）

## 8. 时间与度量的身世 ⏰ ★★

📜：
- **a.m. / p.m.** = ante / post meridiem（中午之前 / 之后），是拉丁语
- **mile** = mille passus：罗马军团的一千步
- **foot / inch**：用身体量长度（中文对照：古代的「尺」「寸」也和手有关）
- **e.g.、i.e.、etc.** 都是拉丁语缩写
- **calendar** = 拉丁语 kalendae（每月第一天，罗马人在这天结账）
- 衔接 H 数字的秘密、I 星期与月份

## 9. 体育与音乐词 🎾 ★

- **piano** 📜：pianoforte 的缩写，意思是「能轻能响」（piano = 轻，forte = 强）
- **tennis**：通行说法来自法语 tenez「接着！」（发球时的喊声）
- **soccer** 📜：来自 Association football 里的 soc
- **love = 零分**：有「来自法语 l'œuf（鸡蛋，形状像 0）」的说法 ❓
- **marathon**、**Olympics**（已收入神话篇）

## 10. 词义漂移：词也会「变脸」 🎭 ★

📜：
- **nice**：拉丁语 nescius「无知的」→ 傻的 → 讲究的 → 好的
- **silly**：原意「有福的、天真的」→ 傻的
- **girl**：中古英语里泛指年轻人，男孩女孩都算
- **villain**：农夫 → 坏人
- **awful**：充满敬畏的 → 糟糕的
- **对照**：中文「小姐」「同志」的词义也变过

## 统一机制：词卡上的身世标签

| 🌍 culture | 欧洲气候、地理、宗教 |
| ⚡ myth | 神话 |
