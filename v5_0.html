第一元公理 · 空间颗粒度

📦 名词边界公理：戴帽加尾铁律

🇨🇳 汉语意合：万物浑然一体，不区分单复数与可数性（一本书、十本书、喝点水，名词本身永不变形）。

🇬🇧 英语形合：万事万物先问“能不能按个数清边界”：

  • 可数单数绝不“裸奔”：出门必戴帽（a book an apple my bag）。
  • 超过 1 个必加尾巴：词尾必加复数 -s/-es（two books three boxes）。
  • 不可数名词“三不铁律”：不戴 a/an 帽、不加 s 尾、谓语永远配单数 is（some milk Water is important）。
第二元公理 · 时间颗粒度

❤️ 动词心脏公理：一山不容二虎 & 四套盔甲

🇨🇳 汉语意合：动作超越时间（我每天去、他每天去、昨天去，全用同一个“去”字）；形容词直接当谓语（“她很聪明”）。

🇬🇧 英语形合：动词是全句唯一的心脏发动机：

  • 一山不容二虎：一句话只能有一个核心动词！形容词前必派 am/is/are 搭桥（She is clever）；有实义动词绝不乱塞 is！
  • 四套时态盔甲：三单加 -s、正在 be+doing、过去穿 -ed、将来 will/be going to。
  • 照妖镜法则：见到 can/must/should/will/do/does/did/let's，后面动词 100% 打回原形！

第一性原理 底层认知规律 高频黄金口诀 标准点读示范
原理 01：语音拼读原理
见词能读·听音能写		 英语 84% 的单词遵循“音形对应（Phonics）”，仅 16% 高频视觉词（Sight Words）需特殊记忆。 开音节哑巴 e 读本音；闭音节读短音；ph=/f/，igh=/aɪ/，ar=/ɑːr/。 cake /keɪk/ elephant /ˈelɪfənt/ light /laɪt/
原理 02：词根积木原理
一词生十词·家族串记		 前缀改方向（sub-/super-/inter-/re-），词根定灵魂（port/vis/spect/dict），后缀定词性（-er/-ful/-y）。 动作加 -er/-or 变人；名词加 -y 变天气形容词；-ful 充满 -less 无。 teacher sunny helpful subway
原理 03：多义辐射原理
三幕剧画面推演		 一词多义绝不是乱造的，而是从 1 个“核心物理画面”通过动作化或场景迁移衍生出来的。 名词直接转类作动词：书册➔预订(book)，公园➔停车(park)，水➔浇水(water)。 book a ticket water the flowers
原理 04：形态一致原理
主谓一致·指代一致		 主语的人称和数决定了谓语动词与代词的形态，前后必须严丝合缝。 我用 am 你用 are，is 连着他她它；单数主语配三单 -s，复数主语配原形。 He studies Chinese. They study Chinese.
原理 05：时空坐标原理
介词与时态精准定位		 英语对时间与空间采用精密的几何切片：点（at）、面/天（on）、体/长周期（in）。 in 年月季早中晚，on 星期几与某一天，at 具体钟点与夜晚。 in spring on Monday at 7 o'clock
原理 06：极性与交际原理
肯定与否定疑问极性切换		 英语词汇对句子极性（肯定 vs 否定/疑问）高度敏感，交际遵循礼貌优先原则。 肯定句里用 some/and/too，否定疑问变 any/or/either（诚意邀请仍用 some）。 Would you like some juice? I don't have any bread.

🌳 决策树 A：看到【动词填空】怎么秒杀？

  1. 第1步【查照妖镜】：空前有没有 can / must / should / will / let's / don't / doesn't / didn't / to？
    👉 有：秒填动词原形！
  2. 第2步【找时间路标】：
    • Look! / Listen! / now 👉 am/is/are + V-ing
    • yesterday / last... / ago 👉 过去式 V-ed
    • tomorrow / next... / tonight 👉 be going to / will + 原形
    • every day / often / usually / on Mondays 👉 一般现在时（进第3步）
  3. 第3步【看主语排头兵】：主语是第三人称单数（He/She/It/单数人名）吗？
    👉 是：动词必加 -s/-es！否：填原形！

🌳 决策树 B：看到【名词/代词】怎么秒杀？

  1. 第1步【判可数性】：是不可数名词（water, milk, bread, juice, rice, homework, weather, information, advice）吗？
    👉 是：绝不加 a/an，绝不加 s，谓语配 is，提问用 How much！
  2. 第2步【看数量帽子】：
    • 前面有 a / an / this / that / one 👉 填单数（元音音素开头用 an：an apple/egg/orange/umbrella/uncle/hour）。
    • 前面有 some / many / these / those / ≥2数字 或 like + 种类 👉 填复数 -s/-es！
  3. 第3步【代词选格】：句首当主语用主格（I/he/she/they）；动介词后用宾格（me/him/her/them）；后面有名词用形物（my/her），后面无名词独立结尾用名物（mine/hers）！

🌳 决策树 C：看到【四大变形拼写】怎么写？

无论是复数(+s)、三单(+s)、进行时(+ing)、过去式(+ed)、比较级(+er)，统一用四步过滤法：

  1. 查不规则表：如 foot➔feet, mouse➔mice, go➔went, buy➔bought, sleep➔slept。
  2. 看末尾哑巴 e：加 -ing/-ed/-er 时先去 e（write➔writing, live➔living, dance➔dancing）。
  3. 看辅元辅重闭：双写尾字母（run➔running, swim➔swimming, big➔bigger, thin➔thinner, sun➔sunny）。
  4. 看辅音+y：变 y 为 i 再加 -es/-ed/-er（study➔studies, heavy➔heavier, worry➔worried）。
